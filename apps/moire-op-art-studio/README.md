# Moiré Op Art Studio（モアレ・オプアート・スタジオ）

線・ドット・同心円のパターンレイヤー（2〜3枚）を重ね合わせ、回転・間隔・太さ・不透明度・合成モードを操作してモアレの揺らぎをリアルタイムに観察できるキネティック・オプアートスタジオです。気に入った瞬間の静止フレームを、展示ラベル風のポスターフレーム付きPNG、または構造が一致するベクターSVGとして書き出せます。

> このアプリは **app-factory パイプライン**（アイディア出し〜プロトタイプ実装までを自律実行する仕組み）によって生成されたプロトタイプです。

## 特徴

- 平行線 / ドットグリッド / 同心円の3種のパターンレイヤーを最大3枚まで重ね合わせ
- レイヤーごとに回転・間隔・太さ・不透明度・色を独立操作（スライダーはrequestAnimationFrameベースで即座にプレビュー反映）
- グローバル合成モード（通常/乗算/差分/除外）＋レイヤー単位の上書き
- Kineticモード: 指定レイヤーをゆっくり自動回転（0〜180度を往復）させ、モアレが呼吸するように変化し続ける。再生/一時停止可能で、止めた瞬間をそのまま書き出せる
- プリセット5種（Riley Stripes / Fine Grid / Concentric Waves / Diagonal Interference / Triple Weave）
- ランダム生成 + 直前の状態への1手Undo（リセット・レイヤー削除にも同じ仕組みを流用）
- PNG書き出し（2×/3×/4×解像度、展示ラベル風のポスターフレーム＋仕様値・エディション番号・日時付き）
- SVG書き出し（Canvasと同じジオメトリ生成ロジックから`<line>`/`<circle>`要素を再構築するベクター出力）

## デザイン方針

スイス（インターナショナル・タイポグラフィ・スタイル）を採用。ベースは黒/白/グレーのみとし、UIのアクセントは赤1色に限定（キャンバス上のアート自体の配色は自由）。コントロールパネルは「LAYER 01 / LINES」のような番号付き仕様書スタイルで構成し、Interの太字見出し数字と細字ラベルのウェイト差で階層をつけています。

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 型チェック + 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果をローカルで確認
```

技術スタックはVite + TypeScript + 素のCanvas 2D API（フレームワーク非依存、外部の描画/シミュレーションライブラリ不使用）。バックエンドは不要で、クライアントサイドのみで完結します。

## Docker

静的サイトとしてビルドし、`nginx:alpine`で配信するマルチステージ構成です。

```bash
docker build -t moire-op-art-studio .
docker run --rm -p 8080:80 moire-op-art-studio
# http://localhost:8080/ で確認
```

## 既知の割り切り（プロトタイプゆえの範囲）

- 写真・画像素材のインポートは非対応（線/ドット/同心円の自前パターン生成のみ）
- Undo履歴は直前の1手のみ（多段階Undo/Redoは非対応）
- タッチジェスチャー専用のモバイル操作は非対応（レスポンシブ表示・スティッキーなプレビューのみ対応）
