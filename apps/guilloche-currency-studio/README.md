# Guilloche Currency Studio（架空紙幣スタジオ）

国名・通貨単位・額面・肖像モチーフの種を入力すると、hypotrochoid / epitrochoid 曲線を多層に重ねたギヨーシェ彫刻紋様を Canvas 上にリアルタイム生成し、完成した「架空の紙幣」1枚を高解像度 PNG / SVG として書き出せるスタジオです。

> このアプリは **app-factory パイプラインによる自律生成プロトタイプ** です（コンセプト立案からビルド確認まで一連のエージェントが自律的に実装しました）。

## 特徴

- **完全クライアントサイド完結**。サーバー・外部API不要。入力・生成物はすべてブラウザ内で完結し、送信・保存は行いません。
- ギヨーシェ描画エンジンは hypotrochoid / epitrochoid のパラメトリック式を自前実装（外部の spirograph / drawing ライブラリは使用していません）。
- 疑似乱数もシード文字列からの決定的な自前実装（`src/lib/prng.ts`）。同じシード（国名・通貨単位・額面・肖像シード・発行年）からは常に同じ紙幣が生成されます。
- 肖像モチーフの種は実写画像の変換ではなく、文字列をハッシュ化して中央メダリオンの幾何学パラメータに変換した「肖像に見立てた抽象紋様」です（UI上にもその旨を明記しています）。
- 額面ごとにインク色プリセットの既定値が変わりますが、一度でも手動でインク色を変更すると、以後は額面を選び直しても上書きされません（明示的にプリセットを選び直すか「額面既定に戻す」を押すまで維持）。
- 「ランダム生成」ボタンの実行前の状態に1手戻せる「元に戻す」操作を用意しています。
- SPECIMEN（見本）の透かし風オーバープリントは常時表示の固定要素で、消すことはできません（実在通貨との誤用・偽造用途と誤解されるリスクを避けるための安全策）。
- PNG（2×/3×/4×相当の解像度）・SVG（ベクタパス）の両形式で書き出し可能です。

## 技術スタック

Vite + TypeScript（フレームワーク非依存のバニラDOM）。描画は Canvas 2D API への直描画のみ。選定理由: 本アプリの核はギヨーシェ曲線の数式実装そのものであり、UI状態はフォーム入力とプレビュー再描画のみで完結する規模のため、フレームワークを介さずシンプルに保つのが最も適していると判断しました。

## セットアップ・起動

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 本番ビルド（dist/ に出力）
npm run preview   # ビルド済み dist/ をローカルで確認
```

## Docker

静的サイトとして nginx でビルド成果物を配信します。

```bash
docker build -t guilloche-currency-studio .
docker run --rm -p 8080:80 guilloche-currency-studio
# http://localhost:8080/ で確認
```

## ディレクトリ構成（`src/lib/`）

- `prng.ts` — 文字列ハッシュ（cyrb53）+ 決定的疑似乱数（mulberry32）
- `trochoid.ts` — hypotrochoid / epitrochoid のサンプリング（自前実装の数学コア）
- `guilloche.ts` — ロゼット・境界帯・タイント紋様など、曲線レイヤーの組み立て
- `notePlan.ts` — 紙幣全体のレイアウト計算（テキスト配置・配色・各ゾーンの座標）を純粋関数として集約。Canvas描画とSVG書き出しの両方がこの同じ「紙幣設計図」を参照するため、両形式の見た目が一致します
- `canvasRenderer.ts` — `notePlan` を Canvas 2D に描画
- `svgExport.ts` — `notePlan` からベクタ SVG 文字列を組み立て
- `banknoteData.ts` — 額面の文字表記・発行機関名・シリアル番号などのテキスト生成
- `nameGen.ts` / `presets.ts` — ランダム生成用の国名・通貨名の疑似生成、インク/紙色プリセット

## スコープ外（プロトタイプとして意図的に対象外としたもの）

- 実写画像アップロードによる肖像画変換
- 紙幣の裏面デザイン
- 複数額面のシリーズ管理・永続保存・アカウント機能
- 透かし・ホログラム等の物理的な偽造防止技術のシミュレーション
- 額面表記の完全自動翻訳（EN/JAの簡易テンプレートのみ）
- 印刷入稿仕様（CMYK変換等）への対応
