# RISO PRINT SIMULATOR（リソグラフ再現ポスターメーカー）

写真・見出しテキスト・図形アクセントを、リソグラフ印刷特有の2〜3色インク版に分解し、版ごとに角度の異なる網点（AMスクリーン）化と意図的な版ズレ（ミスレジストレーション）を与えたうえで、Canvas 2Dの`multiply`合成で重ね刷りするブラウザ完結のポスターメーカーです。蛍光インクの重なりが生む第三色までを再現し、1枚のアートポスターとしてPNG書き出しできます。

> 本アプリは app-factory パイプライン（アイディア出し〜プロトタイプ実装までを自律的に行う仕組み）によって自律生成されたプロトタイプです。

## できること

- 写真アップロード（JPEG/PNG、ドラッグ&ドロップ／クリック選択、キーボード操作対応）。写真なしでもテキスト・図形のみでポスターを構成可能
- 見出し・サブテキスト・図形アクセント（円/帯/三角形）を3種のレイアウトプリセットから配置
- リソグラフの代表的な蛍光/特色インク8色から2〜3色をチェック方式で選択（下限2・上限3を自動で強制、上限到達時はグレーアウト、下限到達時は解除操作を無効化）
- 写真はグレースケール輝度をトーン帯に分解し、版ごとに自動割当角度（0°/15°/45°系）のドットスクリーンを生成。文字・図形は1つの版にベタ塗りで割り当て
- 版ズレ強度スライダー（シード再現可能・振り直しボタンあり）、網点角度スプレッドスライダー
- 用紙トーン（暖色⇄寒色）・粒状ノイズスライダー、トンボ（見当マーク）表示切り替え
- 縦長ポスター／正方形の2アスペクト比、PNG書き出し（1x/2x/3x・書き出し時は全工程を指定解像度で再実行）
- 画像・テキストは一切外部送信されず、すべてブラウザ内で処理されます

## 技術構成

- Vite + TypeScript（バニラ構成、フレームワーク不使用）
- 画像処理（グレースケール変換・トーン帯割当・角度ドットスクリーン生成・版オフセット・multiply合成・紙の粒状ノイズ）はすべて Canvas 2D API による自前実装
- 状態管理は不変更新のリデューサ（`src/state.ts`）、プレビュー再描画は `requestAnimationFrame` で1フレーム1回に束ねて実行
- UI見出し・操作ラベルは `Archivo Black`、ポスター内テキストは `Anton` を `@fontsource` で自己ホスト（取得失敗時はシステムフォントへ縮退）
- バックエンドなし。静的サイトとしてビルドし nginx で配信

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果のプレビュー
```

## Docker

```bash
docker build -t riso-print-simulator .
docker run --rm -p 8080:80 riso-print-simulator
# http://localhost:8080 で確認
```

## デプロイ

`deploy.json` で `{"pages": true}` を指定しており、完全クライアントサイド・`npm run build` が `dist/` に静的サイト一式を出力する構成のため、GitHub Pagesプレビュー対象です（`vite.config.ts` の `base: './'` によりサブパス配信にも対応）。
