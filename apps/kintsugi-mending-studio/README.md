# 金継ぎスタジオ（Kintsugi Mending Studio）

器を割り、金の漆で継ぎ、傷を輝きに変えるポスターとして書き出す──金継ぎの美意識を体験する生成ツールです。

> **注記**: これは app-factory パイプライン（アイディア出し〜実装〜検証までを自律的に行う生成パイプライン）によって生成されたプロトタイプです。

## 使い方

1. **器の形**（碗・皿・花瓶）と**釉薬**（青磁・白磁・黒漆・辰砂）を選び、「この器を割り始める」を押す。
2. 作業台に置かれた器の面をクリック／タップして罅を入れる（最大4起点まで）。「やり直す」で罅を消去できる（数秒間はトースト通知から元に戻せる）。
3. 罅が1本以上ある状態で「金で継ぐ」を押すと、金線が幹→枝→毛細の順にアニメーションしながら継がれる。
4. 継ぎ終わると自動でポスター体裁（フレーム・一言キャプション・器種／釉薬／亀裂数／日付のキャプションラベル）に遷移する。「次の言葉」でキャプションを差し替えられる（表示中の言葉がそのままPNGにも反映される）。
5. 「PNGとして書き出す」で1600×2000pxの高解像度ポスター画像をダウンロードできる。
6. 「新しい器を割る」で最初の状態に戻る。

## 技術スタック

Vite + TypeScript（フレームワークなし）。器のシルエット、釉薬の陰影、罅の再帰生成、金継ぎの発光アニメーション、ポスター合成・PNG書き出しまで、すべて Canvas 2D API で完結しています。日本語フォントは `@fontsource/shippori-mincho`（見出し・キャプション）と `@fontsource/zen-kaku-gothic-new`（UIラベル）を使用。バックエンド・外部APIなし、クライアントサイドのみで動作します。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果のプレビュー
```

## Docker

```bash
docker build -t kintsugi-mending-studio .
docker run --rm -p 8080:80 kintsugi-mending-studio
# http://localhost:8080 で確認
```

静的サイト（バックエンド不要）のため、マルチステージビルド（Node でビルド → `nginx:alpine` が `dist/` を配信）構成です。
