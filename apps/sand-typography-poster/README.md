# Sand Typography Studio（砂文字ポスター）

短い単語やフレーズを入力すると、格子状のマスクとして生成された文字の輪郭に向けて、セルオートマトンで動く砂粒が上から降り積もっていくアート系トイです。積もった砂はドラッグでキャンバスを傾けると重力方向が変わり、安息角を超えた部分が文字の外へ実際に崩れ落ちます。完成した意匠は、二重罫線フレーム・隅の装飾・砂時計モノグラム・下部のプレート表記を備えたヴィンテージ博物学ポスター風のPNGとして書き出せます。

> **本アプリは app-factory パイプライン（アイディア出し〜プロトタイプ実装を自律的に行う仕組み）によって生成されたプロトタイプです。**

## 使い方

1. 「phrase」欄に1〜15文字程度の単語・フレーズを入力する（日本語・英数字対応）。
2. 「grain colour」でアンバー／テラコッタ／インディゴスレートの砂色を、「typeface」でSerif／Slabの書体を選ぶ（変更は次回の「注ぐ」から反映されます）。
3. 「注ぐ」ボタンを押すと、キャンバス上端から砂が降り注ぎ、文字の輪郭に沿って積もっていきます。文字の外に落ちた粒はそのまま画面下まで素通りして消えます。
4. キャンバスをドラッグ（マウス／タッチ両対応）すると重力の向きが傾き、積もった砂がその方向へ崩れます。指を離すと重力はゆっくり垂直へ戻りますが、崩れた形はそのまま残ります。
5. 十分に砂が定着すると「書き出し」ボタンが有効になり、ヴィンテージポスター風の構図でPNGを書き出せます。

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 型チェック + 本番ビルド（dist/ に静的サイトを出力）
npm run preview   # ビルド結果のプレビュー
```

## 技術構成

- 素の TypeScript + Canvas 2D API（フレームワーク不使用）。Vite はビルド・開発サーバーの薄いラッパーとしてのみ使用。
- 砂の物理はセルオートマトン（`Uint8ClampedArray` によるグリッド状態管理、`requestAnimationFrame` で更新・描画）。文字マスクはオフスクリーンcanvasにテキストを描画し、スーパーサンプリング＋アルファ閾値判定で生成。
- フォントは `@fontsource/playfair-display`（エレガントなセリフ）と `@fontsource/arvo`（レトロなスラブセリフ）をセルフホスト。外部APIキー・バックエンドは不要。
- 一般的なノートPCで滑らかに動くよう既定グリッド解像度は 200×150 程度。実行時に平均フレームレートが30fpsを下回ると自動的に低解像度（130×98）へフォールバックします。

## デプロイ

完全にクライアントサイドで完結する静的サイトのため、GitHub Pages プレビュー対象です（`deploy.json` で `pages: true`）。

Docker でのコンテナ化にも対応しています。

```bash
docker build -t sand-typography-poster .
docker run --rm -p 8080:80 sand-typography-poster
# http://localhost:8080 で確認
```
