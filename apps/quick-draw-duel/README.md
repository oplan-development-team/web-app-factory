# Quick Draw Duel（クイックドロー・デュエル）

1台の端末を挟んだ対面2人対戦の早撃ちリアクションゲーム。黄色い「READY」の間はじっと待ち、ランダムな間（1.5〜4.5秒）を置いて中央に「DRAW!」のサインが出たら、相手より早く反応した方が勝ち。DRAWサインより前に押すとフライング（誤射）でそのラウンド即敗北——画面が真っ赤に点滅し、スクリーンシェイクと合成銃声が炸裂する。3本先取したデュエリストがマッチの勝者。

> このアプリは app-factory パイプライン（New_Service_App の自律プロトタイピング・ワークフロー）によって自律生成されたプロトタイプです。

## 遊び方

- P1（画面左半分）: `Space` キー、またはタップ
- P2（画面右半分）: `Enter` キー、またはタップ
- 「READY」中に押すとフライング負け。「DRAW!」が出てから押した方が勝ち
- 反応タイムはミリ秒単位で計測され、そのラウンドの結果として表示される
- 3本先取で決着。全セッション通算の自己ベストタイムは `localStorage` に保存され、更新時は発光演出で強調される
- 横向き（ランドスケープ）専用。縦持ちでアクセスすると回転を促す案内が表示される

## 技術スタック

- Vite + TypeScript（フレームワーク不使用の素のDOM実装）
- 演出: Canvas 2D（勝利時のダストバースト・パーティクル）、Web Audio API（鐘・銃声・記録更新チャイムをすべてオシレーター/ノイズバッファから自前合成。外部音源ファイルは一切使用しない）
- 永続化: `localStorage`（全体ベストタイムのみ）
- バックエンド不要、`npm run build` は `dist/` に静的サイト一式を出力する（`vite.config.ts` で `base: './'` を設定し、GitHub Pagesのサブパス配信に対応）

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
```

## Docker

静的サイトをマルチステージビルドし、`nginx:alpine` で配信する。

```bash
docker build -t quick-draw-duel .
docker run --rm -p 8080:80 quick-draw-duel
# http://localhost:8080 で確認
```

## スコープ外（プロトタイプゆえの割り切り）

- オンライン対戦・CPU対戦・アカウント/サーバー側リーダーボードは未対応（同一端末での対面プレイ・localStorageの自己ベストのみ）
- キーバインドのカスタマイズ、3本先取以外のマッチ形式、ラウンド履歴の統計は未対応
- 縦持ちスマホ単体プレイのレイアウト最適化は対象外（横向き・対面据え置き前提）
