# ふーっと消して、願いごと (Blow Out & Wish)

マイクに息を吹きかけてロウソクを消す、誕生日のミニゲーム。炎の揺らぎとろうの垂れ落ちを自前の value noise / 手続き的シミュレーションで再現し、全部消えたら願いごとを一言だけダークラグジュアリーな演出でリビールします。

> これは app-factory パイプライン（アイディア出し〜プロトタイプ実装までを自律的に行う仕組み）によって自律生成されたプロトタイプです。

## 遊び方

1. トップ画面で「マイクを許可して始める」を押し、マイクの使用を許可する
2. 2秒ほどの無音キャリブレーション（周辺ノイズ測定）が終わると、モード選択画面へ
   - **ソロモード**: ロウソクの本数を 1 / 3 / 5 / 8 本から選ぶ
   - **連続チャレンジ**: 1本から開始し、消すたびに+1本ずつ増える。制限時間内に消しきれなければ終了
3. マイクに向かって「ふーっ」と息を吹きかけると、画面左上の息の強さゲージが反応し、炎が揺れる。ゲージが閾値を超えて一定時間続くと炎が消える(強く長く吹くほど、一度に複数本を消せる)
4. 全部消えたら、最後に一言だけ願いごとを入力してリビール演出を見る(保存はされません。スクリーンショットでどうぞ)
5. 「もう一度火を灯す」で同じモードに再挑戦、「モードを選び直す」でモード選択に戻れる

マイクの許可を拒否した場合・他のアプリがマイクを使用中の場合は、原因別の案内が表示されます。

## 技術構成

- Vite + TypeScript(フレームワーク不使用の vanilla 構成)
- 描画: Canvas 2D。炎の乱流ノイズ(value noise / fbm)・ろうの垂れ落ちは外部ライブラリを使わず自前実装
- 音声解析: Web Audio API(`AnalyserNode` + RMS計算)のみ。マイク音声はどこにも送信・保存されない
- バックエンドなし、完全クライアントサイド

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 本番ビルド (dist/ に出力)
npm run preview   # ビルド結果のプレビュー
```

### QA用の簡易モード(開発者向け)

`?simulate=1` をURLに付けて起動すると、実マイクの代わりに Space キー長押しで「息を吹く」動作をシミュレートできます(ヘッドレスブラウザ等、実マイクを使えない環境での動作確認用)。通常のプレイでは使用しません。

## Docker

```bash
docker build -t blow-out-wish .
docker run --rm -p 8080:80 blow-out-wish
# http://localhost:8080 で確認
```

静的サイト(nginx配信)のみで完結するため、GitHub Pages相当の配信にもそのまま対応します(`deploy.json` 参照)。

## スコープ外(プロトタイプとして意図的に省略)

- 複数人でのリアルタイム同期(画面共有前提)
- 願いごとの保存・画像生成・SNS共有(スクリーンショットでの持ち帰りを想定)
- ロウソク本数の自由入力、ケーキの装飾カスタマイズ
- スコアのサーバー保存・ランキング・アカウント機能
- PWA化・ネイティブアプリ化
