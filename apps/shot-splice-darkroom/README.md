# 暗室継ぎ足し台 — Shot Splice Darkroom

2回に分けて撮ったスクリーンショット（上半分・下半分）を、重なり領域を自動検出して1枚のシームレスな縦長画像に継ぎ足すツール。バックエンドなし、完全にブラウザ内で完結する（画像は外部に送信されない）。

このアプリは `app-factory` パイプラインによる自律生成プロトタイプです。

## できること

- 2枚の画像を選択 / ドラッグ&ドロップで読み込み（1枚目=上、2枚目=下）
- 重なり幅の自動検出（グレースケール化した行同士の差分が最小になる位置を、低解像度の粗探索→その周辺の高解像度再探索という2段階で探索する自前実装）
- 継ぎ目のドラッグ調整、数値入力、矢印キー（Shiftで10px単位）での微調整
- 上画像下端・下画像上端のクロップ（固定ヘッダー/フッター除去用）
- 重なり部分でどちらの画像を前面にするかのトグル
- 差分確認モード（重なりが完全に一致していれば真っ黒になる）
- 継ぎ目付近をなぞると拡大表示するルーペ
- 出力サイズ・重なり幅・照合スコアのリアルタイム表示
- 入れ替え / 全部クリア
- PNGとして書き出し

## スタイル方向

写真暗室・アナログ現像室。赤いセーフライトの薄暗さ、コンタクトシートやグリースペンシルの罫書きといった質感でまとめ、「位置合わせ」「差分確認」という機能を暗室でネガを重ねて照合する作業のメタファーとして扱っている。見出しに Oswald（工業的な現像機材のラベル風）、数値表示に Space Mono、手描きの注記・トーストに Caveat を使い分けている。

## 技術スタック

Vite + TypeScript（フレームワークなし）。画像処理（グレースケール変換、重なり探索、合成、差分描画）はすべて Canvas 2D APIを使った自前実装で、外部ライブラリに依存しない。

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 型チェック + 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果をローカルで確認
```

## Docker

静的サイトなので、マルチステージビルドで `nginx:alpine` が `dist/` を配信する。

```bash
docker build -t shot-splice-darkroom .
docker run --rm -p 8080:80 shot-splice-darkroom
# http://localhost:8080/ を開く
```

## デプロイ

完全クライアントサイド完結のため `deploy.json` は `{"pages": true}`。GitHub Pagesのサブパス配信に対応するため `vite.config.ts` の `base` は `'./'` に設定している。
