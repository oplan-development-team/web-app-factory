# Oscilloscope Synth — オシロスコープ・サウンドアート

円形のCRTスコープ画面に描いた軌跡の (x, y) 座標を、そのままステレオ波形として左右チャンネルに書き込み、Web Audio APIでリアルタイムに合成・再生する「逆方向のオシロスコープ・ミュージック」ツールです。鳴っている音の波形は、AnalyserNodeで取得してフォスファーグリーンの光跡として画面に再描画されるため、見た目と音が常に一致します。

本アプリは、New_Service_App の app-factory パイプライン（アイディア出しから動くプロトタイプまでを自律生成する仕組み）によって生成されたプロトタイプです。

## 遊び方

1. 中央の円形スコープ画面をドラッグ（またはタッチ）してフリーハンドで軌跡を描く、もしくは左パネルの図形スタンプ（円・星・三角・矩形・リサージュ曲線）をクリックして読み込む。
2. 描いた軌跡は自動的に512点の閉曲線としてリサンプリングされる。「SHARPNESS」ノブで角の鋭さ（＝倍音の量）を調整できる。角が鋭いほど倍音が増えてバズ音に、丸めるほど純音に近づく。
3. 右パネルの PLAY で再生。FREQUENCY（30〜600Hz）・VOLUME を調整すると再生中の音にリアルタイムに反映される。
4. UNDO で直前の操作を1手戻せる（CLEARも1手として扱われる）。CLEARで軌跡を消去できる。
5. EXPORT パネルから WAV（3秒ループ、16bit PCM）・PNG（1周期分の光跡スナップショット）・GIF（アフターグローの残光を2秒キャプチャしたループ）を書き出せる。

すべてブラウザ内で完結し、外部サーバーへのデータ送信は一切ありません。

## 技術スタック

- Vite + TypeScript（UIフレームワーク不使用）
- Web Audio API（`AudioBufferSourceNode` のループ再生 + `playbackRate` によるピッチ制御、`AnalyserNode` によるXY波形の可視化、`OfflineAudioContext` によるWAV書き出し）
- Canvas 2D API（円形スコープ描画、アフターグロー、スキャンライン/ビネット演出）
- WAVエンコードは自前実装（外部依存なし）。GIF書き出しのみ軽量ライブラリ `gif.js` を使用。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に静的サイトを出力
npm run preview  # ビルド結果をローカルで確認
```

## Docker

静的サイトを nginx で配信するマルチステージ構成です。

```bash
docker build -t oscilloscope-synth .
docker run --rm -p 8080:80 oscilloscope-synth
# http://localhost:8080 で確認
```

## スコープ外（このプロトタイプでは扱わない）

- マイク入力・既存音声ファイルの解析
- 複数レイヤー/トラックの重ね合わせ
- MIDI入出力
- リバーブ・ディレイ等の追加エフェクト
- クラウド保存・共有・ギャラリー機能
- セッションをまたいだ描画データの永続化
- 本格的なモバイル最適化（基本的なタッチ描画には対応するが、精密な描画操作を要するためデスクトップでの利用を主眼としている）
