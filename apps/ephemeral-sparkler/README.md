# 線香花火 — Ephemeral Sparkler

長押しで線香花火に火を灯し、蕾→牡丹→松葉→散り際と自前実装の物理で燃え尽きるまでを見守り、消えた瞬間の光跡だけを一枚のPNGとして持ち帰るプロトタイプです。

app-factoryパイプラインによる自律生成プロトタイプです（コンセプト立案からデザイン・実装・検証までエージェントが一括で行いました）。実機フィードバックを受けた修正パスで、向き・難易度・火花の描画・記念写真の露光を後述の通り調整しています。

## 遊び方

1. 画面上寄りの見えない判定エリア（捻り紙の持ち手側）を長押しすると火が灯ります。持ち手は画面上部、燃える玉と火花はその下に垂れ下がります（実物の線香花火と同じ向き）。
2. 押し続けている間だけ燃焼が進行します（合計約45秒、蕾→牡丹→松葉→散り際の4段階）。
3. 燃焼中は不定期に「風」が吹きます。持ち手の中でポインタを風向きと逆にそっとずらすと踏みとどまれますが、何もせず持ったままにしていると不安定度メーター（画面上部の細いゲージ）が満ちて、指を離していなくても早期に落ちてしまうことがあります。ただ長押しするだけでは最後まで灯し続けられません。
4. 指を離すと、その時点で失火して消えます。風に負けた場合も同様です。最後まで見届けると自然に燃え尽きます。
5. 消えた瞬間、直近約1.5秒分だけを短時間露光のように蓄積した一枚の光跡画像がプレビューされます。「記念写真として保存」でPNGとしてダウンロードできます（iOS Safari等では画像を長押しして保存するフォールバック導線を表示します）。
6. 「もう一度、灯す」で新しい花火に再挑戦できます。

保存・再現の手段はPNGダウンロードのみです。シミュレーション状態の保存や再生機能は、「その場限り」というコンセプト上、意図的に持たせていません。

## 技術構成

- Vite + TypeScript、素のCanvas 2D API（描画・パーティクルライブラリ非依存）
- パーティクル物理・燃焼曲線ロジックは `src/sparkler-physics.ts`、風/不安定度メーターのロジックは `src/wind.ts` にUI/描画コードから分離して実装
- 火花は単純な点描ブルームではなく、各パーティクルが直近数フレーム分の（揺らぎを加えた）軌跡を細い線として描く方式で、牡丹・松葉段階での「枝分かれする糸状の光」を表現（枝分かれ自体は元々の物理層が生成する子パーティクルをそのまま利用）
- リアルタイム描画用キャンバスとは別に、DOMに接続しないオフスクリーンキャンバスへ発光パーティクルを`globalCompositeOperation: 'lighter'`で蓄積して記念写真を作るが、無限蓄積ではなく指数減衰で古い光を消していく約1.5秒のローリング露光窓（`renderer.ts`の`AFTERGLOW_WINDOW_SECONDS`）にしてあり、燃焼全体を蓄積すると白飛びしてしまう問題を回避
- バックエンドなし、完全クライアントサイド完結

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果のプレビュー
```

## Docker

```bash
docker build -t ephemeral-sparkler .
docker run --rm -p 8080:80 ephemeral-sparkler
# http://localhost:8080/ で確認
```

## デプロイ

`deploy.json` で `pages: true` を指定しており、GitHub Pagesプレビュー対象です（`vite.config.ts` の `base: './'` によりサブパス配信に対応）。
