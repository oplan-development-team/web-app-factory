# Contour Portrait — 等高線ポートレート・ジェネレーター

写真の明暗を「標高値」に見立て、marching squares（[d3-contour](https://github.com/d3/d3-contour)）で
測量図・地形図風の等高線ポートレートを生成するクライアントサイド・ツール。人物・ペット・物、
どんな画像でも輝度分布ごと等高線化する（人物のみの自動切り抜きは行わない）。

app-factoryパイプラインによる自律生成プロトタイプ。

---

## 使い方

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # 型チェック + dist/ を生成（静的ホスティングにそのまま置ける）
npm run preview  # ビルド済み dist/ をローカルで確認
```

バックエンドは不要。画像のアップロードから等高線トレース・PNG/SVG書き出しまで、すべてブラウザ内で完結する
（リロードで状態は消える）。`base: './'` を設定しているのでサブディレクトリ配信でも動作する。

### Docker

```bash
docker build -t contour-portrait .
docker run --rm -p 8080:80 contour-portrait
# http://localhost:8080
```

ビルド済みの `dist/` を nginx で配信するだけのマルチステージ構成。

## 機能

- **入力**: JPEG / PNG / WebP をドラッグ&ドロップまたはファイル選択でアップロード（上限10MB）
- **処理パイプライン**: リサイズ（640×800の作業グリッド）→ グレースケール輝度マップ化 → 任意の平滑化（3パス簡易ガウスぼかし）→
  輝度を等間隔スライスし marching squares（d3-contour）で等高線パスを抽出 → SVGパスとして描画
- **パラメータ調整**（リアルタイムプレビュー、160msデバウンス）: 等高線の本数（5〜60本）・線の太さ・平滑化強度・階調反転
- **配色モード**: 単色（インク色 + 紙色プリセット/カスタム）／ 多色（標高帯ごとに色分けするハイプソメトリック・ティント。
  「古典的地形図配色」「ブループリント」「セピア」の3プリセット）
- **額装UI**: 四隅のトンボ（レジストレーション・マーク）、上辺・左辺の目盛り付きルーラー、下部の標高カラーランプ凡例
  （min/max値付き）、編集可能なタイトルラベル、日付・CI値（等高線間隔）の自動表示
- **書き出し**: 高解像度PNG（1x/2x/3x）とSVG（トレースしたベクターパスをそのまま出力、額装要素の有無を選択可）
- **エラーハンドリング**: 非対応形式・過大サイズのアップロードは理由と対処を明示して弾く

## スコープ外（意図的に持たない機能）

- 顔・物体の自動検出/セグメンテーション（背景ごと輝度で等高線化する）
- 複数画像のバッチ処理・アルバム・生成履歴・共有リンク
- サーバー保存・アカウント機能
- AIによるエッジ検出・スタイル変換
- 画像のトリミング・回転・明るさ補正などの高度な編集、Undo履歴

## 技術選定

| 領域 | 選定 | 理由 |
|------|------|------|
| ビルド | Vite + TypeScript（フレームワーク非依存） | 状態がシンプルなSVGポスター1枚の描画に留まるため、React等を挟まず素のDOM操作で十分 |
| 等高線抽出 | [`d3-contour`](https://github.com/d3/d3-contour)（marching squares） | 幾何学的トレースの信頼性を担保するため自前実装せず専用ライブラリを利用 |
| 画像処理 | Canvas 2D API | グレースケール変換・輝度取得・3パス簡易ガウスぼかしをブラウザ標準APIのみで完結 |
| 描画 | 手書き SVG | プレビューに使うSVGノードをそのままシリアライズ／ラスタライズするため、プレビューと書き出しが構造的にずれない |
| フォント | `@fontsource`（Inter / IBM Plex Mono）で同梱 | 外部リクエストなしで完結させるため |

### コード構成

```
src/lib/
  image.ts      アップロード検証・画像デコード・輝度グリッド化・ぼかし
  contour.ts    輝度グリッド → 閾値スライス → d3-contourでのトレース
  palette.ts    ハイプソメトリック配色の補間
  poster.ts     トレース結果 + 設定 → 額装SVG（ルーラー/トンボ/凡例/タイトルブロック含む）を手組み
  export.ts     SVGのシリアライズ・PNGラスタライズ・ダウンロード
  state.ts      アプリ状態（設定・処理状態）とデバウンス再計算
src/components/
  panel.ts      左の操作パネル（01 SOURCE〜05 EXPORT の5セクション）
  canvas.ts      右のプレビュー（空状態・ローディング・ドラッグ&ドロップ）
```

## デザイン方針

スイス（インターナショナルタイポグラフィックスタイル）を測量図・技術製図寄りに具体化。
紙色（`#F5F3EE`）に近いオフホワイト背景とチャコールインク（`#1A1A1A`）を基調とし、
UIラベルはトラッキングを広げた全て大文字のグロテスク体（Inter）、数値情報（本数・太さ・座標・日付・CI値）は
すべて IBM Plex Mono に統一して「実測データ」感を出している。角丸・ドロップシャドウ・グラデーション背景は使わず、
罫線はすべて1pxのシャープなヘアラインで統一した。

## 既知の制約

- 完全クライアントサイド完結のため、生成物の保存・共有はブラウザのダウンロード機能に依存する（リロードで状態は消える）
- 4Kクラスの3x PNG書き出しは端末によって数百ms〜数秒かかる（書き出し中はボタンを無効化）
- 網羅的な自動テストは持たない（プロトタイプのため。型チェックは `npm run build` に組み込み済み）
