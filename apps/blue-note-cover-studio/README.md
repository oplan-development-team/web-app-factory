# Blue Note Cover Studio

架空のバンド名・アルバム名から、Reid Miles期ブルーノート・レコードのグラフィックデザイン規範（斜めデュオトーン写真ブロック・極端な字間タイポグラフィ・限定2色配色）をルールとしてプログラム化し、アルバムジャケットを自動生成するツールです。

> **本アプリは app-factory パイプラインによって自律生成されたプロトタイプです。**

## 特徴

- **写真デュオトーンモード**: アップロードした写真を、自前実装のピクセル処理（グレースケール化 → しきい値によるポスタライズ）で2階調化し、選択したパレットのハイライト色・シャドウ色にマッピングします。ライブラリのCanvasフィルタは使用していません。
- **幾何学のみモード**: 写真を使わず、パレットの2色だけでテンプレート固有の色面構成（斜め帯・非対称分割・円）を生成します。
- **レイアウトテンプレート4種**: ダイアゴナル・デュオトーン／タイポグラフィ・オンリー／サークル・インセット／グリッド分割。いずれも実在のブルーノート意匠を規則として実装しています。
- **配色プリセット6種**: ネイビー×クリーム、オレンジ×ブラック、ティール×オフホワイト、マスタード×チャコール、ワインレッド×クリーム、オリーブ×ブラック。自由なカラーピッカーはあえて提供していません。
- **ランダマイズ**: テキストはそのまま、テンプレート・パレット・クロップ・傾き角度だけをシャッフルしてバリエーションを探索できます。
- 画像アップロードを含め、すべての処理はブラウザ内で完結します。サーバーへの送信は一切行いません。
- 実在の「BLUE NOTE」ロゴ・書体は再現していません（隅に自動生成されるカタログ番号風の表記もジェネリックなものです）。

## デザインの方向性

ツール自体のUIも、生成物のルーツであるスイス（インターナショナル・タイポグラフィ・スタイル）— グリッドベースの非対称レイアウト、紙色(paper)・インク色(ink)・赤(red)の限定配色、コンデンス・グロテスク体（Barlow Condensed / Anton）、罫線とセクション番号付き見出し — で統一し、ツールのUIと生成されるジャケットの間に一貫した世界観を持たせています。

## 技術スタック

- Vite + TypeScript（バックエンド不要、完全クライアントサイド）
- 画像処理・レイアウト合成: HTML5 Canvas 2D API（自前実装）
- タイポグラフィ: Google Fonts由来のコンデンス・グロテスク体を `@fontsource` 経由でセルフホスト（Anton / Oswald / Bebas Neue / Barlow Condensed）

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果のプレビュー
```

## Docker

```bash
docker build -t blue-note-cover-studio .
docker run --rm -p 8080:80 blue-note-cover-studio
# http://localhost:8080/ で確認
```

静的サイトのみで完結するため、マルチステージビルド（Node で `npm run build` → `nginx:alpine` で `dist/` を配信）を採用しています。
