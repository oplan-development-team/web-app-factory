# Graphic Score Studio

自由に描いた線や好きな写真を、20世紀前衛音楽の「図形楽譜」風ポスターに変換し、左から右へ自動でなぞりながらWeb Audioのオシレーター合成でアンビエントに鳴らすツール。

> このアプリは app-factory パイプラインによって自律生成されたプロトタイプです。

## 使い方

1. `01 INPUT MODE` で「HAND-DRAW」（手描き）または「IMAGE」（画像アップロード）を選ぶ。両モードは同じ版面上のインクを共有するため、切り替えても既存の描画は消えない（画像を再アップロードして既存画像を置き換える場合のみ確認ダイアログが出る）。
2. 手描きモードでは版面（オフホワイトの用紙部分）の中をドラッグして線を描く。ペンの太さ・不透明度は左のスライダーで調整。Undo / Clear Plate で取り消し・全消去できる（全消去は確認ダイアログ付き）。
3. 画像モードでは画像をアップロードし、しきい値スライダーで二値化の強さを調整する。しきい値より暗い部分がインクになる。
4. `03 SCALE` でペンタトニック／ホールトーンを、`04 DURATION` で演奏時間（20/40/80秒）を選ぶ。
5. `05 TRANSPORT` の PLAY で、シグナルレッドのプレイヘッドが左から右へ一定速度で走査し、通過したインクをWeb Audioのオシレーターで鳴らす。Y位置→ピッチ、線の太さ→音量、インクの密度→音色（サイン/三角/ノコギリ波）にマッピングされる（詳細は版面下部の凡例を参照）。一時停止・停止・ループに対応。
6. `06 TITLE` でタイトルを編集できる（未入力なら自動生成のタイトルのまま）。
7. `07 EXPORT` で、版面全体（罫線・トンボ・凡例込み）をPNG（高解像度ラスタ）またはSVG（手描きはベクターパス、画像はセルのベクター化）として書き出せる。

版面が空の状態では、再生・書き出しボタンは無効化される。

## ローカル起動

```bash
npm install
npm run dev      # http://localhost:5173 で開発サーバー
npm run build    # dist/ に本番ビルド
npm run preview  # dist/ をローカルでプレビュー
```

## Docker

```bash
docker build -t graphic-score-studio .
docker run --rm -p 8080:80 graphic-score-studio
# http://localhost:8080
```

## 技術スタック

- Vite + TypeScript（フレームワークなし、素のDOM操作）
- 描画・ポスター合成: Canvas 2D API（手描きストローク・画像しきい値化・ポスター全体のレンダリングを自前実装）
- 音声合成: ネイティブ Web Audio API（OscillatorNode / GainNode / DelayNode / DynamicsCompressorNode のみ。サンプル音源・外部音源API・AI生成音は不使用）
- SVG書き出し: 手組みのSVG文字列生成（外部の描画/画像処理/音楽理論ライブラリは不使用）
- バックエンドなし、完全クライアントサイド完結

## 制約・スコープ外

- ペンは単色黒インクのみ（グラフィックスコアの単色性を保つ意図的な制約）
- スケールはペンタトニック／ホールトーンの2プリセットのみ（カスタムスケール編集なし）
- サンプル音源・録音音声・MIDI書き出し・複数トラック編集・ログイン/保存/ギャラリー機能は対象外
- PCファースト。モバイルは単指タップ&ドラッグでの基本描画・閲覧が壊れずに動作する最低限の対応（操作パネルはキャンバスを覆わず、上部にスクロール可能な状態で表示される）
