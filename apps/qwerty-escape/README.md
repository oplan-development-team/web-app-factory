# QWERTY ESCAPE

物理キーボードの配列そのものを謎の盤面にした脱出ゲーム。文字の「意味」ではなく、キーの「空間的な形」（三角形・対角線・環・矢印…）を読み解いて、9個の南京錠を1つずつ開錠していく。

> 本アプリは app-factory パイプライン（`.claude/workflows/app-factory.js`）による自律生成プロトタイプです。

## 遊び方

1. `解錠を始める` で開始。
2. 各問題のフレーバーテキストが示す「形」を読み解き、対象のキーを入力する。
   - **同時押し**モード: 物理キーボードなら対象キーを同時に押す。画面上のキーボードをクリック/タップする場合は、対象キーを順にクリックしてトグル選択し、正解の組が揃った時点で成立する。
   - **なぞり（順序あり）**モード: 対象キーを1つずつ、正しい順番で押す/クリックする。途中で違うキーを押すと最初からやり直しになる（ペナルティなし、即再挑戦可）。
3. 正解すると錠前が開き、`次へ`（最終問題は `金庫を開ける`）で次の問題へ進む。
4. 行き詰まったら `ヒント` で対象キーをうっすら光らせる。
5. `RESET` でいつでも最初からやり直せる（確認ダイアログあり、誤操作防止）。
6. US/JIS配列の切り替えはキーボード図の見た目にのみ影響する（正解キーは両配列共通のアルファベット主要ブロックに限定）。切り替えると進行中の問題の入力は初期化されるが、解いた錠前の記録は保持される。

物理キーボードでのプレイを推奨。物理キーボードが無い場合は画面上のキーボードをタップして代替プレイできる（タッチのみのデバイスを検出した場合はバナーで案内）。

## 技術スタック

- Vite + TypeScript（素のDOM操作。外部UI/状態管理ライブラリは不使用）
- 判定は `KeyboardEvent.code`（物理キー位置）ベース。OS側の入力言語設定に依存しない
- キーボード配列（行・列・行オフセット）は `src/data/keyboard.ts` にハードコードされたデータテーブル。外部の配列/物理キーボードライブラリは不使用
- 効果音はすべて Web Audio API（oscillator + gain）で生成。音声ファイルは使用しない
- フォントは Google Fonts の `<link>` 読み込みのみ（Space Grotesk / IBM Plex Mono / Zen Kaku Gothic New）
- バックエンド不要、完全クライアントサイド完結

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果のプレビュー
```

## Docker

```bash
docker build -t qwerty-escape .
docker run --rm -p 8080:80 qwerty-escape
# http://localhost:8080/
```
