# 標本図鑑プレート・ジェネレーター

手元の写真をSobelエッジ検出とクロスハッチングで銅版画風の線画に変換し、
ラテン語風ラベル・図版番号・目盛り付きスケールバー・経年紙テクスチャを添えた
19世紀博物誌図版（natural history plate）としてPNG/SVGで書き出せるジェネレーター。

> **本アプリは app-factory パイプラインによって要件定義から実装まで自律生成されたプロトタイプです。**

---

## 使い方

```bash
npm install
npm run dev     # 開発サーバー（http://localhost:5173 など）
npm run build   # dist/ に静的ファイルを生成
npm run preview # ビルド結果をローカルで確認
```

バックエンドは不要。`dist/` を任意の静的ホストに置くだけで動く。

1. 標本にしたい写真をドラッグ＆ドロップ、またはクリックして選択（JPEG / PNG / WebP・1枚のみ）
2. 右側のパネルでエングレービング（エッジのしきい値・ハッチング密度・線の濃さ・反転）、
   経年紙の強さ、プレート番号、学名風キャプション、スケールバー（単位と実寸値）を調整する
3. プレビューは常に最終見た目（線画＋紙テクスチャ＋罫線＋文字＋スケールバー）を合成表示する
4. 「PNGで書き出す」または「SVGで書き出す」でダウンロード

### Docker

```bash
docker build -t specimen-plate-generator .
docker run --rm -p 8080:80 specimen-plate-generator
# http://localhost:8080
```

ビルド済みの `dist/` を nginx で配信するだけのマルチステージ構成。

## プライバシー

アップロードした画像は**端末の外に一切送信されない**。

- サーバーを持たない純クライアントアプリ（Vite + TypeScript、フレームワーク非依存）
- エッジ検出・クロスハッチング・紙テクスチャ生成はすべて Canvas 2D API でブラウザ内完結
- PNG/SVGの書き出しもその場で生成するのみ（外部APIや画像処理ライブラリは不使用）

---

## 技術選定

| 領域 | 選定 | 理由 |
|------|------|------|
| ビルド | Vite + TypeScript（vanilla-ts） | フレームワークの状態管理が要らない規模。DOM操作で完結する |
| 画像処理 | Canvas 2D API（自前実装のSobel＋クロスハッチング） | OpenCV.js等の外部画像処理ライブラリ・APIに依存しない方針のため |
| 紙テクスチャ | Canvas 2D API＋シード付き疑似乱数（mulberry32） | 外部画像アセットを使わずプロシージャルに生成する要件のため。シード固定で位置は毎回同じにし、スライダー操作時のチラつきを防ぐ |
| SVG書き出し | 文字列組み立てによる直接生成 | 罫線・文字・スケールバーは真のベクター要素、線画は生成したラスターを`<image>`として埋め込む。ビットマップの完全なベクタートレース（potrace等）は行わない |
| フォント | `@fontsource/eb-garamond`, `@fontsource/jetbrains-mono`（セルフホスト） | 外部CDNへのリクエストを発生させず、プライバシー方針と整合させるため |

### 画像処理パイプライン（`src/lib/`）

```
sobel.ts          グレースケール化＋Sobelフィルタによる勾配強度の算出
engraving.ts      輝度勾配＋トーンをもとに、セル単位でクロスハッチングの
                  Path2Dレイヤー（斜め×2・横・縦）を組み立てて線画化する
paperTexture.ts   下地グラデーション＋粒状ノイズ＋フォクシング染みを描く
                  （フォクシングの位置はシード固定、強度スライダーは
                  量と濃さだけを変える＝再描画してもチラつかない）
smallCaps.ts      Canvas 2Dにはfont-variant: small-capsが無いため、
                  小文字を縮小した大文字グリフとして自前描画する擬似スモールキャップス
layout.ts         プレートのジオメトリ定数（罫線・キャプション・プレート番号・
                  スケールバーの座標）。Canvasプレビュー/PNG書き出しとSVG書き出しの
                  両方がこの座標系を共有し、見た目が一致するようにしている
plateRenderer.ts  上記を合成してプレビュー/PNG用のCanvasに描画する
svgExport.ts      同じ座標系で罫線・文字・スケールバーをSVGネイティブ要素として、
                  線画＋紙テクスチャは<image>として埋め込んだSVG文字列を組み立てる
```

エッジ検出のしきい値・ハッチング密度・線の濃さ・反転トグルの変更は線画の再計算
（150msデバウンス、処理中はローディングオーバーレイを表示）を伴う一方、紙の経年感・
プレート番号・キャプション・スケールバーの変更は既存の線画を再利用した合成のみなので
即時反映される。

## デザイン方針

**エディトリアル ― 19世紀博物誌図版フォーマットの再現**を実装前に具体化した。

- **配色**：プレート（図版）そのものは経年紙のクリーム（`#ecdfc0`系）とインク黒
  （`#241a10`、純黒ではなく温かみのある焦茶）、罫線の合間に錆色（`#8a4a26`）を
  差し色として使うのみに絞った。UIの操作パネルは図版と混同されないよう、暗い胡桃材の
  ような焦茶（`#241a10`〜`#2b2014`）と真鍮色（`#a97c3f`/`#cf9f56`）を使った別トーンとし、
  ページ全体の背景はさらに暗い「展示壁」トーン（`#14100a`）にして、プレートが
  ケースの中の展示物のように浮かび上がるようにした
- **タイポグラフィ**：本文・ラベルは EB Garamond（セリフ、19世紀の活字を思わせる
  Garamond系）。学名風キャプションはイタリック＋擬似スモールキャップス（Canvas 2D は
  font-variant: small-capsを解釈しないため、小文字を縮小した大文字として自前描画）。
  プレート番号は非斜体でレタースペースを広く取り、キャプションと役割の違いを
  タイポグラフィで示している。操作パネルの数値読み出し・セクション見出しには
  JetBrains Mono を使い、「計測器」のような性格を持たせて図版本体の書体と区別した
- **レイアウト**：実物の博物誌図版の型（二重罫線の枠、下部中央のイタリック体キャプション、
  左下のプレート番号、右下の目盛り付きスケールバー）を厳密に踏襲。線画の周囲には
  実物の銅版画に見られる「プレートマーク（版の凹み）」を細い罫で表現し、装飾的な
  トーンではなく実物の図版デザインの再現を優先した

## 既知の制約 / スコープ外

- ビットマップから真のベクターパスへのトレース（potrace等）は行わない。SVG書き出しの
  線画部分は常に埋め込みラスター
- 複数標本を1枚に並べる合成レイアウトや、複数ページのブックレット出力は非対応
- ラテン語学名の自動生成・AIによる種の同定は行わない（キャプションは常に手入力）
- 複数枚アップロード・バッチ処理・生成履歴の保存・アカウント機能は非対応
- 枠デザイン/カラーテーマの切り替えは無し（経年紙×セピアインクの単一デザインに固定）
- 印刷用CMYK変換・トンボ/塗り足し等のプリプレス対応は無し（画面用RGBのPNG/SVGのみ）
- 取り消し/やり直し（Undo/Redo）や編集履歴、レイヤー機能は無し
