# 枯山水コンポーザー（Karesansui Composer）

白紙の砂庭に石を置くと、石を避けながら砂紋（箒目）がその周りに輪をつくり、石と石の間を縫うように自動で流れて生成される禅庭シミュレーター。完成した庭園はPNG（ポスター体裁）またはSVG（ベクター）として書き出せます。

> このアプリは **app-factory パイプライン**（New_Service_App の自律プロトタイピング・ワークフロー）によって自律生成されたプロトタイプです。

## 使い方

1. `npm install`
2. `npm run dev` でローカル起動し、ブラウザで開く
3. キャンバス（庭園エリア）をクリック／タップして石を配置する
4. 石をドラッグして移動、選択中は石の上に出るミニツールバーでサイズ調整・削除ができる
5. 右のギャラリーラベル風パネルで、用紙比率・砂紋パラメータ（線の間隔／石への寄り添い／流れの向き／うねりの幅・周期）を調整する
6. 「PNG（ポスター）を書き出す」「SVG（版下）を書き出す」で庭園を保存する

### キーボード操作

- `Ctrl+Z`（または「元に戻す」ボタン）: 直近1手を取り消す（配置・移動・削除のいずれか）
- `Delete` / `Backspace`: 選択中の石を削除する

## 技術構成

- Vite + TypeScript（フレームワークなし）。描画は Canvas 2D API
- 砂紋の生成: 各石の中心・半径から導く距離場をもとに、石に近いほど「その石を中心とした同心円の接線方向」、遠いほど「ベース方向（角度調整可）」へ滑らかにブレンドするベクトル場を自前実装し、等間隔の種点から RK4 で数値積分してストリームラインを生成。2つの石が近接すると両者の同心円影響が重なり合成され、石と石の間を筋が縫うように流れる挙動が自然に生じる
- SVG書き出し用のパスシリアライズも自前実装（外部シミュレーションライブラリは不使用）
- 永続化なし（リロードで状態は初期化される。保存・共有URL・アカウント機能は持たない）
- フォント: `@fontsource/shippori-mincho`（タイトル）、`@fontsource/zen-kaku-gothic-new`（UIラベル）

## ビルド・確認

```bash
npm install
npm run build     # tsc --noEmit && vite build。dist/ に静的サイト一式を出力
npm run preview   # ビルド結果をローカルで確認
```

## Docker

静的サイトのため、マルチステージビルド（build → nginx:alpine配信）で構成しています。

```bash
docker build -t karesansui-composer .
docker run --rm -p 8080:80 karesansui-composer
# http://localhost:8080 で確認
```

## デプロイ

`vite.config.ts` で `base: './'` を設定しており、`deploy.json`（`{"pages": true}`）により GitHub Pages プレビュー対象です。

## スコープ外（意図的に対象外）

- 砂紋ラインの手描き・手直し機能（石の配置から自動生成される、という差別化ポイントのため）
- 石以外の庭園要素（苔・生垣・橋・灯篭・植栽など）
- 真のCFD/流体力学シミュレーション（視覚効果としての近似ベクトル場）
- AIによる石配置の自動最適化
- ログイン・保存ギャラリー・共有リンク・状態の永続化
- 多言語対応（UIは日本語固定）
- 詳細なモバイル専用UI（基本的なタップ配置・ドラッグ移動のみ対応）
