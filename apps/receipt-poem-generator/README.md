# レシート詩集ジェネレーター（receipt-poem-generator）

品名・数量・金額を入力すると、本物の感熱紙レシートそっくりの見た目で印字され、品目の並びがそのまま「見つけた詩（found poem）」として立ち上がる、Canvas書き出し対応のクライアント完結ツールです。

> このアプリは app-factory パイプラインによる自律生成プロトタイプです。

## できること

- 品名・数量・単価を1行とする品目を自由に追加・削除・並べ替え（上下ボタン）できます。行の順序がそのまま詩の行順になります。
- 店名・日付時刻をヘッダーとして編集できます（日付時刻は初期値として現在時刻が入り、手動編集も可能）。
- 小計・合計は品目から自動計算されます。合計欄のラベルは「本日の儚さ」「本日の後悔」など詩的な言い回しの中からランダムに選ばれ、シャッフルボタンでいつでも引き直せます。フッターの結びの一言も同様にプリセットから選べます。
- レシートプレビューは日本語ドットマトリクスフォント（DotGothic16）・ミシン目・疑似バーコード・レシート番号など、感熱紙レシートらしいディテールでリアルタイム更新されます。品目の追加・削除・並べ替えや詩モード切り替え時には、上から刷り上がるような印字アニメーションが入ります。
- 「詩として読む」ボタンで、数量・金額を隠し、品名だけを縦一列の詩として大きく見せるモードに切り替えられます（本アイディアの核となる体験です）。
- 表示中のレシート（通常表示／詩モードいずれも）を Canvas 2D で高解像度（3倍相当）の縦長 PNG として書き出し、ダウンロードできます。
- 入力・生成・画像書き出しはすべてブラウザ内で完結し、外部にデータは送信されません。
- スマートフォン幅では入力パネルとプレビューが縦に積まれ、狭幅でも操作できます。
- 品目が空の状態では画像書き出しボタンが無効化され、ガイド文が表示されます。

## 技術スタック

Vite + TypeScript（フレームワークなしのバニラ構成）。状態管理ライブラリは使わず、DOM操作で完結させています。日本語ドットマトリクスフォント（DotGothic16）と明朝体（Shippori Mincho）は Google Fonts CDN 経由で読み込んでいます（プロトタイプ段階につき許容。本実装移行時は自前ホスティング化を検討してください）。

## デザイン方針

エディトリアル（雑誌・文芸誌のレイアウトを下敷きにした「展示物としてのレシート」演出）。左は原稿用紙のようなドット罫の入力パネル（マニュスクリプト風UI）、右は生成されたレシートを写真のように貼り付けた「展示物」として見せています（わずかな傾き・柔らかい落ち影・美術館キャプション風の一行）。配色は生成り紙の背景（`#F6F1E4`系）に墨色のテキスト、差し色は感熱紙インクを思わせる朱（`#C23B22`）を合計欄などに限定使用しています。見出し・キャプションに明朝体（Shippori Mincho）、レシート本体に日本語ドットマトリクスフォント（DotGothic16）を使い、この2書体の対比をデザインの軸にしています。

## セットアップ・起動

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # dist/ に静的ビルドを出力
npm run preview   # ビルド結果をローカルでプレビュー
```

## Dockerでの起動

```bash
docker build -t receipt-poem-generator .
docker run --rm -p 8080:80 receipt-poem-generator
# http://localhost:8080 で確認できます
```

## スコープ外（このプロトタイプでは対応していないこと）

- 保存・共有機能（URL共有・クラウド保存・SNS連携）。画像はローカルダウンロードのみです。
- 複数レシートの履歴管理・一覧化。常に単一の編集中レシートのみを扱います。
- レシート画像やアプリ連携によるOCR自動読み取り。品目は手入力のみです。
- 日本語以外の多言語対応、ユーザーアカウント・ログイン機能、PDF書き出し。
