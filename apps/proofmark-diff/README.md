# 校正記号diffビューア (Proofmark Diff)

改稿前後の2つのテキストを貼り付けると、単なる色分けハイライトではなく、紙の校正で実際に使われる校正記号——**削除（トルツメ）**・**挿入（キャレット）**・**置換（ルビ風訂正注記）**・**移動（揺らぎのある矢印）**——の見た目で差分を可視化するツールです。

> このアプリは `app-factory` 自律プロトタイピング・パイプラインによって生成されたプロトタイプです。

## 特徴

- **外部diffライブラリ不使用**: Myers差分法（O(ND)アルゴリズム）を自前実装。トークン化は文字単位が基本で、連続する半角英数字は1トークンにまとめる。単語単位モードにも切り替え可能。
- **移動検出（ヒューリスティック）**: 削除ブロックと挿入ブロックのテキストが完全一致し、かつ4トークン以上の場合、単純な削除+挿入ではなく「移動」ペアとして再分類する。文字レベル差分の性質上、周辺テキストと共通文字が多いと検出できないことがある（ヒューリスティックとして仕様通りの割り切り）。
- **校正記号はすべてSVGオーバーレイで描画**: 本文スパンの `getBoundingClientRect` / `getClientRects` から位置を取得し、手描き風の揺らぎ（SVGフィルタ + 決定論的な擬似乱数によるジッター）を加えて描画。`ResizeObserver` でウィンドウリサイズ時に再配置する。
- **PNG書き出し**: `html2canvas` 等は使わず、Canvas 2Dへの手動描画による自前実装（差分セグメントのデータから独立して再レイアウト・再描画する）。
- **完全クライアントサイド完結**: 入力テキストはどこにも送信・保存されない。

## スタイル方向

エディトリアル（活版印刷の校正刷り・原稿用紙の赤入れ原稿風）。生成りの紙色台紙、墨色インクの明朝体本文、朱色一色の校正記号語彙、手書き風フォント（Klee One）による注記、モノスペース（IBM Plex Mono）のUIラベル。詳細な配色・タイポグラフィ・レイアウト判断は実装時に `frontend-design` スキルで具体化した。

## 技術スタック

Vite + TypeScript（フレームワーク非依存のバニラDOM実装）。理由: 差分アルゴリズムとSVGオーバーレイの位置追従描画が主眼であり、UIフレームワークの状態管理は不要と判断したため。

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 本番ビルド（dist/ に静的サイト一式を出力）
npm run preview   # ビルド結果をローカルで確認
```

## Dockerでの起動

```bash
docker build -t proofmark-diff .
docker run --rm -p 8080:80 proofmark-diff
# http://localhost:8080 で確認
```

静的サイト（バックエンド不要）なので、マルチステージビルド（Vite build → `nginx:alpine` が `dist/` を配信）で構成している。

## スコープ外（プロトタイプとして意図的に外した機能）

- 原稿用紙の厳密な文字グリッド組版への本文流し込み
- Word/PDFなどファイルアップロード・パース
- 3つ以上のバージョン間比較・変更履歴管理
- 行単位の差分モード
- 汎用最適ブロック移動アルゴリズム
- 印刷用の正確な用紙サイズ指定を伴うPDF書き出し
- ログイン・保存・クラウド同期
- 自動言語判定・スペルチェック
- モバイルタッチでの編集最適化（デスクトップ〜タブレット幅を主眼とする）
