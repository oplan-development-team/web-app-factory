# レシート詩集ポスター（Receipt Poetry Scroll）

買い物リスト・やることリストなど、行区切りのテキストを貼るだけで、行ごとに文字数・語感から自動で「それっぽい値段」がつき、感熱紙ロールを模した縦長ポスターの詩として1枚のPNGに刷り上がるツールです。

> このアプリは app-factory パイプラインによる自律生成プロトタイプです。

## 遊び方

1. 左のテキストエリアに、買い物リスト・今日食べたもの・やることリストなど、行区切りのテキストを貼り付ける（空行は自動でスキップされます）。「サンプルを試す」ボタンでも試せます。
2. 右側（スマホでは下部）に、行ごとに自動で値段のついたレシート風ポスターがリアルタイムでプレビューされます。
   - 各行のテキストからハッシュ＋乱数シードで決定的に値段が算出されるため、同じテキストなら基本的に同じ値段になります。
   - 「値段を引き直す」ボタンでシードを変え、全体をシャッフルし直せます（時々「本日の特売」演出で取り消し線付きの値引き表示が混じります）。
3. 店名は自動生成された「それっぽい謎の店名」がデフォルトで入りますが、自由に書き換えられます。「店名を生成」ボタンで再生成もできます。
4. 合計欄のラベル（「本日の散財指数」など）も、値段の引き直しと連動してランダムに変わります。
5. 「PNGで刷り上げる」ボタンで、ちぎれた縁を持つ縦長のレシートポスターを1枚のPNG画像としてダウンロードできます。

入力・値段生成・画像書き出しはすべてブラウザ内で完結し、外部にデータを送信しません。

## デザイン方針

ダークラグジュアリーなギャラリー展示ケースをイメージした背景の中央に、スポットライトを浴びた生成り色の感熱紙ロールを配置しています。UIクロム（背景・パネル・ボタン）は漆黒〜チャコールでまとめ、シャンパンゴールド（`#C9A34E`系）は「値段を引き直す」ボタン・バーコードのインク・合計欄の罫線・フォーカスリングなど"特別な操作・注目させたい要素"にのみ使用しています。

- 店名タイトル: Zen Old Mincho / Cormorant（上品な和欧混植セリフ体）
- レシート本体（品名・値段）: DotGothic16（和文ドットマトリクス風フォント）

「高級店の値札」と「機械印字」のギャップで、笑いと洗練を両立させることを狙っています。

## 技術スタック

Vite + TypeScript（フレームワークなし、状態管理ライブラリなし）。ポスターのPNG書き出しは Canvas 2D API で行っています。日本語フォント（Zen Old Mincho / Cormorant / DotGothic16）は Google Fonts CDN 経由で読み込んでいます（プロトタイプ段階として許容。本実装移行時は自前ホスティング化を検討）。バックエンドなし、完全クライアントサイド完結です。

## 開発

```bash
npm install
npm run dev       # 開発サーバー起動
npm run build     # 本番ビルド（dist/ に静的ファイル一式を出力）
npm run preview   # ビルド済み dist/ をローカルで確認
```

## Docker

静的サイトとして nginx で配信するマルチステージ構成です。

```bash
docker build -t receipt-poetry-scroll .
docker run --rm -p 8080:80 receipt-poetry-scroll
# http://localhost:8080 で確認
```

## スコープ外（意図的に実装していないもの）

- 品名・数量・単価の手動入力（`apps/receipt-poem-generator` が担う領域）
- 行の並べ替え・個別編集UI
- 複数ポスターの保存・履歴管理・クラウド共有・SNS直接投稿連携
- アカウント・ログイン機能
- PNG以外の書き出し形式（PDF/SVG等）
- 日本語以外のUI多言語ローカライズ
- レシート画像のOCR取り込み
