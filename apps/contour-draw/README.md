# Contour Draw — 等高線ドローイング

マウス/タッチで自由に描いた線の「密度」をスカラー高さ場に変換し、marching squares を自前実装で走らせて等高線を自動生成する、測量原図風のポスターメーカーです。線が重なる・往復する・円を描くほど地形が盛り上がり、5本ごとの計曲線には架空の標高ラベルが挿入されます。

本プロトタイプは **app-factory パイプラインによる自律生成プロトタイプ** です（アイディア発想〜デザイン方針決定〜実装まで一貫してエージェントが自律的に行いました）。

## 特徴

- Canvas 2D 上のフリーハンド描画（Pointer Events）。ストロークの経路に沿ってソフトな円形カーネルで密度を加算堆積
- 解像度約160×可変のグリッド上のスカラー場を、描画のたびに `requestAnimationFrame` で間引きながら増分更新
- marching squares を外部ライブラリなしで自前実装し、しきい値ごとの等高線ポリラインを抽出・連結
- 5本ごとの計曲線（太線・標高ラベル付き）と主曲線（細線）を描き分け
- タイトル・副題（座標風テキスト）・スケールバー・方位記号・ティックマーク付きネートライン枠の表示/非表示を個別に切り替え可能
- 配色プリセット3種（藍図 Blueprint / 測量原図 Survey Buff / モノクローム Ink）
- ブラシ半径・密度強さのスライダー、全消去、直近20手までの Undo
- 用紙比率（A4縦 / A3縦 / 正方形）を選択可能
- PNG（キャンバス解像度の2倍）・SVG（等高線パス・ラベル・枠をベクターで含む）の両形式で書き出し

## デザイン方針

ダークラグジュアリー×測量原図（ブループリント意匠）。背景は深いインク紺、線は白金/真鍮色。タイトルは彫刻プレート風の広い字間のセリフ体（Cormorant）、標高・座標・スケール表記はスタンプ風モノスペース（IBM Plex Mono）。極細ヘアラインのネートライン枠に真鍮色のティックマークとコンパス記号を配し、額装できる「高級測量原図」の重みを狙っています。

## 技術スタック

Vite + TypeScript（フレームワークなし）。描画・スカラー場管理は Canvas 2D API、marching squares と SVG 組み立ては外部ライブラリに依存せず自前実装しています。状態管理はモジュール変数レベルで完結させています。

## 開発・起動

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 型チェック + 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果のプレビュー
```

## Docker

```bash
docker build -t contour-draw .
docker run --rm -p 8080:80 contour-draw
# http://localhost:8080 で確認
```

静的サイト（バックエンドなし）のため、マルチステージビルドで `dist/` を `nginx:alpine` が配信します。

## プロトタイプゆえの割り切り

- 実世界の地形・GPSデータは扱いません。あくまで手描きから生成する抽象的な創作ポスターです
- Undo は直近20手まで。それ以降の巻き戻しは Clear（全消去）のみです
- 用紙サイズを切り替えるとキャンバス解像度（グリッド）が変わるため、描画内容はリセットされます
- 等高線ラベルの衝突回避は簡易実装です（本格製図ソフト水準の自動回り込みは行いません）
