# DEPARTURES — Deadline Departure Board

複数の締切をローカルに登録し、1970〜80年代の空港・駅の Solari 式スプリットフラップ発着案内板のように、残り時間とステータスを「めくって」表示するカウントダウンボード。

> これは app-factory パイプラインによって自律生成されたプロトタイプです。

## 特徴

- 締切を追加すると、残り時間の昇順で自動ソートされ、行ごとにタイトル・残り時間・締切日・ステータスがフラップ表示される
- ステータスは `SCHEDULED`（7日超）→ `BOARDING`（7日以内）→ `FINAL CALL`（24時間以内）→ `DEPARTED`（超過）の4段階で、閾値をまたいだ瞬間にだけフラップがめくれる（常時アニメーションはしない）
- `DEPARTED` になった行は一定時間表示された後、フラップが空白にめくれてリストから消え、保存データからも削除される
- データはブラウザの `localStorage` にのみ保存される（サーバー・アカウントなし）
- `prefers-reduced-motion` を尊重し、有効な場合はフラップ回転を省略して瞬時に値が切り替わる

## スタイル方向

レトロフューチャリズム（Solari式空港案内板の再現）。近黒〜チャコールの筐体にオフホワイトの文字を載せた個別フラップタイル、トラッキングを効かせたコンデンスド・グロテスク書体（Oswald、フォールバックは Arial Narrow系）、ステータスラベルとライブ時計にアンバー/ゴールドの差し色、かすかなスキャンライン・グレインのオーバーレイでヴィンテージな質感を加えている。フラップの切り替わりは CSS の `rotateX` 3D transform のみで演出し、JS は値の差分検知とクラス切り替えのみを担当する。

## 技術スタック

素の HTML / CSS / JS（ES モジュール）。ビルドツール・npm 依存なし。データ永続化はブラウザの `localStorage` のみ。

選定理由: 単発プロトタイプであり、フラップアニメーションも CSS transform のみで完結できるため、フレームワークやバンドラを導入する必要がない。

## 使い方（ローカル起動）

ビルド不要の静的サイトなので、任意の静的サーバーで配信するだけで動く。

```bash
cd apps/deadline-departure-board

# ビルド確認用（実際にはコンパイル不要）
npm run build

# 開発サーバー起動（Python 標準ライブラリを使用）
npm run start
# → http://localhost:8080 を開く
```

Node 系のツールが使える環境であれば、代わりに `npx serve .` などでも配信できる。

## Docker での起動

```bash
cd apps/deadline-departure-board
docker build -t deadline-departure-board .
docker run --rm -p 8080:80 deadline-departure-board
# → http://localhost:8080 を開く
```

## 操作方法

1. フォームの `TITLE`（英数字・一部記号、最大16文字、自動で大文字変換）・`DATE`（必須）・`TIME`（任意、未指定時は23:59扱い）を入力し「ADD FLIGHT」を押す
2. 追加された締切は残り時間の昇順で一覧に表示され、フラップがめくれて出現する
3. 各行右端の「×」ボタンで手動削除できる
4. 締切超過（`DEPARTED`）になった行は、しばらく表示された後に自動で消える

## スコープ外（今回のプロトタイプでは扱わない）

- 締切の編集（変更は削除して再登録する運用）
- 通知・リマインダー機能
- 繰り返し締切・カテゴリ／タグ・複数ボード
- ドラッグ＆ドロップ等の手動並べ替え
- 効果音・音声演出
- アカウント機能・複数端末同期・バックエンド／DB
