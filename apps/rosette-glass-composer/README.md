# Rosette Glass Composer（ステンドグラス・コンポーザー）

中世ゴシック窓（尖頭アーチ／バラ窓）の輪郭に宝石色の点を打っていくと、距離場ベースの鉛線分割で1枚のステンドグラスが自動生成されるコンポーザーです。バックライト発光演出と自然光表示の2モードを切り替えでき、それぞれ高解像度のPNGとして書き出せます。

> **本アプリは app-factory パイプラインによる自律生成プロトタイプです。** アイディア出し〜コンセプト設計〜実装〜検証までを自律的に行うワークフローの成果物であり、採否をユーザーが判断する段階のものです。

## 使い方

1. 窓の様式（尖頭アーチ窓 / バラ窓）を選ぶ。バラ窓は放射状マリオンの分割数（6 / 8 / 12）も選べる。
2. パレットから宝石色をひとつ選び、窓の輪郭内をクリックして硝子片（点）を配置する。配置するたびに鉛線分割とガラス面がライブで再計算される。
3. 既存の点は以下の操作で編集できる。
   - クリック（移動なし）: 選択中の色に変更
   - ドラッグ（5px以上の移動）: 位置移動
   - ダブルクリック / ダブルタップ / 右クリック: 削除（右クリックはデスクトップ向けの補助的なショートカット）
4. 「不規則さ」「鉛線の太さ」「硝子の質感」「発光の強さ」のスライダーで質感を調律する。
5. 「バックライト」「自然光」ボタンで見え方を切り替え、それぞれ個別にPNG書き出しできる。
6. 写真をドロップ/選択すると、簡易k-means相当の自前実装でドミナントカラーを抽出しパレットに追加できる（画像そのものは抽出後に破棄され、合成には使われない）。

セッション内のみで完結し、リロードすると作業内容は失われます（保存・共有機能は対象外）。

## 技術スタック

Vite + TypeScript のクライアントサイド完結SPA。描画はCanvas 2D APIのみで自前実装しており、Voronoi計算ライブラリやUIフレームワークは使用していません。写真からの色抽出も外部ライブラリなしの自前k-means風実装です。フォントはGoogle Fonts（Cinzel Decorative / Cormorant Garamond）のみ外部依存として読み込んでいます。

距離場ベースの近似（厳密なVoronoi幾何計算ではなく、各グリッド点をノイズでドメインワープしてから最近傍点を探す方式）でガラス面のセルを生成し、セル境界をグリッド解像度の線分群としてPath2Dにまとめ、擬似ベベル（ハイライト/シャドウの重ね塗り）でストロークすることで手作業の鉛線らしい質感を出しています。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド（dist/に出力）
npm run preview  # ビルド結果をローカルで確認
```

## Docker

```bash
docker build -t rosette-glass-composer .
docker run --rm -p 8080:80 rosette-glass-composer
# http://localhost:8080 で確認
```

静的サイト（バックエンド不要）のため、マルチステージビルドで `dist/` を `nginx:alpine` で配信します。

## スコープ外（プロトタイプの割り切り）

- SVG/ベクター書き出し（PNGのみ）
- プロジェクトの保存・読み込み・共有・ギャラリー機能
- 複数連窓の合成（1コンポジションにつき窓は1枚）
- 写真のトレース/モザイク化（色パレット抽出専用）
- 真のドロネー/Voronoi幾何計算
- モバイル操作の最適化（タッチでの基本操作は保証、精度最適化は対象外）
