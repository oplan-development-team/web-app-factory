# カーソル相撲（Cursor Sumo）

同じキーボードを囲んだ2人が、円形の力士を土俵から押し出し合う物理ローカル対戦ゲームです。突っ張りダッシュの駆け引きと、決着の瞬間だけ現れる行司の煽りコメント（朱枠スタンプ演出）が見どころです。

> 本アプリは app-factory パイプラインによって自律生成されたプロトタイプです。

## 遊び方

- プレイヤー1（東・朱）: `W` `A` `S` `D` で移動、`Space` で突っ張りダッシュ
- プレイヤー2（西・藍）: 矢印キーで移動、`Enter` または 右`Shift` で突っ張りダッシュ
- 突っ張りダッシュにはクールダウン（約2秒）があり、HUDの縞模様ゲージが金色になったら再使用可能
- 土俵の外に力士の中心が出た瞬間、その力士の負け
- 3本先取したプレイヤーがマッチの勝者
- 試合中（カウントダウン中・プレイ中含む）は `Esc` でいつでもタイトルへ戻れる
- マッチ終了画面: `Space`/`Enter`/右`Shift`（対戦キー）でリマッチ、`Esc` でタイトルへ
- 画面右上のミュートボタンはタイトル/対戦中/決着後、常に同じ位置からアクセス可能

物理キーボードでの2人同時プレイを前提としたデスクトップ専用ゲームです（スマートフォン等のタッチ専用環境ではタイトル画面に注意メッセージが表示されます）。

## 技術構成

- 素のHTML/CSS/JavaScript + Canvas 2D（ビルドツール・フレームワーク不使用）
- 円剛体の弾性衝突・摩擦・慣性、突っ張りダッシュのインパルスは `src/physics.js` に自前実装
- 効果音（衝突音・ダッシュ音・押し出され確定音）は Web Audio API のオシレーター/ノイズ生成による自前合成（`src/audio.js`、外部音声アセット不使用）
- 状態管理はシンプルなステートマシン（タイトル/カウントダウン/対戦中/決着演出/マッチ終了、`src/game.js`）
- 行司コメントは決まり方（きわどい寄り切り・圧倒的な押し出し・逆転勝ち・僅差）に応じて複数バリエーションから選出（`src/comments.js`）

## セットアップ・起動

依存パッケージはありません。

```bash
# 開発サーバー起動（http://localhost:5173）
npm run dev

# ビルド（dist/ に静的サイト一式を出力）
npm run build
```

ES Modules を使用しているため、`index.html` を `file://` で直接開くとブラウザのCORS制限でモジュール読み込みに失敗します。必ず `npm run dev`（または任意の静的サーバー）経由でアクセスしてください。

## Docker

```bash
docker build -t cursor-sumo .
docker run --rm -p 8080:80 cursor-sumo
# http://localhost:8080 で確認
```

マルチステージビルド（Node.jsで `dist/` を生成 → `nginx:alpine` が配信）です。

## デザイン方針

和風ネオブルータリズム（相撲番付・化粧まわしのモチーフ）。生成り色の和紙背景に極太の黒縁、東（朱赤）/西（藍）のプレイヤーカラーを固定割当し、山吹金をアクセントに使用。ドロップシャドウはブラー無しのハードオフセットのみ。土俵は俵を模した太い縞模様の縁取りで描画し、行司の決着コメントは朱枠の判子（スタンプ）風オーバーレイとして表示します。
