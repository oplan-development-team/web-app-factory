# 家紋帳 — オリジナル家紋ジェネレーター

名前や誕生日を「種」にして、左右対称・点対称の幾何学紋様（オリジナル家紋）をブラウザだけで生成するプロトタイプです。家紋帳の見開きページを開くようなエディトリアルな体験で、生成した紋様をクリーンなSVGとして書き出せます。

> **本アプリは app-factory パイプラインによって自律生成されたプロトタイプです。** アイディア出し・批評・コンセプト具体化・実装・デザインQA・動作検証までを、専用エージェント群が自律的に実行しました。

## 主な機能

- 名前・誕生日（任意テキスト）を入力すると、その場で決定的に紋様が生成される（同じ入力からは常に同じ紋様が再現される）
- 「次のパターンへ」で、同じ種のまま別バリアントを呼び出せる
- 配色は3プリセットのみ（墨×白／朱×白／白×紺）
- このセッション内で生成した紋様は「図版帖」に番号付きで記録され、クリックで再表示できる
- 表示中の紋様を、朱肉の角印を模したボタンからSVGファイルとして書き出せる
- 生成・書き出しはすべて端末内で完結し、サーバーへの送信は一切行わない

## 生成アルゴリズムの概要

1. 入力文字列（名前＋誕生日など）とバリアント番号を結合し、FNV-1aで32bitハッシュ化
2. そのハッシュ値を種として mulberry32（決定的疑似乱数生成器）を初期化
3. 対称モード（線対称、または2/4/6分割の点対称）を確定的に選択
4. 対称の「複製単位」（線対称なら右半分、点対称なら1ウェッジ）の中に、中心モチーフ・外周リングモチーフ（花弁・菱・丸・十字）を配置
5. SVGの `rotate` / `matrix`（鏡像）変換で単位図形を複製し、厳密な対称性を持つ紋様を組み立てる

同じシード・バリアントの組み合わせからは、常に同じ紋様が再現されます。配色プリセットの切り替えは、幾何構造を再計算せず色だけを差し替えます。

## 技術スタック

素のHTML/CSS/TypeScript（フレームワーク非依存）。ビルド・開発サーバーには Vite を使用（バンドル・型チェックの実行環境として最小限に利用しているのみで、UIフレームワークやSVG描画ライブラリは使用していません。図形はすべて自前のSVG文字列生成で構築しています）。

## 開発・起動方法

```bash
npm install
npm run dev       # 開発サーバー（http://localhost:5173 など）
npm run build     # 型チェック + 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果をローカルで確認
```

## Dockerでの起動

```bash
docker build -t kamon-generator .
docker run --rm -p 8080:80 kamon-generator
# http://localhost:8080 で確認
```

nginxが `dist/` を静的配信するだけの構成です。バックエンド・データベースは存在しません。

## プロトタイプゆえのスコープ外

- PNG/JPEG等ラスター形式での書き出し（SVGのみ）
- 生成履歴のブラウザ再読み込み後の永続化（セッション内メモリ保持のみ）
- 任意カラーピッカーによる自由な配色
- 実在の家紋データベース・分類との連携
- 円形以外の紋章外形
- 名刺・封筒・印鑑等への印刷用テンプレート合成
- アカウント登録・共有URL発行・SNS投稿連携
- 多言語UI（日本語のみ）
