# 黒塗りメタデータ開示装置（Redacted EXIF）

写真に埋め込まれた EXIF / GPS / 端末情報を、情報公開請求の「黒塗り公文書」に見立てて演出的に可視化し、リスクを一度だけ確認したうえでワンクリックで完全に除去・ダウンロードできるツールです。

> **本アプリは app-factory パイプラインによって自律生成されたプロトタイプです。**

## できること

- JPEG / PNG を1枚選択（ドラッグ&ドロップ or クリック）すると、`個人情報開示リスク判定書` という架空の行政文書レイアウトで検出項目を表示します。
- 撮影日時・カメラ機種/レンズ・端末シリアル番号・所有者名・著作権情報・GPS座標など機微度の高い項目は、初期表示時に一瞬（約0.3秒）元の値をフラッシュ表示したあと、インクにじみ調の黒塗りバーがスタンプのように降りてきて隠します（`prefers-reduced-motion` 環境ではフラッシュを省略し即座に黒塗り表示します）。
- GPS座標が検出された場合、「撮影地点情報を表示する（1回限り）」から地図タイル1枚+マーカーのプレビューを一度だけ開けます。閉じる操作（封印ボタン・背景クリック・ESC いずれも）は必ず「封印すると二度と表示できません」という確認ステップを経てから恒久的に黒塗りへ戻ります。
- 「証拠品からメタデータを抹消して排出」で、バイナリレベルでメタデータのみを除去した画像をダウンロードできます（後述のとおり非可逆の再圧縮は行いません）。
- 「開示決定書をPNGで出力」で、検出・黒塗り結果を1枚のPNG画像としてエクスポートできます。

## プライバシーについて

- 画像ファイル自体は**一切外部に送信されません**。解析・黒塗り・メタデータ除去はすべてブラウザ内（クライアントサイド）で完結します。
- 唯一の例外は GPS 座標が検出され、「撮影地点情報を表示する」を押した場合です。このときのみ、該当座標付近の地図タイル画像1枚を OpenStreetMap から取得します（画像本体は送信しません）。

## メタデータ除去の方式

- **JPEG**: APP1（Exif / XMP）、APP13（Photoshop/IPTC）、COM セグメントをバイナリ解析して直接除去します。`<canvas>` による再デコード・再エンコードは行わないため、画素データは非可逆圧縮の劣化なしに保たれます。EXIF Orientation タグのみ、除去すると見た目の向きが変わってしまうため、値だけを保持した最小限の APP1 セグメントとして re-insert します（カメラ機種・GPS・シリアル番号等は一切残りません）。
- **PNG**: `tEXt` / `iTXt` / `zTXt` / `eXIf` / `tIME` チャンクを除去します。画素データ（`IDAT`）は無変更です。

## 技術スタック

Vite + TypeScript（フレームワークなし）。EXIF/GPS 解析に [exifr](https://github.com/MikeKovarik/exifr) を利用し、メタデータ除去は上記のとおり自前のバイナリパーサーで実装しています。地図プレビューは地図ライブラリを使わず、OpenStreetMap の XYZ タイルを直接 `<img>` 取得し、マーカーは CSS/SVG オーバーレイで重ねています。

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 本番ビルド（dist/ に静的サイト一式を出力）
npm run preview   # ビルド結果をローカルでプレビュー
```

## Docker

静的サイトなので、ビルド後に nginx で配信するマルチステージ構成です。

```bash
docker build -t redacted-exif .
docker run --rm -p 8080:80 redacted-exif
# http://localhost:8080/ で確認
```

## スコープ外（プロトタイプゆえの割り切り）

- 複数画像の一括処理（1枚ずつ）
- JPEG/PNG 以外（HEIC/RAW/動画）
- サーバー保存・アカウント機能・処理履歴
- 地図のズーム/パン/検索等のインタラクティブ操作（静的タイル1枚+マーカーのみ）
- 実際の情報公開請求制度・政府様式の正確な再現（あくまでパロディ・演出目的です）
- 多言語対応（日本語UIのみ）
