# Life Rings（年輪ポスター）

生まれた年と人生の出来事を数件入力するだけで、有機的に歪んだ年輪・節・放射割れ・木目テクスチャを持つ「自分だけの年輪ポスター」を生成し、SVG／PNGで書き出せるツールです。

>本アプリは `app-factory` パイプラインによって自律生成されたプロトタイプです。

## 使い方

1. 「生まれた年」（ピス＝芯になる年）と、必要なら「終了年」を入力する。
2. タイトル・サブタイトルを編集する（サブタイトルは生年入力時に自動で `生年 – 終了年` が入りますが、自由に書き換え可能）。
3. 「木のトーン」からオーク／ウォルナット／アッシュを選ぶ。
4. 「出来事を追加」で年＋短いラベルを登録する。「大きな出来事」に切り替えると、その年の輪に節（コブ状の膨らみ）・放射状の割れ目・色の濃淡があらわれます。行の並べ替えは ▲▼、削除は × で1クリック完結。
5. プレビューは入力するたびに即座に再計算されます。
6. 下部のボタンから SVG、PNG（画面用 / 印刷用高解像度）を書き出せます。

入力内容はブラウザの `localStorage` にのみ自動保存されます（サーバー同期なし）。

## 技術構成

- Vite + TypeScript（フレームワークなし）
- ドメインロジックは `src/lib/` に分離（フレームワーク非依存）
  - `noise.ts` — シード付きPRNG + 簡易値ノイズ（外部ライブラリ非依存）
  - `rings.ts` — 生年・出来事データ → 年輪モデルへの変換
  - `geometry.ts` — ノイズで歪ませた輪・節・割れ目・バークのSVGパス生成（プレビューと書き出しで同一実装を共有）
  - `export.ts` — SVGシリアライズ／Canvas経由のPNGラスタライズ、ファイル名生成
- 描画は Canvas ではなく手書きSVGのみ（プレビューと書き出しの構造的なズレを防ぐため）
- 木目のムラは SVG の `feTurbulence` フィルタで表現
- 状態管理は素のDOM操作＋小さなpub/subストア（`src/lib/pubsub.ts`）

## ローカルでの起動

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 本番ビルド（dist/ に静的サイト一式を出力）
npm run preview   # ビルド結果をローカルで確認
```

## Dockerでの起動

```bash
docker build -t life-rings-poster .
docker run --rm -p 8080:80 life-rings-poster
# http://localhost:8080 で確認
```

静的サイトのみで完結するため、マルチステージビルド（Node でビルド → `nginx:alpine` で `dist/` を配信）を採用しています。

## スコープ外（プロトタイプとしての割り切り）

- 複数ポスターの比較合成、写真の埋め込み、年月日単位の精緻な時系列表現
- 木のトーン以外のフリーカラー指定
- 印刷業者への発注導線、アカウント登録・クラウド同期、共有リンク
- ポスター自体へのアニメーション演出（書き出しは静止画のみ）
- モバイル最適化された編集体験（デスクトップ/タブレット幅を主眼とし、モバイルは最低限崩れない程度）
