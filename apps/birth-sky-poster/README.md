# Birth Sky Poster — 観測星図ジェネレーター

日時と場所を入力すると、その瞬間・その場所から見えていた星空を天文計算で再現し、計器図面のような精密な円形星図ポスターとして PNG / SVG で書き出せるツールです。

> app-factoryパイプラインによる自律生成プロトタイプです。

## できること

- 日付・時刻（現地時刻＋UTCとの時差を数値入力）と緯度・経度から、その瞬間の空を天頂中心の方位図法で再現
- 「現在地を使う」ボタンでブラウザのGeolocation APIから緯度・経度を自動入力（取得後も手動で上書き可能）
- 場所ラベルは常に自由記述（逆ジオコーディングは行いません）
- 約4.5等級までの恒星（約150個の実在の主要恒星＋密度を補う塗りつぶし用の恒星、計約490個）と、代表的な星座線（約35星座）を表示／非表示切り替え
- 方位環（N/E/S/Wと目盛り付き外周リング）・高度線（同心円）を備えた計器図面風のレイアウト
- タイトル・日付表示・場所ラベルはポスター上のテキストをクリックして自由に手動編集可能
- PNG（1x/2x/4xの解像度選択）・SVG（描画データそのまま、フォント埋め込み済みの自己完結ファイル）の書き出し
- すべての計算・描画はブラウザ内で完結。日時・位置情報は外部に送信されません

## 技術スタック

- Vite + TypeScript（フレームワーク非依存のvanilla構成）
- 恒星位置計算（ユリウス日 → グリニッジ恒星時 → 地方恒星時 → 高度・方位角変換）は外部ライブラリに頼らず自前実装（`src/astro/`）
- 恒星カタログ・星座線カタログはビルド時生成の静的JSON（`scripts/gen-catalog.mjs` → `src/data/*.json`）
- 描画はSVGを直接構築し、そのままSVGダウンロード。PNG書き出しはCanvasにラスタライズして生成
- バックエンドなし、外部APIコールなし（Geolocation APIのみブラウザネイティブ機能として使用）

## 起動方法

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド済みファイルをローカルでプレビュー
```

### Docker

```bash
docker build -t birth-sky-poster .
docker run --rm -p 8080:80 birth-sky-poster
# http://localhost:8080
```

ビルド済みの `dist/` を nginx で配信するだけのマルチステージ構成（実行時イメージは約62MB）。

## 恒星カタログについて（簡易計算の注記）

- 恒星座標はJ2000.0元期の静的データで、歳差・固有運動・章動の補正は行っていません。極端に古い／未来の日付では見かけの位置に誤差が生じます。
- 実在の主要恒星（バイエル符号を持つ約150個、固有名付き）はおおよそのBright Star Catalogue由来の座標を手作業で収録したものです。カタログの密度を「数百個規模」まで補うため、天球上に一様分布させた無名の塗りつぶし用恒星（約340個、3.3〜4.5等）を加えています。星座線は実在恒星のみを結んでいます。
- 太陽・月・惑星の位置表示、全88星座の完全収録、複数のカラーテーマ、都市名からの座標検索は本プロトタイプのスコープ外です。

## デザインの方向性

既存の星空ポスターサービス（Mapiful, StarMapCo, Louvenirなど）が「ダークネイビー背景＋白いドット＋装飾的な円形図＋筆記体の添え書き」という同じ様式に収斂していたため、あえてそれを避け、航海図・測量図・技術計器の読み盤のような精密さを狙ったスイス・インターナショナルスタイルを採用しています。ペーパーホワイトの地に近黒インクの線・文字、単色の朱赤は水平線マーカー・方位針・主要な操作ボタンなど機能要素にのみ使用し、装飾目的では使っていません。
