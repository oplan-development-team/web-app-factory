# Birth Sky Poster — 観測星図ジェネレーター

日時と場所を指定すると、その瞬間・その場所の天頂から見えていた星空を天文計算で再現し、
航海図・測量図のような精密な円形星図ポスターとして PNG / SVG で書き出せる Web ツールです。

バックエンドはありません。天文計算・描画・書き出しのすべてがブラウザ内で完結し、
入力した日時・位置情報が外部へ送信されることはありません。

- 仕様: [`docs/SPEC.md`](docs/SPEC.md)
- 実装方針: [`docs/PLAN.md`](docs/PLAN.md)
- タスク: [`docs/TASKS.md`](docs/TASKS.md)

## できること

- 日付・時刻（現地時刻＋UTCとの時差）と緯度・経度から、その瞬間の空を天頂中心の方位等距図法で再現
- 「現在地を使う」でブラウザの Geolocation API から緯度・経度を自動入力（取得後も手動で上書き可能）
- 場所ラベルは自由記述（逆ジオコーディングは行いません）
- 視等級 4.5 等以下の実在恒星 **921 個** と、**IAU 88 星座**の星座線を表示／非表示切り替え
- 星座線は地平線でちょうど切り詰められ、昇りかけ・沈みかけの星座も見えている部分だけが描かれます
- 恒星名ラベルは重なりを避けて配置されます
- 方位環（N/E/S/W と 5° 刻みの目盛りリング）・高度環（30°/60°）・水平線サークル・方位針
- タイトル・日付・場所はポスター上をクリック（または Tab で選択して Enter）して編集可能
- PNG（1x / 2x / 4x）・SVG（フォント埋め込み済みの自己完結ファイル）の書き出し

## 技術スタック

- **Vite + TypeScript**（フレームワーク非依存の vanilla 構成、`strict` 有効）
- 天文計算（ユリウス日 → グリニッジ恒星時 → 地方恒星時 → 高度・方位角変換）は
  外部ライブラリに依存せず自前実装（`src/astro/`）
- 描画は SVG を直接構築。**画面表示と書き出しで同一の DOM ツリー**を使うため、
  プレビューと出力が構造的に食い違いません
- PNG は SVG を Canvas にラスタライズして生成
- バックエンドなし・外部 API コールなし（Geolocation API のみブラウザネイティブ機能として使用）

## 開発

```bash
npm install

npm run dev            # 開発サーバー
npm run build          # 型チェック + 本番ビルド（dist/ へ出力）
npm run preview        # ビルド済みファイルのプレビュー

npm test               # 単体・統合テスト（Vitest）
npm run test:coverage  # カバレッジ付き（閾値 80%）
npm run test:e2e       # E2E（Playwright / Chromium・Firefox・WebKit）

npm run gen:catalog    # 恒星カタログの再生成（下記参照）
```

E2E は開発サーバーではなく**本番ビルド**に対して実行します。
「外部リクエストが 0 件であること」「書き出した SVG がフォント埋め込みで自己完結していること」は、
実際に配信される成果物についてしか検証する意味がないためです。

### Docker

```bash
docker build -t birth-sky-poster .
docker run --rm -p 8080:80 birth-sky-poster
# http://localhost:8080
```

`node:22-alpine` でビルドし `nginx:alpine` で `dist/` を配信するマルチステージ構成（実行時イメージ約 63MB）。

## 恒星カタログについて

`src/data/stars.json` と `src/data/constellations.json` は `scripts/gen-catalog.mjs` が生成し、
リポジトリにコミットしています。**実行時に外部データを取得することはありません。**

生成元は [d3-celestial](https://github.com/ofrohn/d3-celestial)
（BSD-3-Clause, &copy; Olaf Frohn）が同梱する Hipparcos 由来の実測データです。
d3-celestial は **devDependency のみ**で、アプリの実行時依存には含まれません。

再生成するとカタログの整合性チェック（既知の恒星の位置、星座数、座標範囲など）が走ります。
上流のデータ構造が変わった場合、黙って壊れたカタログを出力せずに生成が失敗します。

### 精度について（仕様として許容している簡略化）

- 恒星座標は **J2000.0 元期の平均位置**です。歳差・固有運動・章動・光行差・大気差の補正は行っていません。
  歳差による誤差は J2000.0 から ±50 年で最大約 0.7°で、これはポスター上で最も明るい恒星の
  ドット半径以下に収まります（[SPEC FR-102](docs/SPEC.md) 参照）。
- 収録は 4.5 等までです。6 等（肉眼限界）まで収録すると 5044 個となり、
  ポスターとして黒くつぶれて可読性を損なうため、意図的に絞っています。
- タイムゾーン DB は持ちません。サマータイムの適用判断を含め、UTC との時差を数値で入力する方式です。
- 太陽・月・惑星の位置、深宇宙天体、天の川、複数カラーテーマ、都市名からの座標検索はスコープ外です
  （[SPEC 1.3](docs/SPEC.md) に除外理由を記載）。

## デザインの方向性

既存の星空ポスターサービス（Mapiful, StarMapCo, Louvenir など）が
「ダークネイビー背景＋白いドット＋装飾的な円形図＋筆記体の添え書き」という同一様式に収斂していたため、
それを避け、**航海図・測量図・技術計器の読み盤**のような精密さを狙った
スイス・インターナショナルスタイルを採用しています。

- **地**: ペーパーホワイト `#f1efe7` ／ **インク**: 近黒 `#17160f`
- **アクセント**: 単色の朱赤 `#bd2a26` のみ。水平線サークル・方位針・N ラベル・
  プライマリ操作・フォーカス・エラーという**機能要素にのみ**使用し、装飾には使いません
- **書体**: グロテスクサンセリフ（Inter）＝ 言語 ／ モノスペース（JetBrains Mono）＝ 数値・座標・時刻。
  この対応は例外なく守ります
- **面の構成**: カード・影・角丸を使わず、太さ 3 段階のヘアラインと余白の強弱だけで階層をつくります

配色トークンは `src/render/tokens.ts` を単一情報源とし、
アプリの CSS・ポスター内蔵 CSS・PNG の下地塗りの 3 箇所が一致することをテストで固定しています。
