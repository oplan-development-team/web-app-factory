### 実装中に確定した仕様変更・判断

- **T09 / FR-106.1**: プロトタイプの乱数生成ダミー恒星（340/490 個）を全廃し、実測カタログへ置換した。
  「観測データを図面化する」というコンセプトと、天球上の 7 割が架空という状態は両立しない。
  結果として恒星数は 490 → 921（すべて実在）、星座は 35 → 88 に増えた。

- **T10 / FR-105.1**: 星座線を「恒星 ID の対」から「折れ線の座標列」へ変更した。
  地平線での切り詰めを行うには、線の頂点がカタログ内の恒星と一致している必要がないため。

- **T07 / FR-001.3**: `Date.UTC` が年 0〜99 を 1900〜1999 に写す仕様のため、
  当該範囲の年で星図が 1900 年分ずれていた。`setUTCFullYear` へ置換した。

- **T13〜T15**: この 3 タスクは 1 コミットに分けられなかった。
  検証を Result 型に変えると、それを消費する状態機械なしにはツリーがビルドできないため。
  T13・T14 は main.ts の最小限の適応を含む形で 1 コミット、T15 で app.ts へ切り出した。

- **T24 / AC-04**: 存在しない日付（2026-02-31）は、Chromium が `<input type="date">` へ
  そもそも受け付けないため E2E では到達できなかった。この規則は多層防御として残し、
  検証は `src/ui/validation.test.ts` の単体テストで行う。E2E では必須項目の空欄で
  エラー状態に入る経路を確認している。

- **T24 / NFR-005.2**: Safari はボタンとチェックボックスを既定で Tab 順に含めない
  （「Tab キーで Web ページ上の各項目を強調表示」設定）。ページ側で上書きすべきものではないため、
  厳密な Tab 走査は WebKit で skip し、全エンジンではフォーカス可能性を確認する形にした。

- **T27**: `.poster-root text { font-family: ... }`（詳細度 0,1,1）が
  `.legend-value` など単一クラスの指定（0,1,0）をすべて上書きしており、
  「数値はモノスペース」という意匠の柱がプロトタイプ期間を通じて一度も効いていなかった。
  JetBrains Mono は読み込まれ書き出しにも埋め込まれていたが、どこにも使われていなかった。

- **T30**: 衝突判定のフォントメトリクスは 3 エンジンで実測した最大値を採用した。
  Chromium 基準で調整すると Firefox でのみラベルが重なる、
  「自分が開いているブラウザでは再現しない」種類の不具合になるため。

- **フッター文言の書体**: T27 の修正でモノスペースが実際に効くようになった結果、
  日本語の散文であるフッターが CJK 部分だけシステムフォントにフォールバックする状態が
  可視化された。「サンセリフ＝言語」の原則どおりサンセリフへ変更した。
