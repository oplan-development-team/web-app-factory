# 傾きガチャ — Tilt Gacha

端末を**振る**と、そのときの**傾き**に応じたパラメトリックな幾何学模様が 1 枚出現し、
**図鑑**に溜まっていく感覚トイ。

出発点は [bookofshapes.com](https://bookofshapes.com) — スライダーで幾何学パターンを
リアルタイム生成する SVG パターン集（黒背景 + 単色の細い線画）。
本アプリはその意匠を踏襲しつつ、**「自由に調整する」道具から「引き当てて集める」トイ**へ
操作モデルを反転させている。

バックエンドなし・完全クライアントサイド。通信は一切行わない。

---

## 遊び方

1. 「振ってみる」を押す（iOS ではここでセンサーの使用許可を求める）
2. 端末を振る。振った瞬間の**傾き**が読み取られる
3. 模様が 1 枚出る。系統・レア度・検出した傾きが表示される
4. 図鑑で 12 種の型を集める

### 傾きと系統の関係

4 つの傾きは、それぞれ相性のいい系統を持つ。
**相性は「決定」ではなく「重み」**で、相性系統が 55%、残り 3 系統が 15% ずつ出る。

| 傾き | 相性系統 | 骨格 |
|---|---|---|
| たて | `FLOW` / ながれ | 波打つ縦線の束 |
| よこ | `GRID` / こうし | ドットの格子 |
| ななめ | `RADIAL` / ほうしゃ | 同心円 |
| さかさま | `NOISE` / ゆらぎ | 散らばった点 |

完全決定にすると 4 方向を順に試して終わりになり、完全ランダムにすると端末を傾ける意味が消える。
バイアスにすることで「たてに構えるとながれが出やすい」という**体感的な学習**が成立する。

### レア度

`COMMON` 70% / `RARE` 25% / `EPIC` 5%。
レア度は**層の数**として視覚化される（1 層 / 2 層 / 3 層）。追加層は同じ系統の骨格を保つ。

系統 4 × レア度 3 = **12 種の型**が図鑑のマスに対応する。

## ジャイロが使えない環境について

PC・非対応ブラウザ・センサー拒否時でも**体験は止まらない**。
ボタンのタップ 1 回がそのまま抽選になり、傾きは 4 方向から無作為に割り当てられる
（そのことは画面に明示される）。

センサーの有無は「値を伴う `devicemotion` が 1200ms 以内に 1 件も来ないか」で判定している。
実機は静止していても連続発火するため、これで「振られていない」と「センサーが無い」を分離できる。

## 開発

```bash
npm install
npm run dev          # 開発サーバー
npm run build        # 型チェック + 本番ビルド（dist/）
npm test             # 単体 + 統合（カバレッジしきい値 80%）
npm run test:e2e     # Playwright（Chromium / Firefox / WebKit）
```

模様の生成結果を目視で確かめたいときは、12 型を並べたコンタクトシートを書き出せる。

```bash
npx vite-node scripts/contact-sheet.ts -- sheet.html [シード]
```

### 技術構成

Vite + TypeScript のフレームワーク非依存構成。外部の SVG / アニメーションライブラリは使わない。

- `src/lib/` — DOM に触れない純粋なロジック。乱数・時刻は引数で受け取るため Node 上で決定的にテストできる
- `src/ui/` — DOM 操作。センサーを知っているのは `ui/motion.ts` だけ
- 模様は `(系統, レア度, シード)` から決定的に再生成できる。**図鑑にはシード整数だけを保存**し、
  サムネイルは毎回生成する（生成済み SVG を保存すると容量を圧迫し、生成ロジック改修時に過去分と整合しなくなる）

フォントは Space Grotesk / JetBrains Mono を `@fontsource` でセルフホストしている
（実行時の外部リクエストを 0 にするため。書体そのものはモックアップの指定どおり）。

## デプロイ

```bash
docker build -t tilt-gacha .
docker run --rm -p 8080:80 tilt-gacha
```

マルチステージ構成で、ビルドした `dist/` を `nginx:alpine` が配信する。

`deploy.json` が `{"pages": true}` のため、main へのマージで GitHub Pages プレビューにも配信される
（プレビューであり本番デプロイではない）。サブパス配信に対応するため Vite の `base` は `'./'`。
