# オーロラ・テルミン (Aurora Theremin)

ポインタ(マウス/シングルタッチ)の位置と速度をピッチ・音量・ビブラートに変換して奏でる、テルミン風のシンセ楽器プロトタイプです。演奏に呼応して、自作のノイズ関数で描くオーロラ状のグラデーションがフルスクリーンCanvas上で揺らめきます。ジェスチャーを録音してその場でループ再生し、最大3レイヤーまで重ね録り(オーバーダブ)できます。

これは **app-factory パイプラインによって自律生成されたプロトタイプ**です(アイディア出し→コンセプト具体化→実装→デザインQA・動作検証の自動サイクルの成果物)。

## 遊び方

1. Canvas上を**ドラッグ**(ホールド+移動)すると発音します。指を離すと止まります。
2. **X座標**が音の高さ(連続的なグリッサンド、2オクターブ程度、音階への量子化なし)、**Y座標**が音量(上ほど大きい)になります。
3. **動かす速さ**がビブラートの深さ・速さとフィルターの明るさに反映されます。速く動かすほど音・映像が揺らぎます。
4. パネル中央の **REC** ボタンで演奏をキャプチャし、もう一度押すと録音を停止して即座にループ再生が始まります(最大45秒、最大3レイヤー)。
5. ループ再生中でも新たに演奏でき、REC で重ね録りできます。各レイヤーのLEDをクリックするとミュート/再生切替、×ボタンでそのレイヤーだけクリアできます。
6. **RESET** で全レイヤーを一括クリアします。

録音・レイヤーのデータはメモリ内のみで保持され、リロードすると消えます(永続化なし)。

## スタイル方向

レトロフューチャリズム(アナログシンセ/宇宙船コンソール意匠)。ダークネイビーのブラッシュドメタル筐体(`#0a0e14`〜`#12161f`)に、アンバー(`#ffb454`)とシアン(`#4dd8e0`)のLED/CRT発光色だけをアクセントとして絞り込み、Canvas内のオーロラは深緑〜ティール〜バイオレット〜マゼンタのキュレーション済みパレット(虹色化はしない)で構成しています。数値リードアウトは等幅フォント(JetBrains Mono)で擬似7segの発光感を、ラベル類はコンデンス系サンセリフ(Oswald)を全大文字・広い文字間で組んで計器銘板のような硬質さを出しています。

## 技術スタック

- Vite + TypeScript、素のHTML/CSS(追加のランタイム依存なし)
- 音声: Web Audio API を直接操作(`OscillatorNode` + `GainNode` + `BiquadFilterNode`、AudioParamのランプ/`setTargetAtTime`でクリックノイズを防止)
- ビジュアル: Canvas 2D API + 自前実装のvalue noise(`src/noise.ts`、外部ノイズ/描画ライブラリ不使用)
- 入力: Pointer Events API(マウス/シングルタッチ共通)

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に静的サイトを出力
npm run preview  # ビルド結果をローカルで確認
```

## Docker

静的サイトとしてビルドし、nginxで配信します。

```bash
docker build -t aurora-theremin .
docker run --rm -p 8080:80 aurora-theremin
# http://localhost:8080 で確認
```

## スコープ外(意図的に含めていないもの)

- マイク/カメラ等の実センサー入力(既存のマイク/カメラ系ジョークアプリとの差別化)
- 録音データのエクスポート/ダウンロード、MIDI出力
- 音階への量子化・スケール補正(連続グリッサンドの生テルミン感を保つため)
- マルチタッチ和音演奏(単一ポインタのモノフォニック楽器として割り切り)
- ユーザーアカウント・共有機能、PWA化、配色テーマ切り替え
