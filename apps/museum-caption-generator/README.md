# 架空美術館 キャプション生成器

手元の写真をアップロードすると、現代アート展の壁面解説文（キャプション）風の
大げさなテキスト（作品タイトル・作家名・素材・寸法・評論文）を自動生成するネタツール。

> **本アプリは app-factory パイプラインによって要件定義から実装まで自律生成されたプロトタイプです。**

---

## 使い方

```bash
npm install
npm run dev     # 開発サーバー（http://localhost:5173 など）
npm run build   # dist/ に静的ファイルを生成
npm run preview # ビルド結果をローカルで確認
```

バックエンドは不要。`dist/` を任意の静的ホストに置くだけで動く。

### Docker

```bash
docker build -t museum-caption-generator .
docker run --rm -p 8080:80 museum-caption-generator
# http://localhost:8080
```

ビルド済みの `dist/` を nginx で配信するだけのマルチステージ構成（実行時イメージは約62MB）。

1. 写真をドラッグ＆ドロップ、またはタップしてカメラロール等から選択（JPEG / PNG / WebP）
2. 展示風のスポットライト演出で写真が浮かび上がり、その下に美術館プレート風のキャプションが自動生成される
3. 「キャプションを引き直す」で同じ写真のまま文面だけ乱数で再生成
4. 「本文をコピー」でキャプション本文をクリップボードにコピー
5. 「展示画像として保存」で写真＋プレートを 1 枚の PNG に合成してダウンロード（SNS投稿を想定）

---

## プライバシー

アップロードした画像は**端末の外に一切送信されない**。

- サーバーを持たない純クライアントアプリ（Vite + TypeScript、フレームワーク非依存）
- 画像解析（色相・彩度・明度の算出）は Canvas API でブラウザ内完結
- PNG 書き出しも Canvas API でその場で合成するのみ（外部ライブラリ不使用）

---

## 技術選定

| 領域 | 選定 | 理由 |
|------|------|------|
| ビルド | Vite + TypeScript（vanilla-ts） | React 等のUIライブラリを使うほどの状態管理は不要。DOM操作で十分完結する規模 |
| 画像解析 | Canvas API（`getImageData`） | 物体認識やAI推論は行わず、縮小画像のピクセルから平均色相・彩度・明度のみを機械的に算出する設計方針のため |
| キャプション生成 | 語彙バンク＋テンプレートの重み付きランダム合成 | 「その写真っぽさ」は色味の傾向を語彙選択の重み付けに反映するだけで十分に演出できる。AI生成文は使わない |
| 画像合成（保存） | Canvas 2D API（`toBlob`） | html2canvas 等を使わず、プレビューと同じ情報を Canvas に再描画することでレイアウト崩れなく1枚のPNGに合成できる |
| フォント | Google Fonts（Noto Serif JP / Playfair Display） | 展示プレートの品格を出すセリフ系ディスプレイフォントが必要なため。CDN読み込みのみで外部への画像・テキスト送信はない |

### 設計上の要点

```
src/
  lib/
    imageAnalysis.ts   画像 → 平均色相・彩度・明度・ムードタグ（Canvas解析のみ、AI推論なし）
    vocabulary.ts       評論調の語彙バンク（形容句・名詞・素材・作家名パーツ等、タグ付き）
    generator.ts         ムードタグに応じた重み付きランダムでタイトル/作家名/年代/素材/寸法/本文を生成
    render.ts             生成結果をプレートDOMへ描画（textContent のみ、innerHTML不使用）
    exportImage.ts     プレビュー全体をCanvasに再描画し、1枚のPNGとして書き出す
    fileHandling.ts     アップロードファイルの形式・サイズ検証、Object URL読み込み
  main.ts                 上記を束ねるDOMイベント配線
  style.css               ダークラグジュアリー・ギャラリーのデザイントークンとレイアウト
```

寸法（cm表記）はアップロード画像の実アスペクト比から算出しており、写真ごとに異なる
「それっぽい」数値になる。色味の解析結果（暖色/寒色/モノトーン・明度）は語彙選択の重みに
反映され、暗い写真では「陰影」「不在」系、暖色の写真では「郷愁」「体温」系の語彙が出やすくなる。

## デザイン方針

**ダークラグジュアリー・ギャラリー空間**を再現する方向性で実装。

- 背景は深いチャコール〜黒（`#0d0c0a`）。実際の展示室の暗さと、上から降りるスポットライトの
  radial-gradient で、アップロード写真が「展示作品」として浮かび上がるよう演出
- キャプションカードは黄銅（`#b08d57`）の二重枠＋淡いクリーム台紙（`#f2e8d6`）で、
  本物の美術館プレートを模した質感。微細なグレインテクスチャ（SVGノイズ）を重ねて紙の質感を出し、
  単調なフラットデザインを避けている
- タイトルは Playfair Display（イタリック）+ Noto Serif JP のセリフ系ディスプレイ書体、
  作家名・年代・素材・寸法はレタースペースを広めに取った小さめの文字、本文は読みやすいセリフ体で
  段落として流し込む、という museum wall label の実際の組版ヒエラルキーを踏襲
- 差し色は真鍮ゴールドのみに絞り、ボタンの hover / focus-visible / active でゴールドの
  アウトラインとグローが淡く反応する

「本物の美術館の空気」と「中身の大げさなテキスト」のギャップ自体がこのツールのジョークの核。

## 既知の制約 / スコープ外

- 物体認識・AI画像解析は行わない（色相・彩度・明度など機械的に取得できる情報のみ使用）
- アカウント登録・生成履歴の保存・ギャラリー機能は非対応
- 複数作品を並べた「展覧会」ページ生成は非対応
- 日本語のみ対応（多言語化なし）
- SNSへの直接投稿連携は行わない。PNGダウンロードまでを提供し、投稿はユーザーが手動で行う想定
- 語彙バンク・テンプレートはコード内の定数として保持しており、外部ファイル化や管理画面は持たない
