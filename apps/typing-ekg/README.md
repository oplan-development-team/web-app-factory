# タイピング心電図 (Typing EKG)

短い英字/ローマ字のプリセット文を打つと、打鍵の間隔がオシロスコープ画面上に心電図のような波形として描かれるタイピング体験ツールです。入力を確定すると、波形と統計値を「心電図モニターのプリントアウト」風のPNG画像として1クリックで書き出せます。

> **Note:** これは app-factory パイプライン（アイディア出し〜プロトタイプ生成を自律的に行う仕組み）によって生成されたプロトタイプです。

## 特徴

- プリセットの短い英字/ローマ字文（5種）からランダム or 選択して開始
- `keydown`/`keyup` のタイムスタンプ（`performance.now()`）を記録し、打鍵間隔をリアルタイムでCanvas上に波形描画
  - 打鍵間隔が短いほど鋭いスパイク、間隔が空くほど波形は平坦に
- Backspace（誤入力の修正）は赤色の「不整脈（ectopic beat）」として視覚的に区別
- 入力完了（対象文と一致 or Enterで明示的に終了）で波形を確定し、所要時間・CPM/WPM・打鍵間隔の乱れスコア・Backspace回数を表示
- 確定した波形とサマリーを、日時・入力文をラベルに含む「モニター プリントアウト」風のPNGとして1クリックでダウンロード
- 「RETRY」で同じ文、または別プリセットを選び直してリトライ可能
- レスポンシブ対応（物理キーボードでの利用を主対象）

## スコープ外（あえて実装していないこと）

- サーバー通信・アカウント登録・ランキング/SNS自動投稿（PNG共有は手動）
- 日本語IME（変換を伴う入力）でのタイミング計測。対象文は英字/ローマ字プリセットに限定
- モバイル仮想キーボードでの高精度計測の保証
- カスタム任意文章のアップロード・自由記述
- 効果音・過去記録の保存/比較・履歴機能

## 技術スタック

Vite + TypeScript（UIフレームワークなし、素のDOM操作）。波形描画はCanvas 2D APIのみ、打鍵タイミング計測はWeb標準の `KeyboardEvent` + `performance.now()` のみで完結し、サーバー通信は一切行いません。

## 開発

```bash
npm install
npm run dev       # 開発サーバー起動
npm run build     # 本番ビルド（dist/ に出力）
npm run preview   # ビルド済みdist/をローカルでプレビュー
```

## Docker

静的サイトのため、マルチステージビルドで `nginx:alpine` から配信します。

```bash
docker build -t typing-ekg .
docker run --rm -p 8080:80 typing-ekg
# http://localhost:8080 で確認
```
