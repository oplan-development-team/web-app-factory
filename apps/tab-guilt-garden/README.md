# タブ庭園 (Tab Guilt Garden)

開いたタブごとに苗が生え、フォーカスを外して放置すると実時間に応じてしおれ、閉じると墓標が残る自虐ジョーク型ブラウザ庭園。

> このアプリは app-factory パイプラインによって自律生成されたプロトタイプです。

## これは何か

- このアプリを開いたタブ1本1本が、庭の苗として表示されます。
- タブにフォーカスを合わせている間は健康に育ち、フォーカスを外して放置すると実時間の経過に応じてしおれていきます（表示テキストは実時間を大げさに盛った「◯時間放置」風の演出）。
- タブを閉じると、そのタブは「墓標」として庭の下の墓地セクションに永久に記録されます（生存期間・死亡時点の放置時間つき）。
- 同一ブラウザ内であれば、開いている複数タブ同士が `BroadcastChannel` + `localStorage` でリアルタイムに同期し、同じ庭を共有しているように見えます。
- サーバー・アカウントは一切なし。保存はこの端末のこのブラウザの `localStorage` のみで完結します。他のブラウザ・他の端末とは同期しません。

## 遊び方

1. 「+ 新しい罪を開く」ボタンで同じアプリを新しいタブとして複数開く。
2. 自分の苗（`YOU` バッジがついているカード）の名前・言い訳を編集できる（他人のタブの苗は編集不可・閲覧のみ）。
3. しばらく別のタブを見て放置してから戻ってくると、しおれ具合が回復する様子を確認できる。
4. タブを閉じると、他のタブの庭に墓標が生えているのが見える。
5. 「庭を焼き払う」ボタンで全状態をリセットできる（確認ダイアログあり）。

## 技術メモ

- Vite + TypeScript（フレームワークなし、素のDOM操作）。
- 状態同期は `BroadcastChannel` によるイベント通知 + `localStorage` の全体再読込のみで実現（サーバー不要）。
- クラッシュ・強制終了でタブが消えた場合も、ハートビート信号が一定時間途絶えたことを他の生存タブが検知し、自動的に墓標へ繰り込む（ゴースト判定）。
- 放置からの経過時間は内部的には数分スケールでチューニングしてデモしやすくしつつ、UI表示テキストは「◯時間放置」のように実際にありそうな時間感でドラマタイズして見せている（`src/constants.ts` の `DISPLAY_TIME_SCALE` 参照）。
- ネイティブの `confirm()` はデザインのトーンに合わないため、庭のリセット確認は自前のネオブルータリズム調モーダルで実装している。

## スタイル方向（frontend-design スキルによる決定事項）

- **方向性**: ネオブルータリズム。自虐ジョークツールらしい荒々しさを狙い、上品にまとめない。
- **配色**: 太い黒枠 + からし色(`#e8a93a`) / 警告レッド(`#d64545`) / 庭グリーン(`#3f7d4e`) のベタ塗り3色 + 生成りの紙色(`#f2e9d8`)。曲線・グラデーション・パステルは不使用。色は装飾ではなく意味を持たせている（緑=健康、からし=注意/しおれ、赤=危険/墓標）。
- **タイポグラフィ**: 見出しは `Archivo Black`（太く荒い大見出し用）、本文/UIは `Space Grotesk`（個性のあるジオメトリック・グロテスク）、統計・タイムスタンプ・墓碑銘は `JetBrains Mono`（データっぽさを強調）。
- **レイアウト**: 罪のスコアはあえて均等グリッドにせず非対称配置＋わずかな傾き（手貼りの紙工作感）。カードは矩形＋厚枠＋オフセット影のみで構成し、角丸は一切使わない。墓標だけは尖った屋根型（`clip-path` による角のカット、曲線は使わない）で庭のカードと差別化。
- **モーション**: 装飾のための動きは避け、状態変化にのみアニメーションを使う（しおれ角度・彩度の変化、ボタン押下時の「スタンプが押し込まれる」動き、墓標へのホバー時の浮き上がり）。

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 本番ビルド（dist/ に静的ファイル一式を出力）
npm run preview   # ビルド結果をローカルでプレビュー
```

## Docker

```bash
docker build -t tab-guilt-garden .
docker run --rm -p 8080:80 tab-guilt-garden
# http://localhost:8080 で確認
```

静的サイト（バックエンド不要）のため、マルチステージ構成（Node.jsでビルド → `nginx:alpine` が `dist/` を配信）になっている。

## スコープ外（プロトタイプとして意図的に省略したもの）

- サーバー・アカウント・複数ブラウザ/端末間同期（同一ブラウザ内のタブ同士のみ）
- エクスポート/インポート・共有・通知/リマインダー機能
- 水やり等のクリックで苗を能動的に救うミニゲーム化（フォーカスに戻ることだけが回復トリガー）
- 苗の種類を手動選択するカスタマイズUI（ランダム割当のみ）
- タブ本来のページタイトル/favicon取得（同一オリジン制約により技術的に不可）
- サウンド演出、モバイル/PWA最適化（レスポンシブ最低限のみ）
