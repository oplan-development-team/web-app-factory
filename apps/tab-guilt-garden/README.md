# タブ庭園 (Tab Guilt Garden)

**このページを開いたブラウザタブ1本が、庭の苗1本になります。**
タブを放置した実時間ぶんだけ苗はしおれ、閉じると墓標が残ります。

タブを溜め込みがちな自分への自虐ジョークであり、同時に**進行が実時間に紐づく
放置系インクリメンタルゲーム**でもあります。

![スタイル: ネオブルータリズム](https://img.shields.io/badge/style-neo--brutalism-e8a93a?style=flat-square)
![バックエンド不要](https://img.shields.io/badge/backend-none-3f7d4e?style=flat-square)

## 1分でわかるコアループ

| | 何が起きるか |
|---|---|
| **① タブを開く** | 苗が1本生える。何タブ開いても、その全部が1つの庭に並ぶ |
| **② 放置する** | そのタブから離れた実時間ぶん、苗がしおれていく |
| **③ タブに戻る** | 苗は回復する。何度枯らしかけても戻れば助かる |
| **④ タブを閉じる** | 苗は墓地へ移り、生きた時間と最期の放置時間が永久に記録される |

苗の段階は7つあり、放置し続けると**枯死のさらに先**まで進みます。

```
発芽 → 若葉 → 満開 → しおれ → 枯死 → 立ち枯れ → 化石化
                                   └─ ここから先は「閉じずに放置し続けた」人だけが見る
```

## 放置ゲームとしての作り

「開いて閉じて終わり」にならないよう、積み上がる要素を用意しています。

- **通算記録** — 通算植栽数・通算埋葬数・最長放置・最長生存・同時最大タブ数。
  **「庭を焼き払う」でも消えません。** 記録の洗浄はできない仕様です
  （消したい場合は焼き払いモーダルの明示的なトグルをONにする必要があります）
- **罪の階級** — 通算埋葬数に応じて `無垢 → 軽犯罪 → 常習犯 → 重罪人 → 庭の破壊神` と昇格。
  次の階級まであと何基かを常に表示します
- **実績（全10種）** — 未解除のものも達成条件つきで表示されるので、次に何を狙うかが分かります
- **時間は止まらない** — 墓標には「埋葬からの経過時間」が表示され、庭が空でも数字は進み続けます

内部の崩壊は分単位（枯死まで実時間3分）でチューニングしつつ、
画面の表示テキストは60倍して「3時間放置」のように誇張しています。
1回座っている間に一通りの変化を見届けられるようにするためです。

## 遊び方

1. 「+ 新しい罪を開く」で同じページを新しいタブとして複数開く
2. 自分の苗（`YOU` バッジのカード）には名前と言い訳を書ける（他タブの苗は閲覧のみ）
3. しばらく別のタブを見てから戻ると、しおれ具合が回復する
4. タブを閉じると、他のタブの庭に墓標が生えているのが見える
5. 初見の説明はヘッダーの「これは何？」でいつでも読み直せる

## 動作の前提

- **サーバー・アカウントは一切不要。** 保存はこの端末のこのブラウザの `localStorage` のみ
- 同期は**同一ブラウザ内のタブ同士のみ**。他のブラウザ・他の端末とは共有されません
- `localStorage` が使えない環境（プライベートモード等）でも動作しますが、
  その場合は一時的な庭になる旨を画面上で告知します

## 技術メモ

- Vite + TypeScript（フレームワークなし、素のDOM操作）
- タブ間同期は `BroadcastChannel` の通知 + `localStorage` の再読込のみ。
  メッセージ本体に状態は載せず、`localStorage` を単一の真実として扱う
- クラッシュ・強制終了で消えたタブは、ハートビート途絶を他タブが検知して
  自動的に墓標へ繰り込む（ゴースト判定）
- タブ間の書き込みは本質的に最終書き込み優先でロックが使えないため、
  直列化を目指さず**各操作を冪等**にしている（埋葬はID重複排除、
  各タブは自分のレコードのみ更新）
- ブラウザの `confirm()` はデザインのトーンに合わないため、確認ダイアログは自前実装

### 構成

```
src/
  domain/    純粋ロジック（DOM・ストレージ・時刻に非依存）
  infra/     localStorage / BroadcastChannel との境界
  ui/        DOM描画
  engine.ts  シミュレーション本体（依存注入）
  main.ts    配線のみ
```

時刻・ストレージ・チャネル・フォーカス判定は `GardenEngine` に注入されるため、
「3分放置で枯死する」といった時間依存の挙動を実時間を待たずにテストできます。

## 開発

```bash
npm install
npm run dev            # 開発サーバー
npm run build          # 本番ビルド（dist/ に静的ファイル一式）
npm run preview        # ビルド結果のプレビュー
npm test               # 単体テスト
npm run test:coverage  # カバレッジ（閾値80%）
```

> テストスイートとE2E・プレビューを**同時に走らせない**こと。どちらもCPUを使い切るため、
> 実装に問題が無くてもタイムアウトで赤くなることがあります。

## Docker

```bash
docker build -t tab-guilt-garden .
docker run --rm -p 8080:80 tab-guilt-garden
# http://localhost:8080
```

静的サイトのため、マルチステージ構成（Node.jsでビルド → `nginx:alpine` が `dist/` を配信）。

## スコープ外（意図的に作らないもの）

- サーバー・アカウント・複数ブラウザ/端末間の同期
- 課金要素・複雑な成長ツリー等の本格ゲームシステム
- 水やり等で能動的に苗を救うミニゲーム（回復トリガーはフォーカス復帰のみ）
- 苗の種類を手動選択するUI（ランダム割当のみ）
- タブ本来のページタイトル/favicon の取得（同一オリジン制約により技術的に不可能）
- サウンド演出・PWA化・通知/リマインダー

## デザイン方針

ネオブルータリズム。自虐ジョークツールらしい荒々しさを狙い、上品にまとめていません。

- 太い黒枠、ぼかしゼロのオフセット影のみ、**角丸は一切不使用**
- 生成り紙色ベース + からし色 / 警告レッド / 庭グリーンのベタ塗り3色。
  色は装飾ではなく意味を持つ（緑=健康、からし=注意、赤=危険/墓標、灰系=枯死以降）
- `Archivo Black`（見出し）/ `Space Grotesk`（本文）/ `JetBrains Mono`（データ）の3書体
- モーションは状態遷移にのみ使用。`prefers-reduced-motion` を尊重
