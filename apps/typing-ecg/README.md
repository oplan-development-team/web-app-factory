# タイピング心電図 (Typing ECG)

打鍵の間隔タイミングだけを計測し、1980〜90年代の病院用心電図モニター風のUIでリアルタイムに波形を描画するジョークプロトタイプです。一定数タイピングすると、間隔の平均・ばらつきから「打鍵の癖」をジョーク診断し、結果をレポート風カードで表示します。診断結果と波形は1枚のPNGとして保存でき、SNS等への手動シェアに使えます。

> 本プロジェクトは app-factory パイプラインによって自律生成されたプロトタイプです。

## 特徴

- 画面中央に心電図モニターを模したパネルUI。走査線・CRTフリッカー・グリッド背景・機器筐体風ベゼルでレトロフューチャーな「稼働中の医療機器」感を演出
- `keydown` のタイムスタンプ間隔のみを計測。**入力された文字の内容は波形にも診断にも一切使わず、保存・送信も行いません**（すべてブラウザ内・画面表示のみで完結）
- Canvas 2D APIでQRSコンプレックス風の波形をリアルタイム描画。打鍵が速いほど鋭く高いスパイク、間隔が空くほど平坦＋ノイズ揺らぎになります
- 瞬間BPM相当値・総打鍵数・経過時間をバイタルサイン風に表示
- 20打鍵以上でジョーク診断が可能に。「診断する」ボタン、または1.5秒の入力停止で自動診断
- 診断は「速度(遅い/普通/速い)」×「規則性(安定/不安定)」の6パターン＋ひとことコメント
- 「PNG保存」で波形＋診断結果を1枚のCanvasに合成し、ダウンロード（外部ライブラリ不使用）
- 「リセット」で計測を初期化し、再計測可能

## 技術構成

素のHTML/CSS/JavaScript（ES Modules、ビルドツール不使用）。

- `index.html` — ページ構造
- `styles.css` — レトロフューチャー医療機器スタイル（配色・タイポグラフィの意図はファイル冒頭コメント参照）
- `app.js` — DOM制御、keydownタイミング計測、PNG合成書き出し
- `ecg-canvas.js` — Canvas 2D APIによるECG波形描画（QRSコンプレックス風スパイク生成）
- `diagnosis.js` — 統計計算（平均・標準偏差・変動係数）とジョーク診断テーブル
- フォントは Google Fonts の `Share Tech Mono` / `VT323` をCDN読み込み

## 使い方（ローカル起動）

ビルドステップの無い静的サイトですが、`npm run build` は構成ファイルの存在確認とJS構文チェックを行う疎通コマンドとして用意しています。

```bash
npm run build   # 構成ファイルの存在確認 + JS構文チェック
npm start        # http://localhost:4173 で静的配信（プレビュー用の簡易サーバー）
```

もしくは任意の静的サーバー（`npx serve .` など）で `index.html` を配信しても動作します。

## Docker

ビルドステップが無い静的サイトのため、マルチステージ不要の単純なDockerfileで `nginx:alpine` にファイルをそのままコピーして配信します。

```bash
docker build -t typing-ecg .
docker run --rm -p 8080:80 typing-ecg
# http://localhost:8080 で確認
```

## 既知の制約（プロトタイプゆえの割り切り）

- 医学的な正確性・妥当性はありません。あくまでジョーク診断です
- 物理キーボードでの利用を想定しています。スマートフォンの仮想キーボードでは `keydown` の発火精度が下がるため、計測結果が不安定になる場合があります
- セッションをまたいだ履歴保存・比較機能はありません（ページを開くたびに初期状態から計測します）
- SNSへの直接投稿連携はありません。PNG保存後、手動でアップロードしてください
