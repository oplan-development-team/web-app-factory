# せーのテレパシー（Sync Reveal Party Game）

1台のスマホ/PCを2人で回し使いし、お題に隠しながら順番に答えを入力、「せーの」で同時公開して一致度と「あうんストリーク」を競う対面パーティーゲーム。

> app-factoryパイプラインによる自律生成プロトタイプです。

## 遊び方

1. お題を2人で確認する（カテゴリは「数字あて」「自由記述」「2択」の3種、約40問をランダム出題）
2. P1が画面を隠しながら回答（伏せ字表示、他人に見せない前提のUI）
3. 「渡しました」ボタンで端末をP2に手渡す（受け渡し確認画面あり）
4. P2が画面を隠しながら回答
5. 両者の回答が揃うと「せーの」カウントダウン→同時公開演出
6. 判定（数字は「ドンピシャ／おしい／ズレ」、自由記述は「完全一致／部分一致／不一致」、2択は「一致／不一致」）に応じてスコア加算。連続で最高一致すると「あうんストリーク」が伸び、倍率が上がる（外れるとリセット）
7. 直近の履歴（お題・両者の回答・判定・獲得点）を一覧確認できる
8. ベストスコア／最長ストリークは`localStorage`に保存され、トップ画面に表示される
9. いつでも「最初から」でセッションをリセットできる

## 技術スタック

Vite + TypeScript（フレームワークなし、バニラDOM）。状態管理は自前の小さなステートマシン（`src/state.ts`）で完結。バックエンド不要・完全クライアントサイド。永続化はlocalStorageのみ（ベストスコア・最長ストリーク）。外部APIキー・音声ライブラリ等の追加依存は無し（Google FontsのCDN読み込みのみ、フォールバックあり）。


## デザイン方針（ネオブルータリズム）

- **背景**: クリーム系オフホワイト `#F5F1E8`。角の対角ストライプ以外は完全フラットにせず、盤面（`.board`）に太い黒罫線とハードエッジのオフセットシャドウ（ぼかし無し）で立体感を出す。
- **配色**: P1=エレクトリックブルー `#0038FF`、P2=ホットマゼンタ `#FF2E63`。一致・高ストリーク時はアシッドイエロー `#FFD400` のフラッシュ演出。
- **タイポグラフィ**: 見出し・判定結果・大きな数字は Archivo Black、本文・指示文は Space Grotesk、スコア/ストリーク/ラウンド番号などのメタ情報は IBM Plex Mono（得点板のような無機質さを対比させる）。
- **モーション**: カウントダウンのジッター、公開時の左右スライド＋ハードストップ、ストリーク中のフリッカー演出など、状態遷移や「当たった感」を伝えるための意味のある動きに限定。
- **操作感**: 入力画面は「相手に見せないでください」の明示バナー＋伏せ字マスク表示。受け渡し画面は物理的な手渡し操作をカードの見た目とアニメーションで強調。

## 判定・スコアの仕様（実装メモ）

- 数値: 差0=ドンピシャ(tier2)、差1〜5=おしい(tier1)、それ以外=ズレ(tier0)
- 自由記述: 全角/半角・カタカナ/ひらがな・空白・大小文字を正規化した上で、完全一致(tier2)／部分文字列一致(tier1)／不一致(tier0)。辞書的な類義語判定はスコープ外
- 2択: 完全一致のみ(tier2)、それ以外は不一致(tier0)
- スコア: 基礎点（tier2=100 / tier1=40 / tier0=0）× ストリーク倍率（ストリーク1で×1.0、以降0.5刻みで上昇、ストリーク5以上で×3.0が上限）
- ストリークは tier2 のときのみ加算、tier1 は維持、tier0 でリセット

## スコープ外（このプロトタイプでは実装していないこと）

- 別端末同士でのオンライン対戦・マルチデバイス同期
- 3人以上でのプレイ・チーム戦
- 音声読み上げ・BGM・効果音
- オンラインランキング・SNSシェア・アカウント機能
- お題のユーザーによるカスタム追加・編集
- 自由記述判定の辞書ベース類義語判定・高度な表記ゆれ吸収
