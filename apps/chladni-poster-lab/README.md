# Chladni Cymatics Poster Lab

n・m の振動モードをスライダーで指定すると、物理式から算出した節線パターンに砂粒子がリアルタイムで集まっていく様子を描き、その瞬間をモード番号・周波数・プレート寸法入りの「実験記録」ポスターとして PNG/SVG 書き出しできるレトロフューチャー実験機材風ツールです。

> このプロトタイプは app-factory パイプラインによって自律生成されました（アイディア出し〜実装〜検証まで一貫してエージェントが実行）。

## 特徴

- モード数 n・m（1〜9）を独立操作できるスライドフェーダー風スライダー
- プレート形状（正方形／円形）とプレート寸法（mm）の指定
- 振幅・駆動強度スライダー、砂粒子密度プリセット（粗い/標準/密: 2000/3500/5000粒子）
- ランダム/リトライボタンで n・m を再選択し、粒子が散って再収束する「実験再試行」演出
- Canvas 2D によるリアルタイム砂粒子シミュレーション。各粒子は変位場の勾配方向へ滑らかに移動し、節線（振幅ゼロ）に収束、腹（振幅大）付近では揺らぎが増す
- n・m 変更時は現在のモード数から目標モード数へなめらかに補間しながら遷移（瞬時ジャンプしない）
- PNG 書き出し: 現在の粒子パターンを実験記録ポスター（タイトル・モード番号・周波数・プレート寸法・通し番号・日時）として2倍解像度で合成しダウンロード
- SVG 書き出し: マーチングスクエア法で節線（ゼロ等高線）をベクトルパスとして抽出し、同じポスターフレーム情報付きでベクター出力
- 初期ロード時は粒子が集まっていく過程そのものをロード完了の合図として使用。書き出し中は処理中表示、完了時はトースト通知でフィードバック

## 物理モデルについて（近似の範囲）

- **正方形プレート**: 標準的な Chladni 自由板モード式 `z(x,y) = cos(nπx)cos(mπy) − cos(mπx)cos(nπy)` を厳密に計算しています。
- **円形プレート**: 上記と同じ変位場を円形境界でクリップして可視化する近似実装です。円板の厳密なベッセル関数解ではありません。
- **周波数表示**: `f = k・√(n²+m²)` の形式（k はプレート寸法から導出される定数）で、正方形膜の波動方程式に基づいた物理的に妥当な近似式です。特定の材質・厚みを較正した実測値ではありません。
- 砂粒子の挙動（節線への収束・腹での揺らぎ）は定性的な物理挙動の近似シミュレーションであり、厳密な流体力学・接触力学シミュレーションではありません。

## 技術スタック

Vite + TypeScript、素の Canvas 2D API（外部シミュレーション/描画ライブラリ不使用）。マーチングスクエア法による SVG 輪郭抽出も自前実装です。バックエンド不要のクライアントサイド完結アプリで、`vite.config.ts` の `base: './'` により GitHub Pages のサブパス配信にも対応しています。

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド（dist/ に静的サイト一式を出力）
npm run preview  # ビルド結果をローカルでプレビュー
```

## Docker

静的サイトなので、マルチステージビルドでビルド後に `nginx:alpine` が配信します。

```bash
docker build -t chladni-poster-lab .
docker run --rm -p 8080:80 chladni-poster-lab
# http://localhost:8080/ で確認
```

## スコープ外（プロトタイプでは扱わない）

- 円形プレートの厳密なベッセル関数解
- 複数モードの線形重ね合わせ、正方形/円形以外の任意プレート形状
- 実際の音声出力・スピーカー駆動シミュレーション
- ユーザーアカウント・保存ギャラリー・SNS共有連携
- 印刷会社への発注連携
- モバイル最適化の作り込み（デスクトップ優先、レスポンシブは最低限）
