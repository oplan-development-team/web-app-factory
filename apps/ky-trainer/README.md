# 空気読みトレーニング（KY Trainer）

日本語特有の「空気を読む」社会的シチュエーションを、マンガのコマ形式で提示するコメディクイズです。制限時間12秒の4択から、その場を一番丸く収める返答を選びましょう。正解すると暖色パレットでほっこり演出、誤答・時間切れは氷結パレットで場が凍る演出になります。全20問終了後、スコア・最高ストリーク・正答率に応じた「空気読みレベル称号」が表示されます。

> 本アプリは app-factory パイプラインによる自律生成プロトタイプです。

## 遊び方

1. スタート画面の「はじめる」をタップ/クリックしてスタート
2. 状況説明を読み、12秒以内に4択から返答を選ぶ（時間切れは自動的に不正解扱い）
3. 結果コマ（正解/誤答/時間切れ）を確認して次の問題へ（自動で進む、タップでも進められる）
4. 連続正解でストリークが伸び、3・5連続などの節目でコンボ演出が出る
5. 全20問終了後、総合スコア・正答数・最高ストリーク・正答率と「空気読みレベル称号」が表示される
6. 「もう一度挑戦」でリトライ、「結果をコピー」で結果テキストをクリップボードにコピー（SNS投稿API連携は無し、テキストコピーのみ）
7. 自己ベストスコア・最高ストリークはブラウザの localStorage に保存され、スタート画面・結果画面に表示される（アカウント・サーバー同期は無し）

## 技術スタック

Vite + TypeScript（フレームワーク非依存のバニラDOM構成）。20問のシナリオは型付きの静的配列としてソース内にハードコードしています。描画はDOM + CSSのみで完結し、Canvas等は使用していません。状態管理は自前の小さな状態遷移（スタート→出題→結果コマ→次問 or 総合結果）です。バックエンドなし、完全クライアントサイド完結。

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 型チェック + 本番ビルド(dist/ に出力)
npm run preview  # ビルド結果をローカルでプレビュー
```

## Docker

静的サイトなので、マルチステージビルドで nginx から配信します。

```bash
docker build -t ky-trainer .
docker run --rm -p 8080:80 ky-trainer
# http://localhost:8080 で確認
```

## デプロイについて

`deploy.json` の `pages: true` により、mainマージ後は GitHub Pages プレビュー（動作確認・共有用、本番運用ではない）の対象になります。本番運用する場合は上記 Docker イメージでのデプロイが前提です。
