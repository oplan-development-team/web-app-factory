# SHOT SPLICE GRID

2回に分けて撮ったスクリーンショット（上半分・下半分）の重なりを検出し、1枚のシームレスな縦長画像に継ぎ足すツール。バックエンド不要、すべての処理はブラウザ内で完結する（画像はサーバーに送信されない）。

このプロトタイプは **app-factoryパイプラインによる自律生成プロトタイプ**（idea-scout → idea-critic → concept-developer → prototype-builder のフローで実装）。

## 機能

- 画像2枚をファイル選択またはドラッグ&ドロップで読み込み（1枚目=TOP、2枚目=BOTTOM）
- 重なり領域の自動検出（グレースケール化した2段階の粗密探索アルゴリズムを自前実装）
- プレビューをドラッグ、または数値入力・矢印キー（Shiftで10px単位）で重なり量を手動微調整
- TOP下端・BOTTOM上端をそれぞれ任意px数カット（固定ヘッダー/フッター除去用）
- 重なり領域でどちらの画像を前面表示するか選択
- 差分表示モード（重なりが完全一致していれば黒くなる合成で位置合わせ精度を目視確認）
- 出力サイズ・重なりpx数をリアルタイム表示
- 上下入れ替え・全クリア
- 完成画像をPNGでダウンロード

## 自動検出アルゴリズムについて

2枚の画像をグレースケール化し、行同士の絶対差分平均が最小になる重なり幅を探索する。

1. **粗探索**: 画像の幅だけを縮小（高さはそのまま）したグレースケール画像で、候補となる重なり量を総当たりに近い密度で走査する。高さを縮小しない理由は、1px単位でしか一致しないシャープな正解位置を、高さ方向の平均化でぼかして見逃さないようにするため。非常に縦長な画像でも探索候補数の上限を設けて実用速度を確保する。
2. **精密探索**: 粗探索で見つかった候補の近傍だけを、フル解像度のグレースケール画像で再評価し、正確な1px単位のオフセットを確定する。

## スタイル方向

スイス・インターナショナルスタイル。「位置合わせ」という行為を「正確な計測作業」として見せるため、オフホワイト＋黒＋差し色1色（vermillion / signal red）の厳格な配色、Space Grotesk（見出し・UI）+ JetBrains Mono（数値・座標表示）のタイポグラフィペアリング、実寸表示のための大きなmono数字readout、測定ブラケット風のコーナー装飾、ハードエッジのオフセットシャドウ（ドラフティングツールのカードが浮いているような質感）を採用した。既存カタログのcontour-draw/contour-portrait（ダーク+ブラス配色・セリフ体のブループリント系）とは配色・書体を明確に分けている。

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 本番ビルド（dist/に出力）
npm run preview   # ビルド結果のプレビュー
```

## Docker

```bash
docker build -t shot-splice-grid .
docker run --rm -p 8080:80 shot-splice-grid
# http://localhost:8080 で確認
```

`dist/`の静的ファイル一式を`nginx:alpine`で配信するマルチステージ構成。

## 技術スタック

Vite + TypeScript + 素のCSS（フレームワーク・UIライブラリ不使用）。画像処理はCanvas 2D APIのみで完結しており、この規模のアプリにフレームワークは過剰と判断した。
