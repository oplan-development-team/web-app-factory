# ブラックライト便箋 (invisible-ink-letter)

暗室の便箋に打った秘密のメッセージを、受け取った相手がカーソル＝懐中電灯でなぞると、通った軌跡だけがネオン色にじわっと発光して浮かび上がり、やがてまた闇に溶けて消える一期一会の手紙アプリです。

> このプロトタイプは app-factory パイプライン（アイディア出し〜実装〜検証までを自律的に行う仕組み）によって自律生成されました。

## 使い方

1. トップページ（URLハッシュなし）が「書く画面」です。本文（最大280字）を入力し、4色のUVインクから1色を選びます。
2. 「懐中電灯でテスト」で、読む側と同じなぞり体験をその場でプレビューできます（編集内容は保持されたまま戻れます）。
3. 「封をする」を押すと、メッセージと色をURLハッシュに軽量エンコードした共有リンクが表示されます。「リンクをコピー」で相手に送れます（現在のタブは書く画面のままです）。
4. 相手がリンクを開くと「読む画面」になり、暗い便箋をマウスドラッグ／指でなぞると、なぞった軌跡だけがネオン色に発光して文字が浮かび上がります。光は数秒でゆっくり消えますが、メッセージ自体はリンクの中にあるので何度でもなぞり直せます。

メッセージはサーバーに保存されません。常にURLハッシュの中だけに存在し、リンクを知っている人だけが開けます。

## 技術構成

- Vite + TypeScript（フレームワーク不使用、素のDOM操作）
- 描画・発光・なぞりマスクの合成はすべて Canvas 2D API のみ（外部の描画/圧縮ライブラリは不使用）
- 手書き風フォントは Yomogi（Google Fonts CDN、`cursive` フォールバック付き）、UI文字は Cormorant Garamond
- バックエンドなし・クライアントサイド完結

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # dist/ に静的サイトを出力
npm run preview   # ビルド結果のプレビュー
```

## Docker

```bash
docker build -t invisible-ink-letter .
docker run --rm -p 8080:80 invisible-ink-letter
# http://localhost:8080 で確認
```

`dist/` を `nginx:alpine` で配信するだけのマルチステージ構成です。

## デプロイ

`deploy.json` の `pages: true` により、GitHub Pages プレビュー対象です（`vite.config.ts` の `base: './'` によりサブパス配信に対応）。
