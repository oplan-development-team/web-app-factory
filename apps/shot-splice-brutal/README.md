# SHOT SPLICE — スクリーンショット継ぎ足し工房

長いWebページやチャット画面を2回に分けてスクリーンショット撮影したとき、上半分・下半分の重なりを検出/手動調整して1枚のシームレスな縦長PNGに継ぎ足すツール。完全クライアントサイド完結で、画像はブラウザの外に出ない。

app-factoryパイプラインによる自律生成プロトタイプではなく、確定済み要件をもとに実装した単発Webアプリ（New_Service_App配下の1アプリ）。

## 主な機能

- 画像2枚をファイル選択 or ドラッグ&ドロップで読み込み（1枚目が上、2枚目が下）
- 重なり幅の自動検出（グレースケール化→行差分の粗探索→局所精密探索の2段階アルゴリズム）
- プレビュー上の継ぎ目バーをドラッグ、または数値入力・矢印キー（Shiftで10px単位）で重なり幅を微調整
- 上画像の下端 / 下画像の上端をそれぞれ任意px数カット（固定ヘッダー・フッターの除去用）
- 重なり領域でどちらの画像を前面にするか切り替え
- 差分表示モード（`mix-blend-mode: difference`でズレを目視確認。位置が合っていれば真っ黒になる）
- 出力サイズ・重なり幅をリアルタイム表示
- 上下入れ替え・全部クリア
- 完成画像をPNGとしてダウンロード

## 技術スタック

Vite + TypeScript（素のDOM操作、フレームワーク不使用）。画像処理はCanvas 2D APIのみで完結し、外部ライブラリ・APIキーへの依存はない。

## スタイル方向

ネオブルータリズム。太い黒枠・オフセットドロップシャドウ・原色的な差し色で「位置を合わせる」「重なりを削る」という道具的な作業感を無骨に表現する。配色は暗室・印刷工房を連想させるパレット（ウォームクリーム地 + 現像液コバルトブルー + アシッドライム + 警告オレンジ）とし、既存カタログのtab-guilt-garden（からし色/警告レッド/庭グリーン）とは意図的に別系統にした。タイポグラフィは見出しにArchivo Black、数値表示（px・出力サイズ）にJetBrains Mono、本文にSpace Groteskを使用し、計測器のデジタル表示のような質感を狙った。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に静的サイト一式を出力
npm run preview  # ビルド済みdist/をローカルで確認
```

## Docker

```bash
docker build -t shot-splice-brutal .
docker run --rm -p 8080:80 shot-splice-brutal
# http://localhost:8080 で確認
```

静的サイトのため、マルチステージビルド（Node.jsでビルド → nginx:alpineで`dist/`を配信）構成。

## デプロイ

`deploy.json`で`{"pages": true}`を指定しており、mainマージ後はGitHub Pagesにプレビューが自動デプロイされる（動作確認用。本番運用時は上記Dockerでのデプロイが前提）。
