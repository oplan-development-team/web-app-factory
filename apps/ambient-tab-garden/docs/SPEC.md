# 浮遊光庭 (Ambient Tab Garden) — 仕様書

**ステータス**: 確定（要件はメインセッション経由でユーザー承認済み。スタイル方向はモックアップ比較で確定）
**種別**: 単発・小規模Webアプリ（`apps/ambient-tab-garden/`）
**バックエンド**: なし（完全クライアントサイド・localStorage永続化のみ）

---

## 1. 概要

このアプリ自身を複数のブラウザタブで開くと、タブ1つにつき1つの「光の粒子クラスタ」が3D空間に生まれ、開いている時間に応じて育っていく観賞用のアンビエント・トイ。放置時間から「きらめき」という資源が貯まり、それを使ってパーティクル系のアップグレードを買うことで、庭全体の見た目が育っていく。

ジャンルとしてはアイドル/インクリメンタルの語彙を借りるが、**自虐・罪悪感・生産性への皮肉といったフレーミングは一切持たない**。ジェネレーティブアート／スクリーンセーバー的なオブジェとして位置づける。

### 先行アプリとの関係

同リポジトリの `apps/tab-guilt-garden/`（タブ溜め込みの自虐ジョーク放置ゲーム）から、**「このアプリの開いているタブ1つ＝育つ実体1つ」というメカニクスのみ**を引き継ぐ。コード・コピー・ビジュアルは一切流用せず、独立した実装・独立したビジュアルアイデンティティとする。

### やらないこと（スコープ外）

- ブラウザ拡張機能化、ユーザーの他サイトのタブの覗き見（通常のWebページからは技術的に不可能。試みない）
- バックエンド、アカウント、サーバー同期
- 深いテックツリー、プレステージ、実績システム
- 課金・外部API

## 2. 用語

| 用語 | 意味 |
|---|---|
| タブ | このアプリを開いているブラウザタブ1つ。リロードしても同一タブとして継続する |
| クラスタ | タブ1つに対応する粒子の群れ。3D空間内の1箇所に浮かぶ |
| きらめき | 時間経過で貯まる唯一の資源。ブラウザ単位（全タブ共有）で1つの残高を持つ |
| 成長段階 (stage) | タブが開かれてからの経過時間で決まる、そのクラスタの成熟度（0〜4） |
| ゴースト | クラッシュ等でクリーンな終了処理を走らせずに消えたタブの残骸レコード |

## 3. 機能要件

### FR-100: マルチタブ・クラスタ

- **FR-101**: ページを開くと、そのタブに固有の識別子（`tabId`）が発行される。`sessionStorage` に保持し、**リロードしても同じタブとして扱う**（クラスタが作り直されない）。
- **FR-102**: 各タブは自分のプレゼンスレコード（`tabId` / `openedAt` / `lastSeenAt` / `seed` / `earned`）を、一定間隔で `localStorage` の共有レジストリに書き込む。**書き込むのは自分のレコードのみ**で、他タブのレコードは読み取った内容をそのまま保つ（最終書き込み勝ちのクロスタブ競合で他タブの状態を壊さないため）。
- **FR-103**: 各タブは、レジストリ上の**生存している全タブ**のクラスタをまとめて描画する（自分のぶんだけではない）。
- **FR-104**: 状態変化は `BroadcastChannel` で即座に他タブへ通知する。`BroadcastChannel` が使えない環境では、定期ポーリング（`localStorage` 再読み込み）だけで結果整合する。
- **FR-105**: タブが正常に閉じられた場合（`pagehide`）、そのタブは自分のレコードをレジストリから削除し、`BroadcastChannel` で退出を通知する。他タブからは**即座に**そのクラスタが消える。
- **FR-106**: クラッシュ・強制終了でクリーンな退出ができなかったタブは、`lastSeenAt` が `GHOST_TIMEOUT_MS` より古くなった時点でゴーストとみなし、レジストリから除去される。
  - タイムアウトは、**バックグラウンドタブのタイマー間引き（Chromeでは最短1分に1回）で生存中のタブが誤って除去されないだけの余裕**を持たせる（120秒）。
- **FR-107**: クラスタは `seed`（`tabId` から決定的に導出）から、3D空間内の位置・色相・粒子の散らばり方が決まる。同じタブは何度描き直しても同じ場所・同じ色になる。

### FR-200: 成長と資源

- **FR-201**: クラスタの成長段階は `now - openedAt`（実時間）から決まる。段階が上がると粒子数・広がり・コア球の大きさが増す。
- **FR-202**: きらめきは**実時間の経過**から積算する。`setInterval` の呼ばれた回数ではなく、前回tickからの実経過ms（`Date.now()` 差分）を使う。バックグラウンドでタイマーが間引かれても、次のtickでまとめて加算されるため取りこぼさない。
- **FR-203**: 1回のtickで加算する経過時間は `[0, 300000]` ms にクランプする（システムスリープ復帰やクロック巻き戻しで異常値が入るのを防ぐ）。
- **FR-204**: きらめき残高 = `banked + Σ(生存タブの earned) - spent`。
  - `earned`: 各タブが自分のレコード内に持つ積算値。自分でしか更新しない。
  - `banked`: タブがレジストリから除去される（正常終了・ゴースト除去いずれも）際に、その `earned` を移し替える先。
  - `spent`: アップグレード購入の累計。
  - この式により、タブが消える瞬間に残高が飛んだり減ったりしない。
- **FR-205**: 開いているタブが多いほど、単純にその数だけ並行して `earned` が増える（タブ数ボーナスの掛け算は行わない。挙動の予測可能性と、自分のレコードだけで完結する計算を優先）。

### FR-300: アップグレード

- **FR-301**: アップグレードは5種類。すべて**ブラウザ全体にグローバルに適用**され、すべてのクラスタに効く。
  - タブは短命で入れ替わるため、購入したものがタブと一緒に消えるのは体験として成立しないという判断による。
  - | ID | 表示名 | 効果 | 上限 |
    |---|---|---|---|
    | `density` | 粒子密度 | クラスタあたりの粒子数を増やす | 4 |
    | `orbit` | 軌道エフェクト | 粒子がコアの周りをゆるく周回する（Lv1で解放、以降は周回速度） | 3 |
    | `bloom` | 発光強化 | ハロー層の広がりと発光量を増す | 3 |
    | `resonance` | 共鳴 | きらめきの獲得レートを上げる | 4 |
    | `spectrum` | 色域拡張 | クラスタが取りうる色相のパレットが広がる | 2 |
- **FR-302**: コストは等比数列。初期コストはモックアップの表示値に合わせる（`density` 500 / `orbit` 1,200 / `bloom` 3,000）。レベルが上がるごとに倍率をかける。
- **FR-303**: 残高が足りない場合、そのアップグレードのボタンは無効化され、説明文が「きらめきが足りません」に差し替わる（モックアップ準拠）。
- **FR-304**: 上限レベルに達したアップグレードは `MAX` 表示となり、購入できない。
- **FR-305**: 購入は全タブに即時反映される（`BroadcastChannel`）。購入時、他タブでも粒子の見た目が変化する。
- **FR-306**: 購入操作は、書き込み直前に共有状態を読み直してから更新する（別タブの購入と衝突したときに、片方の購入だけを取りこぼす窓を最小化する）。

### FR-400: favicon

- **FR-401**: 各タブは、`<link rel="icon">` の href を canvas から生成したPNG data URLに差し替え、**自分のタブ自身の**成長段階をfavicon上に表現する。
- **FR-402**: faviconは成長段階が変わったとき、およびアップグレードで見た目が変わったときに描き直す。毎フレームは描き直さない。
- **FR-403**: faviconはタブストリップ上の小さな表示（16px）で判別できる程度の粒度に留める（中央のコア＋段階に応じた数個の光点）。

### FR-500: 画面

- **FR-501**: 全画面のWebGLキャンバス（three.js）にクラスタを描画する。背景のグラデーション・アンビエントな光のにじみ・微細なダストテクスチャはCSS側で描き、透過したWebGLキャンバスをその上に重ねる。
- **FR-502**: 右上にステータスのガラスパネル：きらめき残高、開いているタブ数、最長放置時間とそのタブ名。
- **FR-503**: 左下にアップグレードのガラスパネル：5行、各行に名称・説明・コストボタン。
- **FR-504**: 左上にワードマーク（`浮遊光庭` / `AMBIENT TAB GARDEN`）。
- **FR-505**: タブが1つしか開かれていない間は、核となる仕掛けが見えないため、**もう1つのタブで開くことを促すヒント**を表示する。タブが2つ以上になったら自動的に消える。手動で閉じることもでき、閉じた選択は記憶する。
- **FR-506**: タブには開いた順に `タブA` `タブB` … と表示名を与える（`tabId` の生UUIDは画面に出さない）。

### FR-600: 状態表示・エラー処理

- **FR-601 (ローディング)**: 初期化中はフェードするオーバーレイを出し、最初のフレームが描画された時点で消す。レイアウトシフトを起こさないよう、オーバーレイは絶対配置とする。
- **FR-602 (エラー: WebGL不可)**: WebGLコンテキストが取得できない環境では、原因と次にできることを示すガラスパネルを表示し、CSSのみの静的な光のフォールバックを出す（真っ白な画面で止まらない）。
- **FR-603 (エラー: ストレージ不可)**: `localStorage` が使えない／書き込みが例外を投げる環境（Safariプライベートモード等）では、メモリ内ストレージにフォールバックし、「このセッションのみ保持される」旨を画面に明示する。アプリ自体は動作を継続する。
- **FR-604 (成功フィードバック)**: アップグレード購入時、ボタンに視覚的な反応を返し、残高の数値がフラッシュし、対象のクラスタが目に見えて変化する。
- **FR-605 (モーション)**: `prefers-reduced-motion: reduce` のとき、粒子のドリフト振幅を大幅に減らし、周回運動とUIのトランジションを止める。

## 4. 非機能要件

- **NFR-01**: フレームレートは、標準的なノートPCのブラウザで、タブ3つ・全アップグレード最大の状態で 50fps 以上を目標とする。粒子の運動はGPU側（頂点シェーダ）で計算し、CPUで毎フレーム全粒子座標を書き換えない。
- **NFR-02**: 発光表現はポストプロセス（EffectComposer/UnrealBloomPass）を使わず、加算合成した2層のポイントスプライト（コア＋ハロー）で表現する。バンドルサイズとGPU負荷を抑えるため。
- **NFR-03**: `localStorage` に保存する内容は、破損・旧スキーマ・手動改変を想定して読み込み時に検証し、不正なレコードは黙って捨てる（アプリ全体が起動不能にならないこと）。
- **NFR-04**: ドメインロジック（純関数）はユニットテストで80%以上のカバレッジを持つ。WebGL描画層はテスト対象外とする。
- **NFR-05**: GitHub Pagesのサブパス配信で動作すること（`base: './'`）。
- **NFR-06**: マルチステージDockerfileで `nginx:alpine` から配信できること。
- **NFR-07**: 個人情報・外部送信は一切行わない。ネットワークアクセスはGoogle Fontsの取得のみ。

## 5. ビジュアル方向（確定：グラスモーフィズム）

参照モックアップ: `apps/ambient-tab-garden/design-reference.dc.html`（ユーザーがダークラグジュアリー案と比較のうえ選定）

- **背景**: 淡いラベンダー→ペールブルー→ごく淡いクリームの斜めグラデーション。左上にブラッシュピンク、右下にペリウィンクルブルー、中央上にミントの巨大なぼかし円を重ねる。細かい白のダストテクスチャを全面に薄く敷く。
- **パネル**: フロステッドガラス。`rgba(255,255,255,0.34〜0.38)` + `backdrop-filter: blur(22px)` + 白い1px境界 + 大きく柔らかい紫みの影 + 内側上端のハイライト。角丸22px。
- **粒子**: 白いコアから色相へ抜ける放射グラデーションの球。色相はラベンダー `#d9c9ff` / ペリウィンクル `#bfd3ff` / ブラッシュ `#ffd6e0` / アンバー `#ffe3c2` / 純白。クラスタごとに1つの主色相を持つ。
- **タイポグラフィ**: Instrument Serif Italic（ワードマーク）/ Outfit（UI）/ JetBrains Mono（数値・ラベル）。Google Fontsから取得。
- **文字色**: 主要 `#4a3d5c`、副次 `#6b6084`、弱 `#8a7fa3`、無効 `#b6aecb`。

Anti-Template Policy対応として、以下を満たす：非対称な四隅配置（画一的なカードグリッドではない）／ワードマークとデータ読み出しの明確なスケール差／背後で実際に動く3Dの上にガラスを重ねた奥行き／3書体の役割分担／クラスタ色相が「どのタブか」を示す意味を持った配色／ボタンのhover・focus-visible・active・disabledを個別に設計。

## 6. 受け入れ基準

| ID | 基準 |
|---|---|
| AC-01 | 同一ブラウザで2つのタブで開くと、**両方のタブ**に2つのクラスタが表示される |
| AC-02 | 一方のタブを閉じると、もう一方のタブから数秒以内にそのクラスタが消え、タブ数表示が減る |
| AC-03 | タブをリロードしても、そのタブのクラスタの位置・色相・経過時間が引き継がれる |
| AC-04 | きらめきの数値が時間経過とともに増加し、タブが2つあるときは1つのときのおよそ2倍の速度で増える |
| AC-05 | 残高が足りないアップグレードはボタンが無効表示になり、「きらめきが足りません」と表示される |
| AC-06 | アップグレードを購入すると残高が減り、粒子の見た目が変化し、**もう一方のタブでも**同じ変化が反映される |
| AC-07 | faviconがタブの成長段階に応じて変化する（初期状態と成長後でPNGのデータが異なる） |
| AC-08 | コンソールエラー（level=error）ゼロで表示される |
| AC-09 | `npm run build` が成功し、`dist/` に静的サイト一式が出力される |
| AC-10 | `docker build` が成功し、コンテナがHTTP 200でページを返す |
| AC-11 | `npm test` が全件成功し、ドメイン層のカバレッジが80%以上 |
| AC-12 | WebGLを無効化した環境でも、エラーパネルとフォールバック表示が出て、白画面にならない |
| AC-13 | `prefers-reduced-motion: reduce` で周回運動が止まる |
| AC-14 | GitHub Pagesのサブパス（`/web-app-factory/ambient-tab-garden/`）配信を模したホスティングでアセットが読み込める |
