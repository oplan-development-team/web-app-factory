# Signature Ribbon Poster

マウス・タッチ・ペンで描いた署名や一筆書きを、動かした速度に応じて太さと発光の強さが変わる「リボン」の光跡として暗い背景に描き、キャプション付きの一枚のポスターとして書き出すツールです。

> このプロトタイプは app-factory パイプラインによって自律生成されました。

## 特徴

- Pointer Events でマウス／タッチ／ペンいずれの入力にも対応。ペンを離してまた描くことで、1枚に複数ストロークを重ねられます。
- 移動距離とタイムスタンプから瞬間速度を算出し、直近値の移動平均でノイズを平滑化。遅い動きほど太く濃く発光し、速い動きほど細く淡く発光します（Canvas 2D の `shadowBlur` と加算合成による多層ストロークでブルームを表現）。
- 背景は「漆黒 / ミッドナイトネイビー / 深いボルドー」の3プリセット、リボンの発光色は「ゴールド / アイスブルー / クリムゾン / パール / エメラルド」の5色から選択。
- 直前ストローク単位の Undo と全消去（Clear）。
- 任意の一行キャプション（署名者名・日付など）を入力すると、書き出し時のみポスター下部に固定レイアウト・セリフ体で焼き込まれます（未入力時は非表示）。
- 「Download Poster」で、背景・リボン・キャプションを合成した 1800×2545px の高解像度 PNG を書き出せます。
- すべての処理はブラウザ内で完結し、サーバーへのデータ送信は一切行いません。

## 技術スタック

Vite + TypeScript（フレームワークなし）。描画は Canvas 2D API を直接利用し、外部の描画ライブラリには依存していません。バックエンドはなく、完全にクライアントサイドで完結します。

## デザイン方針

ダークラグジュアリー。UIチロムは細いヘアライン罫線・十分な余白・セリフ体（Playfair Display / Cormorant Garamond）で構成し、ギャラリーのキャプションカードのような佇まいにまとめています。装飾はゴールド1色のアクセントに絞り、キャンバス上で発光するリボンそのものが視線を集める主役になるようにしています。

## 使い方

```bash
npm install
npm run dev      # 開発サーバーを起動（http://localhost:5173 等）
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド済み dist/ をローカルでプレビュー
```

1. 右側パネルで背景色とリボンの発光色を選びます。
2. キャンバス上をマウス・タッチ・ペンでドラッグして署名／一筆書きを描きます。複数回に分けて描き足せます。
3. 必要なら「Signature Line」欄に一行キャプションを入力します。
4. 「Undo」で直前のストロークを取り消し、「Clear」で全消去できます。
5. 「Download Poster」で高解像度 PNG を書き出します。

## Docker での起動

```bash
docker build -t signature-ribbon-poster .
docker run --rm -p 8080:80 signature-ribbon-poster
# http://localhost:8080 で確認できます
```

静的ビルド成果物を nginx で配信するだけのマルチステージ構成です。

## スコープ外（v1）

- SVG 等ベクター形式での書き出し（グロー表現がラスター前提のため）
- Redo、ストローク単位の個別編集・移動・並べ替え
- 筆圧（pressure）による追加の線幅制御
- 自由なカラーピッカー、グラデーション軌跡、複数色の混色
- キャプションの詳細カスタマイズ（フォント・位置・サイズ・複数行）
- 保存・再読み込み、ローカルストレージ永続化、共有・ギャラリー機能、アカウント機能
- スマートフォン向けの最適化（PC・タブレット利用を主対象）
