# Vinyl Groove Label — サウンド・レコードレーベル・ジェネレーター

音声ファイル、またはマイク録音の振幅を解析し、その波形をレコード盤面の**溝（グルーヴ）の間隔・太さ・明度**に直接刻み込んでレーベルデザインを生成するジェネレーター。溝を音として再生する機能は持たず、あくまで視覚デザインの生成に特化している。

> このアプリは `app-factory` パイプライン（`.claude/workflows/app-factory.js`）による自律生成プロトタイプです。アイディア出し〜コンセプト具体化〜実装〜デザインQAまでを自律的に一括生成しています。

## できること

- **音声ファイルの読み込み**: mp3 / wav / m4a 等をドラッグ&ドロップ、またはクリックして選択（`AudioContext.decodeAudioData` でデコード）
- **マイク録音**: 最大30秒、録音中はレベルメーターをリアルタイム表示（`getUserMedia` + `MediaRecorder`）
- **溝への変調**: 音声から300〜600セグメントのRMS振幅エンベロープを抽出し、レーベル外周から盤外周まで数百本描かれる同心円の溝の**間隔・線の太さ・明度**を連続的に変調。音量が大きい区間ほど溝の間隔が広がり、線が太く明るくなる
- **変調強度スライダー**: デフォルメの度合いをリアルタイムに調整
- **レーベル文字情報**: タイトル・アーティスト名（必須）、カタログ番号・Side表記（任意）をリアルタイムにプレビュー反映。レーベル欄には円弧に沿ったカーブテキストも使用
- **レーベル配色プリセット**: ブラック×ゴールド / ディープレッド×クリーム / ネイビー×シルバー / フォレスト×ブラスの4種
- **艶消し黒ディスク + スペキュラーハイライト**: マットブラックのディスクに、劇場的なスポットライトを思わせる弧状の光沢帯を重ねて質感を表現
- **高解像度PNG書き出し**: オフスクリーンキャンバスで3000×3000pxに再レンダリングしてダウンロード
- **状態表示**: 音声未入力時のプレースホルダー、解析中のローディング、権限拒否・非対応形式・無音入力のエラーメッセージ、書き出し完了時の成功フィードバックを用意

## スコープ外（意図的に実装していないこと）

- 溝を音声として再生する機能（音声合成による読み取り再生は行わない）
- アカウント登録・作品の保存/共有/ギャラリー機能
- 複数トラックのミックスや音声編集（トリミング以外の波形加工）
- 12インチ以外の盤サイズ、B面デザイン
- PNG以外の書き出し形式（SVG/PDF等）
- サーバーサイド処理・外部API連携（音声はすべて端末内で解析され、外部送信されない）

## 技術スタック

- Vite + TypeScript（単一ビューのためフレームワークは使用していない）
- 描画: Canvas 2D API（自前実装。溝の描画・円弧に沿ったテキスト描画・スペキュラーハイライトなどをすべて自前のロジックで構成）
- 音声解析: ネイティブの Web Audio API（`AudioContext.decodeAudioData` / `getUserMedia` + `MediaRecorder`）のみ。外部音声処理ライブラリは未使用
- フォント: `@fontsource/playfair-display`（見出し・レーベル文字）、`@fontsource/space-mono`（技術表記・メーター類）、`@fontsource/inter`（フォーム本文）

## デザイン方向

ダークラグジュアリー。マットブラック〜チャコールの低照度トーンで統一し、暗い試聴室で盤を鑑賞しているような没入感を狙っている。ディスクにはスポットライト状の弧状スペキュラーハイライトを重ねてビニール盤の光沢を再現し、操作UI・レーベルのアクセントカラーにはゴールド/ブラス箔調のグラデーションを使用。タイポグラフィはPlayfair Display（セリフ）とSpace Mono（モノスペース）を組み合わせ、Blue Note/Verveのようなクラシックなレコードレーベルの意匠を想起させる構成にしている。

## 開発

```bash
npm install
npm run dev       # 開発サーバー起動
npm run build      # 型チェック + 本番ビルド（dist/ に静的サイト一式を出力）
npm run preview    # ビルド成果物をローカルでプレビュー
```

## Docker

静的サイトとして、マルチステージ構成でビルド→`nginx:alpine`配信する。

```bash
docker build -t vinyl-groove-label .
docker run --rm -p 8080:80 vinyl-groove-label
# http://localhost:8080 でアクセス
```

## GitHub Pages プレビュー

完全クライアントサイドで完結し、`npm run build` が `dist/` に静的サイト一式を出力するため、`deploy.json` は `{"pages": true}` としている。mainブランチへのマージ後、`https://oplan-development-team.github.io/web-app-factory/vinyl-groove-label/` で確認できる（あくまで動作確認用プレビューであり、本番デプロイではない）。
