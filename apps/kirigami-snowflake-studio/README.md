# 紙雪の結晶スタジオ（Kirigami Snowflake Studio）

「折る → 切る → 開く」という本物の切り紙の手順を疑似体験しながら、六角対称の切り紙雪結晶をクリックだけでデザインできるスタジオです。深夜のアトリエ・カッティングマットをイメージしたダークラグジュアリーな見た目の中で、実際にハサミで作れる SVG 型紙と、完成イメージの PNG を書き出せます。

> このアプリは **app-factory パイプラインによる自律生成プロトタイプ** です（New_Service_App のアイディア出し〜実装を自律的に行う仕組みの成果物）。

## 使い方

1. 初回表示時、六角形の紙が 3 回折りたたまれて 30° のウェッジ（扇形）になる演出が流れます。ヘッダーの「折り方を見る」でいつでも再生できます。
2. 左側の道具箱から「三角ノッチ」「半円」「波線」「ノッチ」の 4 種類のツールを選び、中央のウェッジ（折りたたまれた紙）をクリック・ドラッグして切り込みを配置します。
   - 三角ノッチ・半円は辺（折り目辺・外周）または内部に配置できます。選択後、キャンバス上のハンドルをドラッグしてサイズを調整できます。
   - 波線は辺をドラッグして範囲を指定し、振幅・繰り返し数はサイドパネルのスライダーで調整します。
   - ノッチは辺をクリックするだけの速射ツールで、房飾りのような細かいテクスチャに向いています。
3. 右下の丸いプレビューには、常に展開後の結晶が縮小表示されます。ヘッダーの「開く」でメインキャンバスも実寸大の展開ビューに切り替わります（核となる見せ場のアニメーション）。「たたむ」で編集モードに戻れます。
4. 右側パネルの「デザインを選ぶ」からプリセットを読み込めます。編集中のデザインがある状態で読み込むと、Undo できるトースト通知が表示されます。
5. 「書き出す」から、印刷してハサミで切り抜ける SVG 型紙と、完成イメージの PNG（解像度・背景を選択可）を書き出せます。

### キーボードショートカット

- `Delete` / `Backspace`: 選択中の切り込みを削除
- `Ctrl+Z` / `Cmd+Z`: 元に戻す
- `Ctrl+Shift+Z` / `Cmd+Shift+Z`: やり直す

## 技術スタック

- Vite + TypeScript（フレームワークレス。状態は単純な pub/sub ストアで管理）
- 描画は SVG 一枚岩（プレビュー・SVG 書き出し・PNG 書き出しはすべて同じジオメトリ生成関数から作られるため、見た目と出力がズレません）
- 汎用のポリゴンブーリアン演算ライブラリは使わず、境界パスのパラメトリックな再構成（辺の切り込み）と `fill-rule: evenodd`（内部の穴）で「切り抜き」を表現しています
- フォントは `@fontsource-variable/fraunces`（見出し）と `@fontsource/inter`（UI）をバンドルし、外部リクエストを発生させません
- 幾何ロジック（ウェッジ→ミラー→回転展開、境界パスの再構成、配置バリデーション）は Vitest で単体テストしています

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run test     # Vitest（幾何ロジックの単体テスト）
```

## Docker

```bash
docker build -t kirigami-snowflake-studio .
docker run --rm -p 8080:80 kirigami-snowflake-studio
# http://localhost:8080 で確認
```

`npm run build` が生成する `dist/` を nginx で配信する、静的サイト用のマルチステージ構成です。

## スコープ外（プロトタイプとしての割り切り）

- 4 分割・8 分割など六角形以外の対称パターン
- フリーハンドでの任意多角形描画（意図的に非採用。ガイド付きスタンプ配置に統一）
- ユーザーアカウント・クラウド保存・共有 URL
- 印刷用の実寸(mm/cm)校正・複数用紙サイズ
- 色つき紙・グラデーション紙などマテリアルのバリエーション（生成り紙 1 色のみ）
- 折りガイド線入りの型紙 SVG（書き出しは展開後結晶の輪郭線のみ）
