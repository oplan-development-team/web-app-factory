# スノードーム・メーカー（Atelier de Neige）

写真かミニ落書きを閉じ込めたガラスのスノードームを、その場で作って揺らせる贈り物メーカー。
端末を振る・マウスでドラッグするとパーティクル（雪／ゴールドグリッター／紙吹雪）が
自作の物理シミュレーションで舞い、気に入った瞬間をブラス罫線入りのポストカードとして
PNG保存できる。すべての処理はブラウザの中だけで完結し、写真やイラストは端末の外に送信されない。

> **本アプリは app-factory パイプラインによって要件定義から実装まで自律生成されたプロトタイプです。**

---

## 使い方

```bash
npm install
npm run dev     # 開発サーバー（http://localhost:5173 など）
npm run build   # dist/ に静的ファイルを生成
npm run preview # ビルド結果をローカルで確認
```

バックエンドは不要。`dist/` を任意の静的ホストに置くだけで動く。

### Docker

```bash
docker build -t snow-globe-maker .
docker run --rm -p 8080:80 snow-globe-maker
# http://localhost:8080
```

ビルド済みの `dist/` を nginx で配信するだけのマルチステージ構成。

### 遊び方

1. 「写真を入れる」タブで写真をアップロード（ドラッグ&ドロップ／タップして選択）し、ズームとドラッグで円形マスクに収める。または「落書きする」タブで固定サイズのミニキャンバスにブラシ・消しゴム・スタンプ（⛄🎄🏠⭐❤️）で絵を描く。
2. 台座の素材（ゴールド／シルバー／ローズウッド）と、ドーム内の粒子スタイル（雪／ゴールドグリッター／紙吹雪）を選ぶ。
3. ドームをマウスでドラッグ、またはモバイルで端末を振ると、粒子が独自の物理シミュレーション（重力・減衰・円形境界での反射・底面への堆積）で舞う。DeviceMotionが使えない・許可されない環境ではタップ／クリックでも小さく揺らせる。
4. 気に入った瞬間に「ポストカードに書き出す」を押し、任意のメッセージを添えてPNGでダウンロードする。

## 技術メモ

- Vite + TypeScript（フレームワーク非依存の素のDOM操作）
- ドームの描画・パーティクルの物理シミュレーションはCanvas 2D APIを手書き実装（外部の物理エンジン／描画ライブラリは不使用）
- 雪の「堆積」は角度バケット（floor height map）方式の簡易パイル計算で近似している
- DeviceMotionEventはブラウザネイティブAPIをそのまま使用。iOSの許可ダイアログにはボタンから明示的にリクエストする
- フォントはブティック什器の演出に合わせて Shippori Mincho（見出し・メッセージ）／ Zen Kaku Gothic New（UI）／ IBM Plex Mono（真鍮プレート風のラベル）を採用

## プライバシー

アップロードした写真・描いたイラストはすべてブラウザ内のCanvasだけで処理され、
サーバーへ送信されることはない。書き出したポストカードもその場でダウンロードされるのみで、
どこにも保存・共有されない（アカウント保存やギャラリー機能はスコープ外）。

## スコープ外（プロトタイプゆえの割り切り）

- WebGLによる物理的なガラス屈折・反射（2D近似のハイライト／影表現で代替）
- 1つのドーム内での複数写真の合成、アカウント保存・共有リンク・ギャラリー機能
- PNG以外の書き出し形式（GIF・動画アニメーションなど）
- レイヤーや詳細な色相選択など高機能なお絵描きツール
- 効果音・BGM、複数人での同時編集
