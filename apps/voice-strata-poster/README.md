# 声の地層 — Voice Strata Poster

マイクで録った声の**音量・ピッチ・間（ま）**を、地質調査のボーリングコアのような縞地層として積層描画し、標本ラベル・深度スケール・岩相凡例つきの一枚の科学標本ポスターとしてPNG書き出しできる作品性重視のプロトタイプです。

> **これは app-factory パイプラインによる自律生成プロトタイプです。**（アイディア出し〜コンセプト具体化〜実装〜デザインQA・検証までを自律的に実行するパイプラインで作られました）

## 体験の流れ

1. 標本タイトル・採取者名（任意）を入力する
2. マイクの使用を許可し、「録音を開始する」を押す（最短3秒・最大90秒）
3. 声を出したり、間（沈黙）を置いたりする。経過時間・脈打つRECインジケータ・スクロールするライブレベルメーターが表示される
4. 「録音を停止する」を押すか、90秒に達すると自動停止する
5. 「地層を形成中…」の短い生成演出のあと、1枚の標本ポスターが自動で描画される
6. 「標本ポスターを保存（PNG）」で高解像度PNGを書き出せる。「録り直す」で何度でもやり直せる

## 仕組み（技術メモ）

- 録音音声そのものは**保存も送信もしない**。Web Audio API（`getUserMedia` + `AnalyserNode`）でリアルタイムに解析し、200ms刻みで音量(RMS)・ピッチ(自前実装の自己相関法によるF0推定)・無音判定を抽出するのみ。
- ピッチは連続グラデーションではなく、玄武岩・粘板岩・頁岩・砂岩・石灰岩・石英脈という6段階の「岩相ビン」に離散マッピングする。ピッチのふらつき（ビブラート的発声）が大きい区間は波状のクロスラミナ模様を優先的に割り当てる。
- 音量は層の厚みに、無音は不整合層（ジグザグ境界＋ハッチング）として別種の帯で描画する。隣接する同一岩相区間はマージし、地層列全体が録音時間の長短によらずポスター内の固定高さいっぱいに収まるよう正規化する。
- 積層順序は「録音開始＝地表（上部）、録音終了＝深部（下部）」というボーリング柱状図の慣習に合わせる。
- 岩相ごとのテクスチャ（斑点・ラミナ・結晶脈など）はすべて Canvas 2D API への手続き的な直接描画（外部ライブラリ不使用）。
- 書き出し時は表示解像度の3倍でCanvasを再描画し、PNGとしてダウンロードする。

## スタイル方向

「地質調査フィールドノート／自然史博物館の標本ラベル」をテーマにしたエディトリアル方向。クラフト紙の質感、焦茶〜インク紺のヘアライン罫線、標本タイトルにはFraunces（スラブ／ディドーヌ寄りのソフトセリフ）のイタリック、深度目盛や統計値にはIBM Plex Monoのスタンプ風表記を用いる。配色は玄武岩・頁岩・砂岩・石灰岩・石英脈・粘板岩・不整合層の鉱物パレットに限定し、虹色グラデーションは使わない。

## スコープ外（プロトタイプゆえの割り切り）

- 録音した音声そのものの再生・トリミング・編集は行わない（「聴く」のではなく「地層として見る」体験のため）
- 音声ファイルのアップロードには対応しない（マイクのライブ入力のみ）
- 生成後の地層の手動編集（色・厚みの個別調整）はできない
- 単一の高解像度PNG以外の書き出しフォーマットには対応しない
- 過去標本のギャラリー・アカウント・共有URL機能は持たない（1セッション＝1標本の使い切り体験）
- デスクトップ想定のレイアウトを優先しており、モバイル特化の最適化は行っていない（録音自体は動作する）

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 型チェック + 本番ビルド（dist/ に静的サイト一式を出力）
npm run preview   # ビルド済みdist/をローカルでプレビュー
```

技術スタック: Vite + TypeScript（フレームワーク非依存）、Web Audio API、Canvas 2D API。バックエンド不要・完全クライアントサイド完結。

## Docker

静的サイトとして `nginx:alpine` で配信するマルチステージ構成です。

```bash
docker build -t voice-strata-poster .
docker run --rm -p 8080:80 voice-strata-poster
# http://localhost:8080 で確認
```
