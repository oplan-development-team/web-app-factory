# ハーモノグラフ・ジェネレーター — 振り子の詩

複数の減衰振り子の合成ベクトルをリアルタイムに計算し、実機ハーモノグラフさながらのインクの渦巻き曲線を生成紙面に描く作品性ツールです。トレース・アニメーションで「今まさに描いている」過程を見せながら、プロッター送稿用SVGと高解像度PNGとして持ち帰れます。

> **本プロトタイプは app-factory パイプライン（idea-scout / idea-critic / concept-developer / prototype-builder 等の自律エージェント群）による自律生成プロトタイプです。**

## できること

- 2〜5個の振り子を追加・削除でき、各振り子ごとに **周波数・減衰率・位相・振幅・角度** の5パラメータをスライダーで独立調整可能
- 統一ベクトルモデル（`amplitude * cos/sin(angle) * sin(frequency*t + phase) * exp(-decay*t)` の合成）を外部ライブラリなしで自前実装
- `requestAnimationFrame` によるトレース・アニメーション（実機が描いていく様子を再現）と、即時全描画トグル
- ペン先の局所速度からインクの太さ・濃さを動的に変調（減衰の終盤や方向転換の頂点でインクだまりのように濃く/太くなる）
- 実在するハーモノグラフの型を模した6プリセット（楕円ラテラル型・ロータリー型・スパイログラフ・トライアド・非対称ドリフト型・クローバー共鳴型・混沌の花火）＋ 破綻の少ない見た目に緩くバイアスした「乱数生成」
- 紙面プリセット3種（生成り紙・チャコール紙・方眼紙）と、2色ペン切替を模した「2パス」インクモード
- **SVG書き出し**: mm単位の実寸 `viewBox` を持つ単一クリーンパス。ノード数はRDP (Ramer-Douglas-Peucker) 簡略化を自前実装して抑制（許容誤差はスライダーで調整可能）。2パス時は色ごとに `<g>` レイヤーを分離
- **PNG書き出し**: 選択中の紙面テクスチャ・インク表現を含めて2000px/4000pxの高解像度で書き出し
- バックエンド不要・完全クライアントサイド完結、外部ネットワークリクエストなし

## 割り切っていること（スコープ外）

- 実振り子の厳密な物理演算（ラグランジュ方程式・空気抵抗・支点摩擦係数など）ではなく、減衰正弦波の合成という単純化モデルにとどめています
- アカウント・クラウド保存/共有ギャラリー機能、動画/GIF書き出し、音（ソニフィケーション）、プロッターへの直接送信、モバイルのタッチ操作最適化、プリセットのファイル保存/読込・URL共有、多言語対応は対象外です

## 技術構成

- Vite + TypeScript（フレームワーク非依存のバニラDOM）
- 描画は Canvas 2D API のみ。減衰振り子の合成計算・パス簡略化（RDP）・SVGパス文字列の組み立てはすべて自前実装（外部の数式/グラフ/物理演算ライブラリは不使用）
- フォントは `@fontsource` でバンドル（見出し: Cormorant Garamond、数値・目盛りラベル: JetBrains Mono）
- スタイル方向: ダークラグジュアリー（Victorian精密計器のコンソール意匠）。深いウォールナット/チャコールブラウン背景に真鍮ゴールドの操作パネル、中央に生成り紙のドローイング面を実物の紙が机上に置かれているように埋め込み、「無骨な機械」と「繊細なインクの軌跡」を対比させています

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 型チェック(tsc --noEmit) + 本番ビルド (dist/)
npm run preview   # ビルド結果のプレビュー
```

## Docker

完全に静的なサイトなので、マルチステージビルドで `nginx` により配信します。

```bash
docker build -t harmonograph-generator .
docker run --rm -p 8080:80 harmonograph-generator
# http://localhost:8080 で確認
```

## デプロイ

`deploy.json` の `{"pages": true}` の通り、`npm run build` が `dist/` に静的サイト一式を出力する構成のため、GitHub Pagesプレビューの対象です。
