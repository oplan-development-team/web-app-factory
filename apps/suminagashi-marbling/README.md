# 墨流し マーブリング・スタジオ（Suminagashi Marbling Studio）

墨流し（すみながし）の水面に絵の具を落とし、渦や櫛目で模様を作り込み、紙に「浸して引き上げ」て、継ぎ目のない壁紙タイルまたは観賞用ポスターとして持ち帰れるデジタル工芸ツール。

> **これは app-factory パイプラインによって自律生成されたプロトタイプです。** アイディア出し・設計・実装・検証までを専門エージェント群が一括で行っています。採否はユーザーの判断に委ねられ、採用された場合は本実装（sdd-manager によるフルサイクル開発）に引き継がれます。

## できること

- 中央の「水盤（たらい）」に、6色の伝統色インク（墨・藍・朱・金土・松葉）と透明の礬水（どうさ）から選んで滴を落とし、同心円の模様を作る
- 同じ場所を長押しすると、インクとどうさが交互に自動追加され、多重の同心円（墨流しの核となる模様）ができる
- 「櫛（コーム）」ツールでドラッグすると、方向に沿った波状の縞模様が入る（粗・中・密の3段階）
- 「渦（スワール）」ツールでドラッグすると、回転しながら模様が渦を巻く
- 元に戻す（直近16手まで）・水盤を清める（確認付きリセット）
- 「紙を浸して引き上げる」ボタンで、紙が水面をなぞって模様を写し取るアニメーションが再生され、刷り上がりがギャラリーに追加される（水盤自体はその後も編集を続けられる）
- 各刷りから、(a) 装飾的な縁取り付きの鑑賞用ポスターPNG、(b) 継ぎ目のない壁紙タイルPNG（2×2/3×3の敷き詰めプレビュー付き）を、512/1024/2048pxの解像度で書き出せる

## 技術的な工夫

- 表示・保持しているデータは常に「墨の記録（座標・色・時刻順のリスト）」と「累積した歪みベクトル場」の2つだけ。画面に見えている模様はテクスチャ画像ではなく、この2つから毎フレーム計算して描いている（Canvas 2D + 手計算のベクトル場歪みのみ、外部描画ライブラリなし）
- すべての距離計算は水盤の境界で周期境界（トーラス）としてラップさせているため、水盤に見えている領域そのものが「継ぎ目のない1タイル分」になる
- 書き出し時は、低解像度のライブプレビューを拡大するのではなく、墨の記録と歪み場を書き出し解像度で再評価して描き直す（にじみ・ジャギーを避け、画質を解像度非依存にする）。大きな解像度でもUIが固まらないよう、行単位でイベントループに処理を譲りながら描画する

## スタック

Vite + TypeScript。UIフレームワーク・外部描画ライブラリなし。ロジック（墨の記録管理・歪み場の更新・トーラス距離計算・書き出し用再レンダリング）は `src/lib/` に純粋関数として分離し、Vitest で単体テストしている（`npm test`）。UI状態管理・DOM操作は `src/state.ts` と `src/main.ts` + `src/ui/` の小さなモジュール群で素朴に組んでいる。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
npm test         # Vitest（src/lib/ の純粋関数のみ）
```

## Docker

静的サイトなので、`nginx:alpine` でビルド成果物を配信するマルチステージ構成。

```bash
docker build -t suminagashi-marbling .
docker run --rm -p 8080:80 suminagashi-marbling
# http://localhost:8080/
```

## デプロイ

バックエンド不要・完全クライアントサイドで完結し、`npm run build` が `dist/` に静的サイト一式を出力するため、GitHub Pages プレビュー対象（`deploy.json` の `pages: true`）。`vite.config.ts` の `base: './'` によりサブパス配信にも対応している。

## 割り切り（プロトタイプゆえ）

- セッション内のみで完結。リロードすると消える（保存・再開機能なし）
- アカウント・共有ギャラリーなし
- 模様が完成するまでの過程を動画/GIFとして書き出す機能はなし（将来拡張候補）
- スタイラスの筆圧感知・端末の傾き検知などは非対応。基本的な Pointer Events（マウス・タッチ）のみ
- 色管理は sRGB の PNG 書き出しのみ（CMYK変換等は対象外）
