# 指先の集会 — コイン・セアンス

複数人が同じタブレット/スマホの画面に実際に指を置き、その重心を「玉」として追跡・自律ドリフトさせる、集団の物理接触そのものが核となる疑似こっくりさんボード。

> 本プロトタイプは app-factory パイプラインによって自律生成されたものです。

## 遊び方

1. 画面中央のカードに問いをひとつ入力し、「はじめる」を押す（入力中は盤面への接触は無効）。
2. 参加者は盤面に指を置く（複数人可、画面上部に接触本数が表示される）。玉が指の重心に寄り添う。
3. 指の動きが一定時間（デフォルト約3秒、設定で調整可）止まると、玉が自律的にドリフトしはじめ、線香の煙のようなトレイルを残しながら答えのゾーンへ吸い寄せられていく。
4. いずれかのゾーンに一定時間とどまると着地・確定する。画面下部の「続ける」ボタンを押すか、指を一度すべて離してから置き直すと、同じ問いに文字を連結できる（着地直後、指を置いたままの連続接触では自動的には続かない ―― 答えを読む間もなく続いてしまわないようにするため）。
5. 「鳥居」または「さようなら」に着地するとセッションが終了し、質問・着地シーケンスのまとめが表示される。「怪談札を書き出す」から、和紙・朱印風の札をプレビューし、確認のうえ PNG としてダウンロードできる。
6. 画面左右のタブから「設定」（アイドル判定時間・ドリフト速度/強度・吸引半径/強度）と「記録」（セッションの応答ログ）を開閉できる。盤面のレイアウトを覆わないよう、開くと盤面側が縮んで再フィットする。

セッションの状態はすべてブラウザのメモリ上のみで保持され、リロードすると消えます（永続化なし）。

## 技術構成

- Vite + TypeScript + Canvas 2D（外部フレームワーク・外部ノイズライブラリ非依存）
- 複数指の追跡は Pointer Events（pointerId 単位で管理し、重心を算出）
- ドリフトは自前実装の軽量 Perlin ノイズ（`src/noise.ts`）
- フォント: 見出し・盤面文字は筆文字風の `Yuji Syuku` / `Klee One`、設定・ログ等の UI 操作系は `Zen Kaku Gothic New`（対比を作るための意図的な使い分け）
- バックエンドなし、完全クライアントサイド

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 型チェック + 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果のプレビュー
```

## Docker

静的サイトなので、ビルド成果物を nginx で配信するだけのマルチステージ構成です。

```bash
docker build -t coin-seance .
docker run --rm -p 8080:80 coin-seance
# http://localhost:8080 で確認
```

## スコープ外（プロトタイプゆえの割り切り）

- 音響効果、複数デバイス間のネットワーク同期、ログの永続化・アカウント機能
- AIによる回答生成・カメラ/音声認識、SNS直接シェア（PNGのローカルダウンロードのみ）
- マウス単一ポインタでの本番体験保証（開発時の動作確認用途に限る。実プレイは複数指のタッチ操作を前提とする）
