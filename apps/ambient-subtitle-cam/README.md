# アンビエント映画字幕オーバーレイ（Ambient Subtitle Cam）

自室のウェブカメラ映像に、**音量スパイク**と**動き検出**だけをトリガーにした映画風フェイク字幕（`[遠くでサイレンが鳴る]` 等）をリアルタイムで重ねるネタツールです。物体認識・音声認識・文字起こしなどのAI/ML処理は一切行わず、音量のRMS値と画素差分（ダウンサンプリングした前後フレームの差）という単純な閾値判定のみで駆動する軽量な仕組みに徹しています。

> このプロトタイプは `app-factory` パイプラインによって自律生成されました（アイディア出し〜デザイン方針決定〜実装まで一括生成。人間による個別の実装作業は行っていません）。

## できること

- カメラ・マイクへのアクセスを許可制で取得し、ミラーリング済みの映像をリアルタイムプレビュー
- 音量スパイク（Web Audio APIのAnalyserNodeでRMS計測）・動き検出（Canvas上の画素差分）・沈黙/静止（一定時間動きが無い状態）の3種のトリガー
- トリガー種別ごとに、選択中のムード（サスペンス／メロドラマ／日常コメディ）のキャプションバンクからランダムに1件を選び、下部中央にブラケット付きでフェードイン/アウト表示（クールダウンと表示中ガードで連発を防止）
- 音量・動きの感度スライダーで、環境ノイズやカメラの違いを吸収
- 手動キューボタン（キーボードショートカット `1` / `2` / `3`）で、狙ったタイミングで字幕を出す
- 合成済みキャンバス（映像＋レターボックス＋グレイン＋ビネット＋タイムコード＋REC＋字幕）のPNGスナップショット保存
- ボタン押下から3秒間のWebMクリップ録画・ダウンロード（映像＋音声）
- 映像・音声はいずれもサーバーへ送信・保存されません。すべてこの端末のブラウザ内で完結します

## スタイル方向

ダークラグジュアリー × フィルムノワール／アートハウス上映室調。マットブラック基調にシャンパンゴールド/真鍮の差し色、上下太めのレターボックス黒帯、微細なフィルムグレインとビネット、モノスペースのインクリメントタイムコード、点滅する赤いRECインジケーター、白文字＋黒縁取りのブラケット付き映画字幕、真鍮風アクセントラインの操作卓——という具体的な意匠まで固めた上で実装しています。

## 技術スタック

素のHTML/CSS/JS（Canvas API + getUserMedia + Web Audio API(AnalyserNode) + MediaRecorder API のみ、外部UIライブラリなし）。ビルドツールとして [Vite](https://vitejs.dev/) を使用していますが、これはあくまで開発サーバー・バンドル用途で、アプリのロジック自体には一切のフレームワーク・ライブラリを使用していません。

## 使い方（ローカル開発）

```bash
npm install
npm run dev       # 開発サーバー起動（表示されるURLをブラウザで開く）
npm run build     # 本番ビルド（dist/ に静的サイト一式を出力）
npm run preview   # ビルド結果をローカルで確認
```

「上映を開始する」ボタンを押し、カメラ・マイクへのアクセスを許可してください。カメラ映像が表示されたら、自動検出（音量スパイク／動き／沈黙）または手動キューで字幕が表示されます。

## Dockerでの起動

```bash
docker build -t ambient-subtitle-cam .
docker run --rm -p 8080:80 ambient-subtitle-cam
# http://localhost:8080 をブラウザで開く
```

マルチステージ構成（Node.jsでビルド → `nginx:alpine` が `dist/` を配信）で、バックエンドは不要です。

## プライバシーについて

カメラ映像・マイク音声はいずれもサーバーへ送信・保存されません。音量・動きの数値判定と字幕合成はすべてこの端末のブラウザ内で完結します。物体認識・音声認識・音声文字起こしなどのAI/ML処理は一切行っていません。

## スコープ外（意図的に対応していないもの）

- 物体認識・音声認識・文字起こしなどのAI/ML解析
- アニメーションGIF生成（短尺WebMクリップ保存で代替）
- 複数人・複数カメラ・複数ウィンドウの同時処理
- SNS直接投稿・共有API連携（ローカルへのダウンロードのみ）
- キャプション文言のユーザー編集・カスタムバンク追加
- スナップショット/クリップの履歴管理・一覧機能
- スマートフォン向けの最適化（PCブラウザでの利用を主眼とし、モバイルは動作すれば良い程度）
- 日本語以外の字幕・多言語対応
