# サイアノタイプ・ポスターメーカー

写真を誤差拡散ハーフトーンでプルシアンブルーの二階調に変換し、紙の繊維テクスチャ・手引きの藍液の塗りムラ・不規則な白いふちまで再現して、植物標本ラベル付きの一枚のサイアノタイプ風ポスターとして高解像度PNG書き出しできるツールです。

> app-factoryパイプラインによる自律生成プロトタイプです。コンセプト出し〜デザイン方針決定〜実装までをエージェントが自律的に行いました。

## できること

- 写真をドラッグ&ドロップ／ファイル選択でアップロード（JPEG / PNG）
- グレースケール化 → コントラスト・感光しきい値を調整できるFloyd-Steinberg誤差拡散による二階調ハーフトーン化（リアルタイムプレビュー）
- プルシアンブルー系のインク・紙色プリセットを3種（クラシック濃藍 / 褪色ヴィンテージ / 深藍）から選択
- 質感の作り込み
  - 紙の繊維をプロシージャル生成するノイズテクスチャ
  - 手引きの藍液の濃淡ムラ・周辺減光のヴィネット
  - 感光域の縁を「直線マスク」「ラフな手塗り縁」から選択（ラフ側はノイズで揺らした不規則な境界＋欠け）
- 植物標本ラベル（学名イタリック・和名/通称・採集地・緯度経度・採集日・標本番号）。標本番号はアップロード時に自動採番、緯度経度はGeolocation APIでの現在地取得ボタン付き
- レイアウトプリセット2種（縦長標本シート／正方形）
- 2×/3×相当の高解像度PNG書き出し

画像・ラベル情報はすべてブラウザ内で完結して処理され、サーバーへは一切送信されません。

## 技術構成

Vite + TypeScript（バニラ構成、フレームワーク不使用）。画像処理（グレースケール化・誤差拡散ハーフトーン・ノイズテクスチャ生成・境界のゆらぎ）はすべてCanvas 2D APIで自前実装しており、外部の画像処理/フィルターライブラリには依存していません。バックエンド不要、完全クライアントサイド完結です。

## デザイン方針

自然史博物館の植物標本アーカイブ（19世紀ハーバリウム・シート様式）をエディトリアルに再構成。ポスター本体（生成される標本シート）はプルシアンブルーのインク色と生成り〜クリームの紙色の2色構成のみに徹底し、実在の単色印画技法らしいリアリティを保っています。囲むツールUI側は、ダークな「陳列室」の壁色にクリームの索引カード（コントロールパネル）を並べ、真鍮の金具（フォーカスリング・留め具のドット）で標本キャビネットらしい質感を添える構成です。学名タイトルはイタリック体セリフ（EB Garamond）、日付・座標・標本番号はタイプライター風モノスペース（Special Elite）、産地・付帯情報はスモールキャップスの本文セリフという3層のタイポグラフィ対比を敷いています。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド成果物のプレビュー
```

## Docker

静的サイトとしてビルドし、nginxで配信するマルチステージ構成です。

```bash
docker build -t cyanotype-poster-maker .
docker run --rm -p 8080:80 cyanotype-poster-maker
# http://localhost:8080 で確認
```

## スコープ外（このプロトタイプでは扱わない）

- 実際の化学的感光プロセス（露光時間・薬品反応など）のシミュレーション
- 地名からの自動ジオコーディング（外部API依存を避けるため、緯度経度は手入力＋Geolocation APIでの現在地取得のみ）
- 画像認識による学名・植物種の自動判定/AI提案
- 複数写真の合成・コラージュレイアウト
- 印刷注文・物理プリント連携
- 作品のギャラリー化・複数保存・共有機能（localStorageでの履歴管理含む）
- 藍以外の色調（セピア・モノクロ等）のフィルター
