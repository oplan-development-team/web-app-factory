# 文章クセのカルテ — Prose Habit X-ray

貼り付けた1本の日本語文章を、ルールベースで文体のクセ（「が」連続・同語尾連続・文長のばらつき・受動態・体言止め・同一接続詞の多用）の6項目にわたって診断し、健康診断風の「カルテ」として可視化するプロトタイプです。

app-factoryパイプラインによる自律生成プロトタイプです（コンセプト立案からデザイン・実装・検証までエージェントが一括で行いました）。

## 使い方

1. トップの入力欄に日本語の文章を貼り付け、「診断する」を押す。
2. 6項目それぞれについて「異常なし／軽度／要注意／要精査」の所見と、該当箇所の抜粋がカード形式で表示される。カルテ冒頭には総合判定（A〜D）と、最も顕著な傾向から機械的に選ばれる「診断タイプ」が表示される。
3. 左側の原文パネルには、診断完了と同時に6項目すべての該当箇所が色分けハイライトされた状態で表示される（X線フィルムに複数の所見が同時に写るイメージ）。
4. カード内の該当箇所をクリックすると、原文パネル内の該当箇所へスクロールし縁取り＋明滅で強調表示される。逆に原文パネル内のハイライト箇所をクリックすると、対応するカードの該当項目へスクロールする（双方向連携）。
5. ヘッダー右上の「別のテキストを診断する」でいつでも入力画面に戻れる（確認ダイアログなし。診断結果はページ内メモリのみで保持され、保存・共有機能はない）。

デスクトップ幅（900px以上）では原文パネル（独立スクロール／sticky）とカルテのカード列を左右2カラムで表示し、長文の見比べを主眼に設計しています。モバイル幅では縦積みにフォールバックしますが、カードクリック→ハイライト連携などの操作は維持されます。

## 診断ロジックについて（重要な割り切り）

- 文分割は句点（。／！／？）を基準にした正規表現ベースの簡易分割です。鍵括弧内の句点などでも分割されてしまう場合があります。
- 受動態・体言止め等の判定も、形態素解析ではなく正規表現・文字列ヒューリスティックによる簡易判定です。誤検出があり得ます。
- 解析はすべてこの端末内（ブラウザのJavaScript）で完結し、外部NLP API・サーバーへの送信は一切行いません。

## 技術構成

- Vite + TypeScript（フレームワーク非依存のvanilla DOM実装）。UIフレームワークの状態管理を要さない規模のため採用。
- 解析ロジックは `src/analysis.ts`、カード⇔原文ハイライトの重なり処理は `src/highlight.ts`、DOM構築・イベント配線は `src/main.ts` に分離。
- フォントは `@fontsource/noto-sans-jp`（見出し・本文）と `@fontsource/jetbrains-mono`（文字数・スコア等のデータ表現）をバンドルし、外部フォントCDNには依存しない。
- バックエンドなし、完全クライアントサイド完結。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果のプレビュー
```

## Docker

```bash
docker build -t prose-habit-xray .
docker run --rm -p 8080:80 prose-habit-xray
# http://localhost:8080/ で確認
```

## デプロイ

`deploy.json` で `pages: true` を指定しており、GitHub Pagesプレビュー対象です（`vite.config.ts` の `base: './'` によりサブパス配信に対応）。
