### [11:45:12] prototype-builder（初回実装） — 液だまり(Puddle Tilt)をapps/puddle-tilt/に実装
- 結果: frontend-designでダークラグジュアリーの配色/タイポ/レイアウトを具体化した上で、Vite+TS+Canvas 2Dで浅水シミュレーション(2バッファ波紋+セミラグランジュ移流)・薄膜干渉風カラー・DeviceOrientationEvent連携(iOS権限フロー含む)・PNG書き出しを実装。テスト30件（Vitest）、npm run build、docker build --独立起動確認まで完了。
- 実装中に見つけた不具合と対処:
  1. 標準的な4近傍リップル方程式を反射境界(clamped)のまま使うと、正方形グリッドの角で波が反射して持続的な定在波（角ばった模様）ができ「液体っぽさ」を損なっていた。可視円の外側(半径92%〜)にのみ効く放射状スポンジ減衰を追加し解消。
  2. hslToRgbのhue正規化に`((h%360)+360)/60`と書いており外側の%360が抜けていたため、常に同じHSLセクターに落ち込みG成分が常時ゼロになるバグがあった（既存の赤単色テストだけでは偶然検出できなかった）。Playwrightで実際のcanvasピクセルを時系列サンプリングして発覚。修正し、全primary/secondary hueを検証する回帰テストを追加。
  3. バグ修正後にhueScaleを高いまま使うと虹色が全周期回ってしまい「ティール→マゼンタ→ゴールド」の意図から外れた（緑・黄色が混入、モアレ状のノイズも発生）。HSLの連続hue回転をやめ、3色をRGB空間で直接lerpするfilmColorAtに置き換えて解決（意図しない色相を経由しなくなる）。
  4. iOS判定以外の環境（Chromiumデスクトップ等）でもDeviceOrientationEventはbeta/gamma=nullの「センサー無し」イベントを1回発火する仕様があり、それを「受信した」と誤判定してTILT ON扱いしてしまっていた。beta/gammaが実際に非nullの場合のみ受信成功とみなすよう修正。
  5. 何も操作しない静止状態だと高さ場が完全にフラットになり単色べったりの円になっていた（「生きた宝石」の体験品質に反する）。低振幅で緩やかに周回するアンビエント波源を常時追加し、常に微かに呼吸しているように調整。
- 気づき: 色関連のバグはコードレビューだけでは気づけず、Playwrightでcanvasピクセルを実際にサンプリングして数値検証したことで発見できた。visual-qaのチェックリストにある「スクリーンショットは眺めるのではなく照合する」を、動的なcanvas描画物に対しては「実際にピクセル値をサンプリングして期待値と突き合わせる」レベルまで踏み込む必要があった。
